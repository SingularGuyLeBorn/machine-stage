# UI 风格规范（一页纸）

> 项目主人的明确要求：**大气现代 · 浅色 · 素雅 · 简洁 · 交互清晰**。
> 本文档是硬要求，不是建议。任何实现者改 UI 前先读这一页。

## 1. 总基调

**军工工作台**：像一张干净的工程图纸铺在浅色台面上——模型是主角，UI 是衬托，长时间看不累。

- ✅ 浅色底（冷灰白系，禁止纯白刺眼）
- ✅ 单一强调色（钢蓝 = 军工图纸蓝，非饱和）
- ✅ 平实边框 + 微弱层级阴影，无拟物化堆叠
- ❌ 禁止暗黑模式、高饱和色、霓虹渐变、玻璃拟态

## 2. 单一真值源

颜色 / 间距 / 圆角 / 字体 **只**在 `src/app/styles/tokens.css` 定义（CSS 变量），组件内**禁止写裸值**（hex、px 散落）：

- 底色：`--bg`（冷灰白 #f3f4f6）／面板 `--panel`（白）
- 文字：`--text` 三级（主 / 次 / 弱）
- 强调：`--accent`（钢蓝 #2f6ea8）及其 soft/line 变体
- 语义色：danger / warn / ok 各有 soft + line 三件套

新增颜色需求 → 改 tokens，不改组件。

## 3. 布局与交互

- **三栏**：左 角色库+零件树 / 中 3D 视口 / 右 动作+参数——结构不许变
- 交互清晰：每个可点元素有 hover 态；危险操作（清空、重置）有确认；当前态（选中模型/乘位/构建层）永远可见
- 文字用中文军语 + 手册原名（与零件命名同源），禁止自造花哨术语

## 4. 验收

- [ ] 全站无裸 hex/px（组件抽查）
- [ ] 截图对比：色调与 tokens 一致，无未授权变更
- [ ] 暗色背景下打开 = 验收失败（本项目没有暗黑模式）
