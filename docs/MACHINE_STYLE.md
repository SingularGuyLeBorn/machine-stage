# Machine Skill 风格指南（fight-stage 适配版）

> 来源：AirsupHQ/machine-skill（本地副本 `D:\FunnyProjects\threejs_refs\repos\machine-skill`，
> 标杆示例 `examples/turbofan.html`）。以下是其"产品摄影 + 工程师讲解"标准的落地版，
> 适用于本仓库所有纯代码程序化载具/武器/机械角色（CodeCharacter）。
> 子代理实现新角色时必读，验收时逐条检查。

## 0. 总基调

**「机器是按产品摄影的方式被拍摄、按工程师的方式被讲解的」**：真实比例、真实材质、
干净的工作台、由求解器驱动并且每个数字都经过计算。交付的每一帧都应当已经像一张
真实机器的棚拍照片——不是灰盒，不是占位。

## 1. 动手前先研究（写进文件顶部注释块）

- **真实尺寸（米）**：写出 5–10 个定义轮廓的关键部件真实尺寸。例：涡扇发动机
  风扇直径 1.16 m、全长 4.95 m；MG42 全长 1.22 m、枪管 533 mm……（数据取公开资料近似值，注明）。
- **零件清单（按装配顺序）**：15–40 个命名零件，每个带材质。重复件（叶片、弹链节、
  螺栓）按整组算一个命名零件但要有真实数量。
- **物理（3–6 条真正会计算的方程 + 真实常量）**：例：转速一阶滞后
  `approach(v, target, tau, dt)`（spool-up）、布莱顿循环近似、后坐力冲量、射速周期。
- **主角数字**：观众最在意的那一个（推力 kN / 射速 发每分 / 转速 rpm / 膛压）。
- **可破坏点（可选）**：工程师最担心的失效，及其计算后果。

## 2. 几何：真实实体

- **优先封闭实体**：旋转件用闭合 lathe 剖面（车削感）；壳体用带壁厚的壳；管件封口。
- **绝不悬空、绝不明显穿插**：每个零件都接触支撑它的零件（法兰贴面、轴进轴承、
  支脚落地）。机枪的枪管必须真的穿进机匣，叶片必须真的装进轮盘。
- **细节跟随视线**：法兰加螺栓圈、棱边倒角、面板缝、油管、线束、名牌。
- **机器要有底座**：座架、托架、工作台。飞行器除外（其"底座"是起落架）。
- **预算**：≤ 约 20 万三角面；重复静态件内联合并，运动组保持独立。

## 3. 材质：绝不能只有一种灰

- 钢 / 不锈钢 / 钛 / 铝 / 铸铁 / 黄铜 / 紫铜 / 漆面 / 聚合物 / 橡胶 / 玻璃并排必须可辨。
- 热部件按求解器温度发光（`glow` 通道），别用一个固定自发光糊过去。
- 完成度按"产品摄影"验收：金属读起来是金属，漆面有清漆感，橡胶不发亮。

## 4. 求解器：动画必须由数字驱动

- 写纯函数 `solve(input, state) → 所有屏幕数字`，用真实单位与常量。
- 转速用一阶滞后 `target + (v-target)*exp(-dt/tau)`（松油门后转速惯性下掉）；
  射速对应周期性的枪机往复曲线；后坐力是冲量衰减，不是随手正弦。
- 关键帧烘焙也须物理合理：曲线要能看出"加速—稳定—减速惯性"的层次。
- 数值自检：与公开数据偏差 >20% 就修模型（如 MG42 射速 1100–1200 发/分）。

## 5. 表现

- 高速运动要么真实快（1 秒几十转）、要么降速并注明比例；数字永远真实。
- 分解视图：零件沿装配轴移动，外壳最远、核心不动，途中不互相穿越。
- 热点点击（hotspot:）对应真实操作：开盖、换管、上弹链、拉机柄、点火。

## 6. 验收清单（任一不满足即不合格）

- [ ] 机械师期待的零件缺失（燃烧室没有喷嘴、机枪没有导气箍/照门/抛壳窗）？
- [ ] 有悬空、穿插、可见接缝或缝隙？
- [ ] 该金属的地方像塑料？全机一个灰色？
- [ ] 屏幕/动画里的数字是随手编的而不是求解器算的？
- [ ] 剖面是空壳而不是实心截面？
- [ ] 第一帧不像产品照片？

## 7. 本项目映射（CodeCharacter 契约）

- 参考实现：`src/three/code/j20.ts`（飞机）、`v8Engine.ts`（机械装置）、`tigerTank.ts`（载具）。
- 所有动画节点登记进 `animNodes`，**每条 clip 都对其统一采样**（防残留姿态）。
- `dispose()` 释放全部 geometry / material / texture。
- 热点命名 `hotspot:<ClipName>`；摆放用 `placement`；自发光脉冲用 `glow`。
- clip 名称与 `public/assets/characters/<id>/meta.json` 的 animations 一字不差。

## 8. 截图验收（交付后固定动作）

- 用根目录 `qa.html` 查看器（独立于主程序）多角度截图：
  `qa.html?p=<预置名>`；`window.__qa.focusNode('节点名', 距离, 方位角, 仰角)` 聚焦任意零件；
  `clip=`/`t=` 定格动画时刻；`shot=1` 干净截图。
- 验收项：真实尺寸对表 / 零件完整性 / 接缝与悬空 / 材质区分度 / 动画关键帧 / 与参考照片对照。
- 流程详见 `docs/PROGRESS.md` 第 6 节。

## 9. 反积木红线（密度标准 · 2026-10-18 用户退稿教训）

用户判定："零件数量太少、最小单元太大 = 看起来像乐高"。以下为强制标准，任一不满足即退稿：

1. **最小单元**：剪影级表面不得出现连续无中断的大平面/大盒体——飞行器/载具单块可见边长 ≤ 0.35 m。超限必须切分（板缝）或倒角、附着细节。
2. **曲面优先**：机身/弹体/喷管/油箱等主曲面必须放样 / Lathe / 圆角挤出（≥ 24 径向段），禁止用盒体拼主轮廓。
3. **微倒角**：所有板件棱边倒角 1.5–4 mm（统一用 `bevelBoxGeometry`）。
4. **翼面 = 翼型**：机翼 / 旋翼 / 桨叶 / 尾翼必须 NACA 翼型截面挤出、带尖后缘（`airfoilGeometry`），禁止平板条。
5. **细节密度**：每个大面积区域配板缝网格 + 铆钉列 + 口盖 / 百叶 / 天线 / 把手 / 铰链 / 作动筒 / 线束；飞行器整机命名细节件 ≥ 250 个（静态件可 merge）。
6. **程序化贴图**：大面积涂装必须用 `panelTextures()` 的 map + roughnessMap + bumpMap 三联（板缝 / 铆钉 / 油渍 / 熏黑 / 掉漆）；纯单色大面 = 退稿。
7. **面数预算**：飞行器 / 载具 80k–200k 三角面；武器 40k–120k；机械机构 60k–200k。低于下限视为密度不足。
8. **近距验收**：0.5 m 距离截图不允许出现"未中断大平面 / 锐利 90° 大角 / 单色裸面"。
9. **工具箱**：`src/three/code/detailKit.ts`（bevelBoxGeometry / plateGeometry / airfoilGeometry / louverGeometry / rivetStripGeometry / mergeGeometries / panelTextures / place）——新模型与增密改造必须使用。
