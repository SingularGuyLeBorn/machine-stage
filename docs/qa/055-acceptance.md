# 055 型驱逐舰 · 首轮交付（DDG-1）

## 本轮交付
- 在模型库「舰船」分类新增 **055 型驱逐舰 · 南昌舰**（`type055`），展示 1 单位 = 1 米。
- 主尺度：舰长 180m、舷宽 20m、吃水 6.6m；水线以上舷侧内倾 18%（隐身外形）。
- **112 单元通用垂发**：前甲板 8×8=64 + 后部 8×6=48；井盖/井筒按 112 实例化，配阵列框架/燃气排导/冷发射燃气发生器。
- **346B 四面阵**：4 块阵面（每块 8×8 T/R 模块），一体化隐身桅杆、旋转导航雷达、卫通/ESM。
- **130mm 主炮**：隐身炮塔 + 身管/炮座/甲板下扬弹机 + 130mm 弹药库。
- **近防/导弹**：前后 1130 近防（11 管）+ 红旗-10 发射装置 ×2。
- **反潜**：左右舷各三联装鱼雷发射管 + 舰壳声呐罩/阵列。
- **航空**：双机库 + 直升机甲板（H 标/系留轨道）；直-20 在下一轮补。
- **动力**：4×QC-280 燃气轮机（机匣/压气机级/燃烧室/动力涡轮）+ 并车齿轮箱 + 双轴双桨 + 双舵。
- **上层建筑/内部**：一体化上建、舰桥窗带、烟囱、舰桥与 CIC 显控台、舱室地板、锚/舷侧栏杆/救生筏。
