## 第五轮：按公开数据重做垂发/导弹/动力
- 公开参考与口径见 `docs/qa/055-reference-notes.md`；CC BY 4.0 对照照片见
  `docs/qa/refs/055/`（日本防卫省统合幕僚监部）。
- **垂发**：112 单元（前 64 + 后 48），单元 **850mm × 850mm**、井深 **9m**、冷热共架；
  单元间距 0.95m（0.86m 井口 + 结构框），井筒/发射筒改为**开口圆筒**，
  导弹从井口穿出不会被实体端盖截断；井筒/发射筒/减震环/作动筒/燃气发生器各 112。
- **导弹**：动态井按真实弹种布置——
  - 海红旗-9B：6.5m × 0.5m，冷发射；
  - 鹰击-18：8.0m × 0.5m，热发射（筒内点火）；
  - 鹰击-21：8.8m × 0.82m，冷发射。
  三种弹各有折叠尾翼（筒内收拢）→ 出筒展开；尾焰挂点按弹长自动定位。
- **动力**：4×QC-280（28MW，8.2m 长，9+9 级压气机 + 16 火焰筒 + 4 级动力涡轮），
  左右两个机舱、并车齿轮箱、双轴、5 道轴轴承、艉轴管、双舵；
  五叶可调距螺旋桨半径 2.5m，**桨尖低于水线**（旧版桨叶露出水线的问题已修）。
  烟囱改为低矮内埋式排气口（参考图侧影），不再使用高塔状烟囱。
  机舱为检修剖切状态：机匣上半/侧板拆下放在舷侧，转子/压气机级/燃烧室可见，
  `engine` 状态下 4 台燃机转子与双桨同时转动。
- **门禁**：624 族 / 1756 物理件；悬空 0、孤岛 0、静态未豁免 0；动画扫掠未豁免 0。

## 本轮交付
- 模型库「舰船」分类提供 **055 型驱逐舰 · 南昌舰**（`type055`），1 单位 = 1 米。
- 主尺度：舰长 180m、舷宽 20m、吃水 6.6m；水线以上舷侧内倾 18%，艏部水线以上外飘。
- **舰体线型**：全舰脊弧（艏 +1.55m / 艉 −0.35m）、前倾艏柱、球鼻艏声呐导流罩、
  水线黑色漆带、艏部舷墙、舷号 101（真字形轮廓挤出）、舷窗 ×40。
- **112 单元通用垂发**：前 8×8 + 后 8×6；106 静态井盖 + 6 动态井盖；井筒/发射筒/
  减震环/作动筒/燃气发生器各 112。
- **VLS 冷发射**（`launch` 状态）：井盖翻开 → 导弹冷弹射出筒 → 点火尾焰 → 加速离场。
- **346B 四面阵**：暗色阵面 + 安装框 + 内侧 T/R 组件 ×256；一体化桅杆、桅顶平台/
  横桁/鞭天线/电子战阵面/X 波段阵面、旋转导航雷达、卫通。
- **主炮/近防/反潜**：130mm 隐身炮塔（炮盾/扬弹机/弹药库）、1130 ×2、红旗-10 ×2、
  左右舷三联装鱼雷管、舰壳声呐。
- **航空（本轮重点）**：
  - **直-20 舰载直升机 ×3**：甲板 1 架（旋翼展开，主旋翼/尾旋翼/自动倾斜器/桨夹/
    变距拉杆/起落架/吊放声呐舱/声呐浮标发射器/反潜鱼雷/光电转塔/救援绞车）；
    机库内 2 架（折叠旋翼、收进机库）。
  - **双机库**：实心方块改为可看内部的双机库壳体；卷帘门可升起；
    内部有地板、顶灯、肋骨、工作间、灭火瓶、吊车轨道/小车、机库系留点 ×8。
  - **`aviation` 状态**：双机库门 2.2s 升起，甲板直-20 主旋翼 9.5rad/s、尾旋翼 30rad/s 运转。
- **上层建筑**：前后分面甲板室、舰桥翼台（斜撑/栏杆）、舷窗 ×62、水密门 ×10、
  通风百叶 ×12、烟囱顶盖/排气格栅、救生筏 ×20、锚机/锚链 ×48/系缆桩 ×18/
  系泊绞车/艏艉旗杆/通风筒、RHIB ×2 + 吊艇架。
- **甲板**：安全走道线、垂发危险区黄色虚线、直升机甲板圆盘 + 白圈/H/中线/系留点 ×16。
- **动力/内部**：4×QC-280、并车齿轮箱、双轴双桨双舵；舰桥/CIC 显控台与屏幕、机舱。
- **内部第一人称（本轮重点）**：
  - 舰桥改为**空腔壳体**（前壁留窗洞 + 透明前窗），内部有前显控台/3 块前屏/顶灯/
    12 张座椅；从舰桥可透过前窗看到舰艏。
  - CIC 下移到主船体内，显控台/屏幕/座椅全部在舱内；机舱、机库、弹药库各有固定眼点。
  - 相机动作：航海舰桥 / 战斗情报中心 / 机舱 / 机库 / 弹药库（鼠标拖动环视）。
  - 弹药库改为横向弹架 + 16 发 130mm 炮弹 + 侧壁灯；机库/机舱保持可看内部。
- **零件密度**：**624 个注册零件族 / 1756 个物理件（按实例计）**。
