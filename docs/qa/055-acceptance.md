  井筒 ×112、发射筒 ×112、减震环 ×112、作动筒 ×112、冷发射燃气发生器 ×112。

- **130mm 主炮**：放大隐身炮塔（含炮盾）+ 身管/炮座/甲板下扬弹机 + 130mm 弹药库。
- **近防/导弹**：前后 1130 近防（11 管，带雷达罩）+ 红旗-10 ×2（各 12 管）。
- **反潜**：左右舷三联装鱼雷发射管 + 舰壳声呐罩/阵列。
- **航空**：双机库门、直升机甲板（防滑圆盘 + 白圈/H/中线/系留点 ×16）、牵引轨道、
  左右舷刚性充气艇 + 吊艇架。
- **上层建筑细节**：前后分面甲板室、舰桥翼台（斜撑/栏杆）、舷窗 ×62、水密门 ×10、
  通风百叶 ×12、烟囱顶盖/排气格栅/侧百叶、救生筏 ×20、锚机/锚链 ×48/系缆桩 ×18/

  双轴双桨 + 双舵。
