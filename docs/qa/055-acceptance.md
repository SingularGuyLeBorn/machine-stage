## 第十八轮：055 海面、切角上建与桅座/烟囱支撑（2026-10-25）
### 海面
- `CarrierOcean` 从只服务福建舰扩展为福建舰/055 共用：055 水线按 `T55.WATERLINE = 6.6m`，
  尾流坐标按 180×20m 舰体计算；055 工具条新增「海面」开关。
- 取消单独的「水下」模式：海面开启时 Orbit 相机可直接拖到水面以下，水面自动双面着色、
  深水背景与水下遮罩自动触发，不再需要单独按钮。
- 新增自由视角舰体保护：海面开启时相机若进入舰体 AABB，会沿最近的面推到舷外/水下，
  避免从船壳内部看到空舱/轴隧；关闭海面仍可用于内部检查。

### 轮廓与支撑
- 「一体化上层建筑 / 前部上建连接段 / 烟囱机舱围壁 / 后部上层建筑 / 内埋式烟囱」
  改用 `type055ChamferFrustum` 切角八棱台，恢复可见的斜切棱线。
- 主桅切角基座下新增 **承力筒**（主上建顶 → 基座），补住基座后半段伸出舰桥顶的悬空感。
- 内埋式烟囱 2 从 z=-20 前移到 z=-18，底部落在烟囱围壁顶面内；两只烟囱都新增
  切角基座围圈，消除悬空/台阶感。
- 零件 11,944 → **11,972**（+桅座承力筒、+2 烟囱围圈；不含 055 海面运行时网格）。
