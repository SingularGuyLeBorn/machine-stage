# T-800 右腿 · 屈伸演示存档

单腿屈伸演示的逐帧截图（`npm run dev` → 模型库选「T-800 内骨骼 · 右腿」→ 动作「屈伸演示」）。
每帧都是浏览器实时渲染的 WebGL 画布直出，**不是离线贴图**。

## 帧序与关节状态

| 帧 | 髋 / 膝 / 踝 | 膝主缸露出杆长 | 说明 |
|---|---|---|---|
| `t800-flex-stand.png` | 0.0° / 0.0° / 0.0° | 137.4 mm | 站姿（待机状态，动画不驱动） |
| `t800-flex-00.png` | 0.0° / 0.0° / 0.0° | 137.4 mm | 启动瞬间（零初速） |
| `t800-flex-01.png` | 21.5° / -64.5° / 23.3° | 79.3 mm | 屈伸峰值：膝主缸缩回 58.1mm |
| `t800-flex-02.png` | 21.5° / -64.5° / 23.4° | 79.1 mm | 峰值保持（过冲回弹的驻留段） |
| `t800-flex-03.png` | 21.5° / -64.5° / 23.3° | 79.2 mm | 开始回位 |
| `t800-flex-04.png` | 21.4° / -64.3° / 23.3° | 79.5 mm | 回位中 |

| `t800-flex-07.png` | 21.2° / -63.5° / 23.0° | 80.8 mm | 回位中 |

阻尼曲线是二阶欠阻尼阶跃响应（`t800/motion.ts` 的 `dampedStep`）：
慢启动 → 加速 → 减速 → 过冲约 3% → 回弹，不是匀速插值。

## 关键观察

- **活塞伸缩是几何解**：膝主缸露出杆长从站姿 137.4mm 缩到 79.1mm（58.3mm 行程），
  与膝关节 64.5° 的转角严格对应；没有动画位移写死（见 `registry.test.ts` 的几何断言）。
- **六根缸成对对置**：膝前补偿缸随屈膝伸长、膝后主缸随屈膝缩短；髋屈/伸缸同理。
- 髋 / 膝 / 踝三个转动副均为横向销轴 + 叉耳 + 关节盘 + 衬套 + 卡环的分解装配。

## 复现

```bash
npm run dev          # 模型库 → T-800 内骨骼 · 右腿 → 动作「屈伸演示」
npx tsx scripts/diag-t800.ts --write   # 静态 + 24 帧扫掠穿模 / 悬空 / 液压行程核算
```

数值审计见 `docs/qa/t800-leg-audit.md`。
