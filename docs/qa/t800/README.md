生成方式（无头即可跑，不依赖浏览器窗口）：


## 这组图要证明的三件事

### 一、减壳露机

- **骨段是开放桁架**，不是实心光板：4 根纵向角柱 + 5 道横撑环 + 两端带孔端板
  （`t800/kits.ts` 的 `trussBeam`）。从环与环之间能直接看穿到对侧骨架。
- **六根驱动缸全外露**，缸体挂在骨段外侧，活塞杆是独立零件且**长度随关节角变化**。
- **护板只做局部**：大腿/小腿各一条窄护条（16~24 mm 宽）、膝部前后各一块 58×130 mm 局部护罩。
- **关节机构外露**：叉耳 / 关节盘 / 横向销轴 / 衬套 / 球头销全部是独立零件。

### 二、腿形是 S 曲线，不是直柱

腿的"中心线"靠**骨段本体相对关节连线的 X 偏移**（`BONES.*.bodyX`）做出：

| 段 | 本体偏移 | 效果 |
|---|---|---|
| 股骨（大腿） | **前移 55 mm** | 股四头肌弧度：大腿前缘鼓到 +103 mm |
| 胫骨（小腿） | **后移 35 mm** + 踝驱动缸后置 | 小腿肚后凸：后缘鼓到 −81 mm |
| 膝端板 | 缩到 **70%** | 膝盖比大腿小腿都细（腰） |
| 髋/踝端板 | 保持 **100%/80%** | 腿段之间连得上，不散架 |

从髋到踝，中心线依次是：髋 0 → 大腿 **+55** → 膝 0 → 小腿 **−35** → 踝 0 → 足 **前伸**，
前后起伏成 S（前-后-前）。偏移量由骨段 kit 内部的**双耳连接臂**消化：
端板留在关节连线上（保证插销对准关节中心），本体整体前移/后移。

### 三、腿是"有肉"的：缸体本身就是肌肉

液压缸不再是一根细杆，而是**纺锤形肌肉块**（`segments/cylinder.ts` 的 `muscleProfile`）：

- 缸体外形按正弦鼓胀 `r(t) = rEnd + (rMax − rEnd)·sin(πt)`（两端收细、中间鼓起），
  缸膛仍等径做活塞导向面 —— 外形是肌肉，内里是液压缸。
- 缸径整体放大：髋缸 φ88、膝主缸 φ92、膝前补偿缸 φ80、踝缸 φ88
  （原来 φ42~φ52），腿的横截面因此从"细杆"变成**约 270 mm 宽的肌肉块**。
- 缸块摆到解剖位置：膝主缸的缸体落在**大腿中段**（股四头肌），
  踝驱动缸落在**小腿中段**（腓肠肌），髋缸落在骨盆到大腿之间。
- 于是正视看过去是**六块鼓胀的肌肉块 + 中间一根细骨架**——正是 T-800 内骨骼腿的读法。

## 四、零件是"连着"的：悬空检测按真实表面距离判定

早期版本只看**包围盒间距**，于是"两个盒子挨着、实体却没接上"的零件被误判成有支撑
（髋窝座悬在髋轭里、关节盘插销够不到骨段插座、骨盆框板浮在髋轭上方……全放过去了）。

现在 `scripts/diag-t800.ts` 的悬空判定改成：

1. **AABB 只做粗筛**（间距 ≤ 25 mm 的才算候选对）；
2. **真实表面间距**用 BVH 最近面点量：在 A 的表面采样（包围盒八角 + 顶点 +
   三角面棱中点/重心），对 B 的 BVH 逐点求最近点，**双向各量一次取最小**；
3. 阈值 **3 mm**：设计配合间隙 1~2 mm 算有支撑，超过 3 mm 就是肉眼可见的悬空。

> 为什么必须双向量：只从 A 采样会漏掉「B 的大平面贴在 A 中间」这种接触 ——
> A 是平板时，它的角点离接触区可以差几十毫米。

贴附方案随之统一（`segments/*.ts` 的布局表）：

| 骨面 | 占用 | 贴附件 |
|---|---|---|
| **+Z 面** | 装甲外壳（与骨段同件，z ∈ [34, 39+弓高] mm） | 不挂任何东西（凸台从中穿出） |
| **−Z 面** | 机构面 | 硬管 / 接头 / 管卡 / 软管束 / 侧护条（管卡外径让出 2.5 mm） |
| **±X 面** | 肌肉面 | 活塞杆束 / 加强条 / 护板 / 传感线束 |

所有接触一律留 **2.5 mm 间隙**（不压合、不共面）：压合会在实体里切出薄片，
测穿透深度时射线在片内走很远，会报出 7~15 mm 的假穿透。
