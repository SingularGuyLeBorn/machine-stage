# T-800 右腿 · 侧视存档（减壳露机 + S 曲线腿形）

本目录是 **T-800 内骨骼右腿** 的侧视投影存档：每张图由 `scripts/t800-views.ts`
直接把装配后的真实几何（136 件定义 / 201 实例）投影成平涂侧视图，
**不是离线贴图，也不是手绘示意图** —— 图上每一根管、每一节杆件都来自注册表里的真实零件。

生成方式（无头即可跑，不依赖浏览器窗口）：

```bash
npx tsx scripts/t800-views.ts      # 写出 docs/qa/t800/views/*.png + *.txt
```

## 这组图要证明的两件事

### 一、减壳露机

- **骨段是开放桁架**，不是实心光板：4 根纵向角柱 + 5 道横撑环 + 两端带孔端板
  （`t800/kits.ts` 的 `trussBeam`）。从环与环之间能直接看穿到对侧骨架。
- **六根驱动缸全外露**，缸体挂在骨段外侧，活塞杆是独立零件且**长度随关节角变化**：
  站姿露出 151.1 mm，屈膝峰值缩到 85.8 mm —— 伸缩可见、无遮挡。
- **护板只做局部**：大腿/小腿各一条 20 mm 窄护条、膝部前后各一块 58×130 mm 局部护罩、
  大腿上段一块 20×110 mm 正面护板；没有一块包住整段的壳。
- **管路外露**：硬管 + 黄铜接头 + 管卡沿骨段正面走线，每根管两端都有接头。
- **关节机构外露**：叉耳 / 关节盘 / 横向销轴 / 衬套 / 球头销全部是独立零件。

### 二、腿形是 S 曲线，不是直柱

腿的"中心线"靠**骨段本体相对关节连线的 X 偏移**（`BONES.*.bodyX`）做出：

| 段 | 本体偏移 | 效果 |
|---|---|---|
| 股骨（大腿） | **前移 55 mm** | 股四头肌弧度：大腿前缘鼓到 +103 mm |
| 胫骨（小腿） | **后移 35 mm** + 踝驱动缸后置 | 小腿肚后凸：后缘鼓到 −81 mm |
| 膝端板 | 缩到 **70%** | 膝盖比大腿小腿都细（腰） |
| 髋/踝端板 | 保持 **100%/80%** | 腿段之间连得上，不散架 |

于是从髋到踝，中心线依次是：髋 0 → 大腿 **+55** → 膝 0 → 小腿 **−35** → 踝 0 → 足 **前伸**，
前后起伏成 S（前-后-前）。偏移量由骨段 kit 内部的**双耳连接臂**消化：
端板留在关节连线上（保证插销对准关节中心），本体整体前移/后移。

## 复现

```bash
npm run dev                                             # 模型库 → T-800 内骨骼 · 右腿 → 动作「屈伸演示」
npx tsx scripts/diag-t800.ts --write                    # 静态 + 24 帧扫掠穿模 / 悬空 / 液压行程核算
npx tsx scripts/t800-views.ts                           # 重新生成本目录的侧视存档
```

数值审计见 `docs/qa/t800-leg-audit.md`。
