### 检测器三修 + 交线法深度口径轮（2026-10-19）

背景：口径改成「未豁免报告 = 0」之后，报告本身还在用 probeDepth「顶点落入法」测深度：
面贴合、同心配合面（轴装进孔）根本没有顶点落进对方实体 → 测不出，旧实现拿 **AABB 交叠尺寸兜底**，
于是上文那批数字（`shell↔piston ×8 最深 125.6mm`、304 条 / 75 条 >2mm 深插入）里的深度全是假的。

三修（`src/three/parts/solver/detect.ts`）：

| 修                 | 口径                                                                                                                                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 深度只报真实穿透   | `probeDepth` 采样点落进对方实体后的实测距离；测不出时 `depth_mm = null` + `estimated: true`，**禁止 AABB 交叠尺寸冒充深度**                                                                                                                      |
| 交线几何           | bvhcast 回调累计 `intersectsTriangle` 线段总长与分布包围盒 → `intersection_mm` / `extent_mm`（卡片改显示「交线 XXmm（形态）」）                                                                                                                  |
| 形态分类           | 交线绕轴闭合（含半环鞍座）→ `bearing_overlap`（配合面，白名单候选）；局部成团且实测出深度 → `displaced`（错位真缺陷）；其余 → `face_contact`                                                                                                     |
| 贴合面守门（补丁） | 测不出深度时再加两条：① 交线须来自近共面三角面对（法向 \|cos\| ≥ 0.7 且占交线长度 ≥ 50%）——共面板接触的「交线」其实是侧壁切面与贴合面的交线；② 交线须是三维曲线（`extent` 最小轴 > 0.1mm）——0 间隙面贴合的退化平面交线没有体积穿透证据，一律不报 |

**复核结论（shell↔piston 一族、以及 335 / 156 那批「深插入」）**：交线法下
`crankcase.shell` 与 `piston / block / liner` 等零件对**一条相交线都没有** —— 旧的 125.6mm / 95.3mm /
83.3mm 全是 AABB 交叠尺寸（假数字），不是几何穿透。当前报告只有两类：

1. 螺栓/螺钉埋头座的实体交叠（4.00–7.61mm，构造性接触，已登记豁免）——这部分是真的几何相交；
2. 8 条面贴合/配合面（`depth_mm = null`，交线退化在一个平面上）——经贴合面守门后仍出现，是因为
   默认详细分析预算（1200 对）之外的候选对按「只判相交不测深」保守照报（`estimated`），全部已豁免。

**构造决策（L4-e 起照此办理）**：

1. **两种舱盖状态分开处理**：驾驶 / 无线电员舱盖按「打开 90°」建模（盖板立起、可见内舱与

2. **不给顶盖开孔**：闭合舱盖只需要「盖板 + 隆起 + 铰链 + 锁扣」浮在顶盖上方 3mm，不必在

3. **曲面壁上装门要用曲面件**：炮塔后部圆弧（r 0.94）上直接贴平板，两端会沉进壁里 21.5mm；

  同零件的其他实例也算邻居（履带板靠相邻板成链 / 螺栓圈靠同圈螺栓）。
- 例外：`tags: ["fx"]`（特效件）/ `["floating"]`（飞行件）默认豁免；
  这两个标签写进 `PartDefinition.tags` 的注释，后续装备照此标注。
- 保守性：AABB 距离只会让「实际更远的零件看起来更近」（漏报而不会凭空报）；
  调用前须 `resetNodes()` 到装配态。O(n²) 扫描，虎式 1995 实例 29ms。
- 接入：`diag-clips` 末尾固定打印悬空摘要；`support.test.ts` 覆盖
  「整机 20mm 0 报告」「吊环抬高 250mm → 恰好两个实例级报告」「fx 标签豁免」。

**现状（20mm 阈值）：0 实例 / 0 零件**。已知边界：磁电机距最近缸盖 35.9mm，

### 交互打磨：主炮重量感 / MG34 连射 / 受击分级 / 装填手舱口枪座（2026-10-20）

用户反馈「只有主炮能击发、后坐没劲、机枪是死的」+「防盾连舱盖、枪把悬空」：

**1. 主炮后坐传全车（重量感）**：后坐仍是 450mm，但车体反应从 6mm/0.2° 提到
**26mm 下沉 + 约 1° 点头 + 40Hz 高频颤**，复进段带阻尼回弹；测试断言 t=1.3s 时
`root.position.y < -15mm` 且 `|rotation.z| > 0.01rad`。

**2. MG34 连射（`mg_firing` 状态，10 发 / 3.2s 循环）**：
- 枪座从车长塔移到**装填手舱口环形枪座**（环抱 ⌀400 舱口，朝近防武器管方向留 70° 开口）；
  装填手从舱口探身即可握到枪尾，**防盾载荷链 = 盾 → 悬臂 → 舱口环 → 顶盖**。
- MG34 拆成独立件：机匣 / 枪托 / 握把 / 双联弹鼓 / 枪管 / 供弹链 / 枪口焰 / 弹壳；
  枪管走 `AaBarrel` 短后坐 6mm，枪身走 `AaGun` 枪口上跳（每发 0.0045rad、0.32s 回落），
  弹链走 `AaFeed` 每发一节距 14mm，弹壳 12 枚按重力抛物线 + 顶盖弹跳（fx）。
- 枪托与机匣后榫留 3mm 装配缝、握把离机匣底 3mm、弹鼓离供弹盖 3mm——**不再是 100mm 悬空**。

**3. 受击分级（`hit_light` / `hit_heavy`）**：轻击 26Hz 高频轻颤（<2mm）；
重击 20mm 下沉 + 1° 重挫 + 5Hz 阻尼回弹；测试要求重击响应至少为轻击 5 倍。

**4. 悬空检测盲区结论（枪把为什么以前没报）**：旧版整个 MG34 是**一个合并 part**，
悬空检测按「实例 AABB 到最近实例」判定——接收机/耳轴和枪座接触，整个 part 就算有支撑，
合并件内部 100mm 断开的枪托永远不可见。**修法不是放宽容差，而是拆件**（项目红线：
可动/可拆附件独立 part），并新增回归：把 `aa_mg_stock` 抬高 300mm → 检测报
`tiger.turret.aa_mg_stock`，最近机匣仍距 46mm > 20mm 阈值。以后新装备的合并 kit 仍可能
藏内部空腔件——拆件优先，必要时再做几何岛级检查。

**5. 关闭爆炸视图姿态复位**：原 `StageCanvas` 只在 explode=true 时调 `applyExplode`，
关掉后零件停在半爆炸态。现在每帧都传目标值（true→1 / false→0），爆炸开关可逆。

- 1.6–3.4s **起动机拖动**：曲轴/凸轮/风扇/12 组活塞连杆以 ~165rpm 不均匀压缩脉冲转动，车体抖动逐渐建立，**未点火**（排气只有少量未燃混合气）。
- 3.4s **点火**：转速跳到 260rpm，排气白烟 + 车体一次明显扭动；3.4–5.4s **暖机**；之后 650rpm 怠速。
- 新 `EngineHud`（视口右下）：阶段（预热/起动机拖动/点火/暖机/怠速）+ 水温（冷车 18°C → 点火后指数升温）+ 转速 + 暖机进度条；时间轴与 `tigerEngineRpmAt/tigerCrankAngleAt` 同源。

**2. 加油通道（原几何断在甲板与油箱之间）**
- 油箱顶部原本是实心盖：改为**通孔加油颈**（⌀124/⌀96）。
- 发动机舱盖由实心 box 改为 `hullPlate`，在 x 0.616 / z ±0.802 开两个 **⌀140 加油孔**（战损变体同步开孔）。
- 新增 `tiger.engine.fuel_filler` ×2：立管 ⌀88 + 上法兰 + 穿甲板套筒 ⌀128/⌀100 + 下端软管 ⌀108/⌀80 + 卡箍；上端距甲板盖 2mm，下端套在油箱颈外 3mm。
- 甲板加注口改为**开盖展示**：通孔颈管 + 铰链 + 68° 掀起盖盘 + 提手 + 防丢链；左盖绕 Y 转 180°，两边都向外开。路径：盖 → 甲板孔 → 加注管 → 软管 → 油箱颈。
