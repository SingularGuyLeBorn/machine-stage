### 检测器三修 + 交线法深度口径轮（2026-10-19）

背景：口径改成「未豁免报告 = 0」之后，报告本身还在用 probeDepth「顶点落入法」测深度：
面贴合、同心配合面（轴装进孔）根本没有顶点落进对方实体 → 测不出，旧实现拿 **AABB 交叠尺寸兜底**，
于是上文那批数字（`shell↔piston ×8 最深 125.6mm`、304 条 / 75 条 >2mm 深插入）里的深度全是假的。

三修（`src/three/parts/solver/detect.ts`）：

| 修                 | 口径                                                                                                                                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 深度只报真实穿透   | `probeDepth` 采样点落进对方实体后的实测距离；测不出时 `depth_mm = null` + `estimated: true`，**禁止 AABB 交叠尺寸冒充深度**                                                                                                                      |
| 交线几何           | bvhcast 回调累计 `intersectsTriangle` 线段总长与分布包围盒 → `intersection_mm` / `extent_mm`（卡片改显示「交线 XXmm（形态）」）                                                                                                                  |
| 形态分类           | 交线绕轴闭合（含半环鞍座）→ `bearing_overlap`（配合面，白名单候选）；局部成团且实测出深度 → `displaced`（错位真缺陷）；其余 → `face_contact`                                                                                                     |
| 贴合面守门（补丁） | 测不出深度时再加两条：① 交线须来自近共面三角面对（法向 \|cos\| ≥ 0.7 且占交线长度 ≥ 50%）——共面板接触的「交线」其实是侧壁切面与贴合面的交线；② 交线须是三维曲线（`extent` 最小轴 > 0.1mm）——0 间隙面贴合的退化平面交线没有体积穿透证据，一律不报 |

**复核结论（shell↔piston 一族、以及 335 / 156 那批「深插入」）**：交线法下
`crankcase.shell` 与 `piston / block / liner` 等零件对**一条相交线都没有** —— 旧的 125.6mm / 95.3mm /
83.3mm 全是 AABB 交叠尺寸（假数字），不是几何穿透。当前报告只有两类：

1. 螺栓/螺钉埋头座的实体交叠（4.00–7.61mm，构造性接触，已登记豁免）——这部分是真的几何相交；
2. 8 条面贴合/配合面（`depth_mm = null`，交线退化在一个平面上）——经贴合面守门后仍出现，是因为
   默认详细分析预算（1200 对）之外的候选对按「只判相交不测深」保守照报（`estimated`），全部已豁免。

3. 机油管 R 卡箍：焊道波动让孔必须放到 1.18×r+1mm；唯一放得下的 0.25 处正好卡在罐口（0.4 之后
   被 rib#11 吃光，实测 0.0mm）——位置不成立，**整件撤掉**，不为了凑数留一个假件。

**卡箍孔的两种口径**（都是量出来的）：焊道管表面半径 0.82–1.18 波动 → 孔 = 1.18×r + 1mm；
光滑钢管/罐体 → 孔 = r + 1mm；环带取 40 段（内切 0.9969×孔半径），否则多边形棱会切进罐体顶点
（首轮探针就报了 4 条相交）。收紧块由「平行于管轴的圆管」改成「径向骑在带上的方块」——前者看着
像管旁插了根棒，不像卡箍的锁紧壳。

**单实例不走布局**：装配器只在 `count > 1` 时应用 `instance_layout`（首轮机油管卡箍因此掉在原点，
与曲轴 web 相交 10.99mm 被门禁抓住）。端盖改用 `mate.position/rotation`，卡箍全部 ≥2 实例。

**净隙实测**（装配后按真实实例抽面测距，0 相交）：端盖 ↔ 罐体 0.6mm、↔ 壳体 3.4mm；
水箍 ↔ 水管 1.0mm、↔ 前端板 2.6/2.9mm；空滤箍 ↔ 罐体 1.5mm。

**履带闭环（本轮主战场：报告 1915 → 227，即只剩 L1 白名单族）**——五个根因，全部按几何链修：

1. **走线**：旧版只取主动轮/诱导轮两圆公切线，上段直线直接穿过负重轮（实测 260 条 link↔wheel、
   最深 35mm）。改成「主动轮 + 8 副负重轮 + 诱导轮」的凸包：主动轮弧 → 地线 → 诱导轮弧 →
   与末轮公切线 → 轮顶直线 → 与首轮公切线的反向切线。上段由逐轮圆弧串成（hull 走线）。
2. **节距**：环长必须等于 96 × 130mm = 12.480m。求解 **诱导轮中心 x 0.67 → 0.5995m**
   （环长 12.619 → 12.480m）；负重轮轴距 **0.51 → 0.49m**（0.51 时轴与相邻轮相切、扭杆互相穿；
   并顺带把 `TORSION_PIVOT_Z` 1.16 → 1.1 让摆臂座避开最内侧轮）。
3. **履带板取向**：板是刚体，前后销之间是**弦**。按 s 点切线取向时，弧形段前铰耳会朝圆心偏一个
   弦高（主动轮 5.1mm、诱导轮 6.3mm），销直接切进耳孔（实测 12.30mm）。改为「原点 = 后销、
   +X = 指向下一销的弦」，销↔耳仅剩 0.6mm 弦长差，落在 1.5mm 孔隙内。
4. **主动轮**：齿相位取相邻两销正中（`sprocketToothPhaseOf`）；真实齿顶 0.44 会切穿履带板
   （板内表面在过渡段弦中点低到 0.3777）——齿顶按「不切板」收到 **0.375**，啮合窗孔 + 全高齿
   留给 M-C。铰接耳轴向从 44.5mm 外伸到 115mm 与外板搭接（板体尾端退到 30mm 让开对面舌片
   26mm 半径，搭接块放在齿窗 z 带以外）；`bush()` 的环面改到 XY 平面（轴沿销），否则销从环体穿过。
5. **诱导轮/摆臂**：诱导轮销半径加弦高让量 `IDLER_CHORD_ALLOWANCE 4.2mm`（平板弦中点才不切
   φ600 轮缘）；扭杆座孔径改 `TORSION_R + 6mm`、摆臂根部 30 → 40mm（倒角后 26mm 的根部前脸
   横跨 z=0，与扭杆相交 1.46mm）；固定支座 x 向宽度 0.1 → 0.06m（让开对面扭杆）。

另外：L2 的 `build_order` 由 200–241 改到 **300–341**（校验器里 L2 的区间是 [300,399]）。
