## 一、右腿收尾（按参考图抠到像）

- **颜色**：铬钢银亮金属（不黑）——缸体/骨骼铬钢，关节/轴深色，紧固件
- **大腿**：前侧一根**斜置的粗圆筒液压缸**（从髋斜向下到膝，这是"股四头肌"位）+ 骨骼杆
- **小腿**：后侧**细长活塞杆**（小腿肚位）+ 骨骼
- **膝关节**：齿轮/关节盘（圆形关节结构）
- **结构密集**：多根杆+活塞+关节盘密集排列（参考图那种"机械丛林"感）
- **屈伸运动学**：每缸活塞随关节角度真实行程伸缩（关节转多少度，活塞伸缩多少毫米对得上）+ 阻尼感（慢启动→加速→减速→过冲回弹）

## 二、复制双腿 + 骨盆

- 右腿镜像成左腿（左右对称，注意镜像件法线/朝向）
- **骨盆**：髋臼×2（接大腿球头）+ 骶骨 + 骨盆环（前/后）+ 与脊柱连接座

## 三、脊柱（躯干中枢）

- **脊椎逐节**：颈椎 7 + 胸椎 12 + 腰椎 5 = 24 节（每节独立件：椎体+椎弓+棘突），能逐节弯曲
- **椎间盘×23**（椎节间，弹性）
- **中央主液压柱**：贯穿脊柱的承重主柱（缸体+活塞，弯腰/转身时伸缩）
- **脊柱两侧液压肌**（模拟竖脊肌，左右各一组长缸）

## 四、躯干（胸廓 + 动力）

- **肋骨×24 逐根**（12 对，弧形肋条，实例化）+ 胸骨 + 肋软骨连接
- **肩胛骨×2 + 锁骨×2**（肩带）
- **动力单元**（胸口，可拆）：燃料电池（外壳+电芯×N+接头+控制板）——终结者2 可自拆
- **液压主泵**（躯干内）+ 主蓄能器×2 + 主阀组
- **躯干液压管路网络**（主干 + 分支到各关节，tube 几何，沿骨架走）

## 五、手臂 ×2（每臂零件级）

- **肩**：球窝关节（球头/窝座/保持环/轴承/密封）+ **肩驱动缸×3**（前屈/外展/旋转）
- **上臂**：肱骨（铬钢圆管）+ 肘驱动液压缸（缸体/活塞/活塞杆/耳环/密封逐件）+ 硬管
- **肘**：铰链 + 衬套 + 缸
- **前臂**：尺骨/桡骨双杆 + **旋转机构**（前臂能轴向旋转）+ 腕驱动缸 + 液压腱
- **腕**：多轴节 + 缸
- **手（最复杂）**：掌骨×5 + **五指×三节指骨=15 指骨/手** + 每指液压腱 + 拇指旋转——能握拳/张手/抓握
