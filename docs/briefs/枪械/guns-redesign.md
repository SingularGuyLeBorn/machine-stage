# 枪械线重做 · 超详细设计任务书（7 把枪 · 零件级 · 一个人干）

> **之前的枪械模型全部废掉**——巨差、零件少、不够细。这次按"自动原理递进"重新设计，**零件拆到簧/销/凸榫级**。
> 你是 flash 级模型（没枪械知识）——这份把每把枪的机构原理 + 每个零件都写给你。
> 全程自主别来问。冲突以「真实枪械结构 + 机构正确」为准，记 PROGRESS.md。

## 〇、统一标准（每把枪都按这个，逐条对照）

1. **零件级**：枪机的每个凸榫、击发机构的每个簧、供弹的每个齿——**逐件独立 partId**
2. **射击循环**：完整可演示（击发→自动循环→抛壳→供弹→再击发），运动学正确
3. **弹药零件化**：弹头（被甲+铅芯+钢芯）/弹壳/发射药/底火 独立件，击发分离
4. **爆炸视图**：能拆开看内部机构怎么动
5. **质感层**：烤蓝/磷化/木质 + 磨损（握把磨亮、枪口积碳、机匣划痕）
6. **阻尼感**：机构快但有惯性
7. 零穿模零悬空 / commit 带原因 / tsc·vitest 全绿 / 前端可见（能选能射击能拆）

## 1. 三八大盖（三八式步枪）——栓动，~60 件（先做，立框架）

**机构原理**：手动栓动步枪——打一发，手拉枪栓退壳上弹再打。无自动机构。
特色：长枪管、枪机上有**防尘盖**（"三八大盖"得名）。

零件级拆分：
| 总成 | 零件（逐件） |
|------|------------|
| 枪管 | 枪管（**4 条右旋膛线**，剖视可见）/ 准星 / 表尺（立框式表尺，可竖起）|
| **枪机** | 枪机体 / **拉机柄** / 闭锁凸榫×2 / **击针** / 击针簧 / 保险（枪机尾部保险盖）/ 抽壳钩 / 抛壳挺 |
| **防尘盖** | 枪机上盖的防尘盖（随枪机前后动）——特色件 |
| 弹仓 | 5 发固定弹仓体 / 托弹板 / 托弹簧 / 弹仓底板 |
| 扳机 | 扳机 / 扳机簧 / 阻铁 |
| 木托 | 一体木枪托 / 护木 / 枪颈 / 枪托底板 |
| 弹药 | 6.5×50mm 步枪弹（弹头/弹壳/发射药/底火）×N 实例化 |

**射击循环**：拉机柄上旋（开锁）→ 后拉（抽壳钩抽壳→抛壳挺抛出）→ 前推（推弹入膛）→ 下旋（闭锁凸榫锁住）→ 击针击发。
手动栓动——机构简单，但闭锁凸榫/抽壳/击针每个件都要对。

## 2. 野牛冲锋枪（PP-19 Bizon）——自由枪机 + 螺旋弹筒，~90 件

**机构原理**：**自由枪机**（枪机无闭锁，靠惯性+复进簧顶住，击发后燃气直接推枪机后退）。
**特色：螺旋弹筒**——枪管下方一个圆筒弹匣，子弹**螺旋排列**（64 发大容量）。

零件级拆分：
| 总成 | 零件 |
|------|------|
| 机匣 | 机匣（冲压）/ 机匣盖 / 拉机柄 |
| **枪机** | 自由枪机（枪机体/击针/抽壳钩）/ 复进簧 / 复进簧导杆 |
| **螺旋弹筒**（招牌） | 弹筒外壳 / **螺旋导轨**（子弹沿螺旋排列）/ 托弹机构 / 弹筒口部供弹口 / 弹筒前盖（可开装填）|
| 击发 | 击锤 / 击锤簧 / 扳机 / 快慢机（单发/连发/保险）|
| 枪管 | 枪管 / 枪口 |
| 木/塑件 | 握把 / 护木 / 折叠枪托 |
| 弹药 | 9×18mm 手枪弹 ×N |

**射击循环**：击发→燃气推自由枪机后退→抽壳抛壳→复进→弹筒旋转供下一发→再击发。
**螺旋弹筒旋转供弹是招牌**——弹筒里子弹螺旋排列，射击时弹筒旋转逐发供弹。

## 3. AK-47——导气式 + 回转闭锁，~120 件

**机构原理**：**导气式**（燃气从枪管导气孔泄出推活塞）+ **枪机回转闭锁**（枪机头旋转锁住枪膛）。

零件级拆分：
| 总成 | 零件 |
|------|------|
| 机匣 | 冲压机匣（左/右板 + **铆钉族实例化**）/ 机匣盖 / 弹匣卡榫 / 拉机柄 |
| 枪管 | 枪管（膛线）/ 枪口制退器 / 准星座 / 导气箍 |
| **导气系统** | 导气箍 + **活塞 + 活塞杆**（燃气推活塞——核心）+ 导气管 + 导气塞 |
| **枪机** | **枪机框** + **枪机头（回转闭锁，闭锁凸榫×2）** + 击针 + 抽壳钩 + 抛壳挺 + 击针簧 |
| **击发机构** | 击锤 + 击锤簧 + 击锤导杆 + 扳机 + 阻铁 + **快慢机（保险/单发/连发三档）** |
| 复进 | 复进簧 + 复进簧导杆（双节） |
| **弹匣** | 30 发弧形弹匣（弹匣体 + **托弹板 + 托弹簧** + 底板 + 抱弹口）|
| 木件 | 护木 / 握把 / 枪托（木质纹理）|
| 附件 | 通条（枪管下）/ 刺刀座 |
| 弹药 | 7.62×39 中间威力弹 ×30 |

**射击循环**：击发→弹头过导气孔→燃气推活塞→活塞杆推枪机框→枪机框带动枪机头**旋转开锁**→后退抽壳→抛壳→复进簧推回→推弹上膛→旋转闭锁→待击。

弹链供弹 + 快拆枪管是特色。

## 7. 加特林 M134——转管，~300 件（最难，压轴）

**机构原理**：**6 根枪管绕中心轴旋转** + **外接电机驱动**（不靠火药燃气，电机驱动旋转）。
旋转中每管依次：装填→闭锁→击发→抽壳→抛壳。射速极高（每分钟数千发）。

零件级拆分：
| 总成 | 零件 |
|------|------|
| **枪管束** | **6 根枪管**（实例化，绕中心轴）/ 枪管箍（前后）/ 旋转机匣 |
| **每管枪机** | **6 套独立枪机**（枪机体/击针/抽壳钩——旋转中依次动作）|
| **驱动** | **驱动电机** + 减速齿轮组（齿轮×N）+ 传动轴 |
| 供弹 | 供弹机 / 弹链 / 弹链箱 / 无链供弹系统 |
| 旋转机构 | 中心轴 / 轴承 / 旋转凸轮（控制枪机动作）/ 离合器 |
| 机架 | 机架 / 握把 / 电击发按钮 |
| 弹药 | 7.62×51 ×N |

**射击循环**：电机驱动枪管束旋转→每管转到装填位装弹→转到击发位击发→转到抛壳位抛壳→**6 管轮流，超高射速**+弹壳瀑布式抛出。
**转管是皇冠**——6 管旋转 + 每管独立枪机依次击发，做对了枪械线封神。

## 顺序与验收

三八大盖 → 野牛 → AK-47 → RPK → M60 → M2HB → 加特林。每把一个 commit 闭环。

**验收（每把枪）**：
- [ ] 零件数达标（见上表），机构拆到簧/销/凸榫级
- [ ] 射击循环正确（栓动/自由枪机/导气/短后坐/转管——各原理对）
- [ ] 子弹零件化 + 抛壳堆积 + 后坐 + 枪口焰
- [ ] 特色机构做出来（防尘盖/螺旋弹筒/回转闭锁/弹鼓/弹链/加速子/转管）
- [ ] 爆炸视图能拆看内部机构；零穿模零悬空；tsc·vitest 全绿；commit 带原因

## 警告

**别再糊弄**——零件数要达标，机构要拆到簧/销/凸榫级。
用户要看"这把枪怎么打响的"——枪机怎么闭锁、击锤怎么打击针、弹链怎么步进、活塞怎么被燃气推。
机构对了、零件够了，才配叫枪械模型。
