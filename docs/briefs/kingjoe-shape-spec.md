## 三、表面与质感

- **颜色**：哑光金属灰（基础色 #9a9da0 灰，**不是亮镜面银**）
- **分体接缝**：腹/胸/腿各段之间**环状接缝**（深 0.005 的凹槽——分体感）
- **彩虹发光胸**：两块格栅（格栅孔 + 背后彩虹色发光，红橙黄绿青渐变）
- 少量铆接点/突起细节（别太多——金古桥表面相对光整）
- 关节/缝隙深色

## 四、外形生成提示（怎么做出鼓形）

- **鼓形段（腹/胸）**：用 **lathe（车削）**——轮廓线沿 y 轴：两端直径小、中间鼓出（半径 = f(y)，中段最大）
- **圆筒（腿/臂）**：cylinderGeometry（上下等径）
- **鼓的程度**：中段直径 / 端部直径 ≈ 1.3-1.4（鼓但不夸张）
- **分体接缝**：在两段之间留一道环状凹槽

## 五、顺序

1. **先只做整体比例轮廓**（各段鼓形摆对位置——一眼是金古桥的敦实）
2. 再逐部件抠外形细节（脚分块/膝球/彩虹胸/天线）
3. 表面质感（哑光灰 + 接缝 + 发光胸）
4. **机构后置**：分离合体机构（之前做对的）在外形定稿后套回来
