# 导弹家族 · 设计任务书（零件级 · 导弹线）

> 自主别来问。冲突以「真实 + 工程自洽」为准，记 PROGRESS.md。
> 导弹家族是"弹药零件化"的放大——每型导弹都是：导引头 + 战斗部 + 发动机 + 舵面 + 弹翼 + 弹体。
> 参考真实导弹结构（公开外形/剖视）。

## 〇、导弹的通用结构（所有导弹的"零件骨架"）

```
导引头（寻的：红外/雷达/激光）→ 战斗部（杀伤：破片/破甲/装药）→ 控制舱（制导计算机+舵机）
 → 发动机（固体火箭：药柱+喷管 / 或涡喷）→ 舵面+弹翼（气动控制）→ 弹体结构（舱段）
```
**每型导弹都按这个骨架零件化**，差别在导引头/战斗部/弹道。

## 一、各型导弹（按用途，零件级）

### 1. 火箭弹（PHL-191 远火）
- 无/简易制导；火箭发动机 + 战斗部（杀爆/子母）+ 尾翼；发射箱（远火发射车）；面覆盖

### 2. 高超音速导弹（两大流派）
- **东风-17（乘波体滑翔）**：助推火箭 + **乘波体滑翔器**（扁平楔形，滑翔机动）——助推分离后乘波体高超音速滑翔
- **DF-21D / DF-26（双锥体机动）**：双锥体再入弹头（机动再入）——反舰弹道

### 3. 空空导弹
- **PL-15**（中距）：主动雷达导引头 + 双向数据链 + 双脉冲发动机（远程）
- **PL-10**（格斗）：红外成像导引头 + 推力矢量（大离轴格斗）

### 4. 空对地导弹
- 空地导弹（精确制导炸弹/空地导弹）：激光/卫星导引 + 侵彻/杀爆战斗部

### 5. 地对空（防空导弹）
- **红旗-9 / 海红旗**：主动雷达导引 + 垂直发射 + 大机动舵面——拦截飞机/导弹

### 6. 地对地
- **弹道导弹**（DF 系列）：助推→再入；**巡航导弹**（长剑）：涡喷+地形匹配低空巡航

### 7. 鹰击-21（高超音速反舰——"航母杀手"）
- **舰载/空射高超音速反舰导弹**：助推 + 双锥体/乘波体滑翔弹头 + 末段机动突防
- 打航母的——**和 055 的 VLS、航母战斗群联动**（矛与盾）

## 二、发射 + 制导 + 命中（每型可演示）

- **发射**：垂直发射（热/冷弹射）/ 倾斜发射 / 空投 / 车载发射——发射动画（点火/出筒/转向）
- **制导**：导引头锁定（红外/雷达/激光）+ 舵面机动 + 弹道（高抛/巡航/滑翔）
- **命中**：战斗部起爆（破片/破甲金属射流/装药冲击波）+ 命中特效
