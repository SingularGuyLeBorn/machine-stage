# 055 垂直发射系统（VLS）· 超详细零件级（055 的灵魂）

> 055 的**灵魂**——112 个通用垂直发射单元（前 64 + 后 48）。
> **冷热共架**：同一发射井兼容热发射（海红旗防空）和冷发射（鹰击-21 等大型弹）。
> 参考真实 VLS（MK41 / 055 通用垂发）。

## 〇、工作原理（先吃透冷热两式）

VLS = 导弹垂直存放在甲板下的发射井阵列，发射时垂直升空。

### 热发射（海红旗防空等）
```
发射井盖打开 → 导弹在井内【点火】→ 发动机燃气经【燃气排导管】排出（排焰）
 → 导弹冲出井口 → 升空转向
```

### 冷发射（鹰击-21 等大型弹）
```
发射井盖打开 →【燃气发生器】点火产生高压燃气 → 把导弹【弹射出井】（弹本身没点火）
 → 导弹离井到安全高度 → 导弹【空中点火】→ 爬升
```
冷热共架：同一井既能热发射又能冷发射（通用性——弹种灵活）。

## 二、机构运动/交互动画

### 热发射流程（海红旗）
井盖开 → 导弹井内点火 → 燃气经排导管排出（排焰）→ 导弹冲出井口 → 升空 → 相控阵引导拦截

### 冷发射流程（鹰击-21）
井盖开 → 燃气发生器点火 → 导弹被弹射出井（弹没点火）→ 离井到安全高度 → 空中点火 → 爬升 → 高超音速滑翔/机动

- **发射井阵列**：前 64 + 后 48 排布
- **连续发射**：多单元依次发射（防空拦截扇面/反舰齐射）
- **冷热共架**：两种发射方式都演示

## 三、受击/质感

- 受击：VLS 中弹（**弹药殉爆风险**——井内导弹殉爆）/ 井盖损坏卡死
- 质感：甲板垂发口盖阵列 / 井筒金属 / 发射焰熏黑 / 井盖开合机构
