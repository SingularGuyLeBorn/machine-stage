# 055 全燃联合动力（COGAG）· 超详细零件级

> 055 用**全燃联合动力（COGAG）**：4 台燃气轮机，双轴双桨。
> COGAG = Combined Gas turbine And Gas turbine——多台燃气轮机联合（巡航部分机工作、高速全部并联）。
> 参考真实 COGAG 动力结构。

## 〇、COGAG 工作原理（先懂）

```
4 台燃气轮机（QC-280 级）
 → 巡航：部分燃气轮机工作（省油）
 → 高速：全部燃气轮机【并车】（并联输出）→ 大功率
 → 经【并车齿轮箱/减速齿轮】→ 双轴 → 双螺旋桨
```
关键：多台燃气轮机通过**并车齿轮箱**联合驱动——灵活（巡航空部分机、高速全并联）。

## 一、零件级拆分（~250 件，逐件）

### 1. 燃气轮机×4（QC-280 级）

## 二、机构运动/交互动画

- **COGAG 并车**：巡航（部分燃气轮机工作）→ 高速（全部并车）——**并车/解车演示**（离合器合/脱）
- **加速/减速**：燃气轮机转速→推力（阻尼感——热惯性）
- **双桨差速转向**：左右桨差速 → 转向
- **可调螺距**：调距桨变螺距（进退车不用反转主机）
- **剖视**：燃气轮机 + 并车齿轮箱 + 轴系内部

## 三、受击/质感

- 受击：燃气轮机损伤 / 轴系断裂 / 舵机失效
- 质感：机舱金属 / 燃气轮机排气熏黑 / 轴系
