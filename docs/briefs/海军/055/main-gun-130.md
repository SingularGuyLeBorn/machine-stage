# 055 主炮（H/PJ-45 型 130mm 舰炮）· 超详细零件级

> 055 舰艏的 130mm 单管舰炮——对海/对陆/对空射击。
> 舰炮 = 炮塔（身管+俯仰）+ 旋回架 + **甲板下供弹系统**（弹药库→扬弹机→炮塔）。
> 参考真实 130mm 舰炮结构。

## 〇、工作原理（先懂）

舰炮是个"自动装填的火炮"：
```
弹药库（甲板下）→【扬弹机】垂直提升炮弹 →【扬弹筒】→ 炮塔内【装填机构】装弹入膛
 → 炮闩闭锁 → 击发 → 后坐（复进/制退）→ 抛壳/退壳 → 下一发
炮塔：旋回（方向）+ 身管俯仰（高低）——火控随动
```

## 二、机构运动/交互动画

- **射击循环**：扬弹机供弹 → 装填入膛 → 关闩 → 击发 → 后坐（复进/制退）→ 退壳 → 下一发（自动装填，高射速）
- **俯仰/旋回**：炮塔转动 + 身管俯仰（火控随动——**阻尼感**：炮塔转动有惯性）
- **对海/对陆/对空**射击演示

## 三、受击/质感

- 受击：炮塔中弹 / 身管损伤 / 供弹卡壳
- 质感：炮塔隐身外形 / 身管烤蓝 / 炮口焰
