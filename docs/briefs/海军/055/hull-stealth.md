# 055 隐身舰体 · 超详细零件级（拆到每块板/每道舱壁）

> 055 舰体——**隐身外形**（内倾舷侧 + 一体化上层建筑）+ 全通甲板。万吨舰体。
> 舰体不是"一个壳"——是分段建造 + 肋骨框架 + 外板 + 舱壁 + 上层建筑，拆到每块板每道舱壁。

## 〇、舰体结构逻辑（先懂）

舰体 = **龙骨（脊柱）+ 肋骨框架（横向肋骨+纵向桁）+ 外板（蒙皮）+ 舱壁（分隔）+ 甲板（分层）**，分段建造。
055 隐身特色：**内倾舷侧**（雷达波反射偏转）+ **一体化上层建筑**（减少直角反射）。
