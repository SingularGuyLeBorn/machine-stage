# 055 型驱逐舰 · 设计文档（子系统分册）

> 055 万吨大驱，航母战斗群"带刀侍卫"。**灵魂是 112 个通用垂直发射单元（VLS）+ 346B 中华神盾雷达**。

1. 舰体 + 动力（立住舰）
2. **VLS（灵魂）**——112 单元 + 冷热共架 + 各型导弹
3. 346B 相控阵 + 一体化桅杆
4. 主炮/近防/鱼雷/直升机
5. 作战系统联动
