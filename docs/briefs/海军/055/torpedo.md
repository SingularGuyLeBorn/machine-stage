# 055 鱼雷发射 + 反潜系统 · 超详细零件级

> 055 反潜：舰壳声呐 + 拖曳声呐 → 发现潜艇 → **反潜鱼雷**（发射管发射）或 **直-20 投放反潜鱼雷**。
> 鱼雷是"水下导弹"——有导引头/战斗部/推进/控制。

## 〇、反潜体系（先懂）

```
探测：舰壳声呐（舰艏）+ 拖曳线列阵声呐（舰艉拖曳）→ 发现潜艇方位
打击：【反潜鱼雷】发射管发射（或直-20空投）
 → 鱼雷入水 →【泵喷推进】→【声呐导引头】主动/被动寻的 → 命中潜艇
```

## 一、零件级拆分（~180 件，逐件）

### 1. 鱼雷发射管（舷侧三联装）
| 零件 | 说明 |
|------|------|
| **三联装鱼雷发射管×2** | 舷侧三联装发射管（左右舷各一）|
| 发射管盖 | 管口盖（防水，发射时开）|
| **发射机构** | 发射（压缩空气/火药——把鱼雷推出）|
| 装填机构 | 鱼雷装填（再装填）|

### 2. 反潜鱼雷（零件级——鱼雷是"水下导弹"）
| 零件 | 说明 |
|------|------|
| **声呐导引头** | 鱼雷头部声呐（主动/被动寻的潜艇）|
| **战斗部** | 鱼雷战斗部（装药——水下爆炸）|
| **推进** | **泵喷推进器**（泵喷——安静推进）或 螺旋桨 + 电池/热动力（发动机）|
| **控制舱** | 鱼雷制导计算机 + 舵（方向舵/升降舵）|
| 导线 | 线导（鱼雷和舰的导线——线导修正）|
| 雷体 | 鱼雷壳体（舱段）|

### 3. 声呐系统
| 零件 | 说明 |
|------|------|
| **舰壳声呐** | 舰艏球鼻艏内的声呐阵（主动/被动）|
| **拖曳声呐** | 舰艉拖曳线列阵（长缆+阵，可收放）+ 收放机构 |
| 声呐机柜 | 声呐信号处理 |

### 4. 反潜指挥
- 反潜火控 / 显控台 / 鱼雷发射控制

## 二、机构运动/交互动画

- **鱼雷发射**：发射管盖开 → 鱼雷被推出（入水）→ 泵喷推进 → 声呐导引头寻的 → 命中潜艇
- **拖曳声呐**：拖曳线列阵放出/收回（收放机构）
- **声呐探测**：声呐波（水下探测可视化）
- **直-20 反潜**：直升机投放反潜鱼雷（配合 helicopter.md）

## 三、受击/质感

- 受击：发射管损坏 / 鱼雷殉爆
- 质感：发射管金属 / 鱼雷 / 声呐罩
