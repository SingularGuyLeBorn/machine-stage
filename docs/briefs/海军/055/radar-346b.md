# 055 雷达系统（346B 相控阵 + 一体化桅杆）· 超详细零件级

> 055 的"中华神盾"——346B 型相控阵雷达（四面阵）+ **一体化桅杆/综合射频**（多波段天线集成在一根桅杆）。
> 综合射频一体化是 055 比 052D 先进的关键（雷达/电子战/通信集成，隐身外形）。

## 〇、055 雷达的特色（先懂）

- **S 波段相控阵**（四面阵，远程对空搜索）+ **X 波段**（精确跟踪/火控）
- **一体化桅杆/综合射频**：雷达/电子战/通信天线集成在一根桅杆里（不是一堆分散天线）——隐身 + 集成
- 相控阵原理：电子扫描不转动（见 carrier/radar-phased-array.md）

## 二、机构运动/交互

- **电子扫描**：相控阵不转动，波束电控（多目标跟踪）
- **综合射频**：雷达/电子战/通信共用孔径——资源调度演示
- **火控引导**：搜索 → 跟踪 → 引导海红旗/鹰击-21（火控链）
- 一体化桅杆（集成天线的隐身外形）

## 三、受击/质感

- 受击：阵面中弹（T/R 单元失效）/ 桅杆受损
- 质感：阵面罩复合材料 / 桅杆隐身外形 / 舰桥
