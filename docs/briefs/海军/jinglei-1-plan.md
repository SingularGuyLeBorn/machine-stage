# 惊雷-1（JL-1）空射高超音速导弹 · 设计任务书（零件级）

> 自主别来问。冲突以「真实 + 工程自洽」为准，记 PROGRESS.md。
> 惊雷-1：2025 年九三阅兵首次亮相的**空射高超音速弹道导弹**（世界首款空射高超音速远程导弹）。
> 轰-6N 轰炸机携带 → 高空投放点火 → 助推 → 双锥体机动再入。核常兼备，射程约 8000 公里。

## 〇、背景

JL-1 特色：**空射**（轰炸机带到高空投放，借飞机速度和高度）+ **高超音速**（双锥体机动再入）+ **核常兼备**。
弹体特征：细长弹体 + **双锥体头部** + **头体分离后 4 片三角形控制面**（机动再入）。

## 二、发射 + 飞行（空射高超音速——特色）

```
轰-6N 携带 JL-1 高空巡航 → 投放（导弹离机下落）
 → 点火（空中点火助推）→ 助推爬升（出大气层）
 → 级间分离 → 头体分离（双锥体弹头 + 4 控制面）
 → 双锥体机动再入（高超音速滑翔+机动）→ 命中
```
- **空射投放**：轰炸机机腹挂架 → 投放 → 空中点火（不是地面发射）
- **双锥体机动再入**：头体分离后，双锥体弹头 + 4 控制面高超音速机动（突防）
- 弹道：投放→助推→滑翔机动
