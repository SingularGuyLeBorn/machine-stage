# 航母舰体结构 · 超详细零件级 + 细化（5 维度）

> 航母舰体——海上移动城市。分段建造 + 水密分舱 + 多层甲板。
> 本版按《细化规范》细化：零件再拆 + 数值时序 + 参考 + 分镜 + 剖视。

## 维度 1：零件再往下拆（拆到肋骨/板/梁级）

| 层级 | 零件 |
|------|------|
| 主承力 | **龙骨**（平板龙骨+龙骨翼板）/ **肋骨×N**（每档：肋板+横梁+强肋骨，实例化）/ **纵桁×N** |
| 舰体分段 | **分段×N**（每段：外板+内部骨架+平台，实例化，分段接缝）|
| 外板 | 每块外板（板厚分区——舷侧厚、甲板厚）+ **焊缝**（分段/板间焊缝）|
| 水密舱壁 | **横向水密舱壁×N**（舱壁板+扶强材）+ **水密门×N**（门+铰链+压紧装置）|
| 甲板 | 飞行甲板（**装甲/加强板**，承受着舰冲击）+ 机库甲板 + 内部各层甲板×N + 甲板梁 |
| 舱室 | 机舱/弹药库/油库/住舱/医院/配电舱（各舱壁+设备）|

## 维度 2：数值/时序

- 舰体尺寸（福建舰级：~320m 长 × ~78m 宽飞行甲板）；分段数；水密舱数
- 下水/总装时序（分段合拢）

## 维度 4：交互分镜

```
镜头1（全景）：舰体（分段建造——分段清晰可见）
镜头2（剖视特写）：剖开看内部（多层甲板+水密舱壁+机库/机舱）
镜头3（特写·水密门）：水密门开闭（损管）
镜头4（特写·分段接缝）：分段建造的接缝/焊缝
节奏：整体 → 剖视内部 → 细节（分段/水密）
```

## 维度 5：剖视（内部结构）

- **舰体纵剖**：多层甲板 + 机库 + 机舱 + 弹药库（内部分层）
- **横剖**：水密舱壁 + 双层底 + 舷侧
- **分段剖视**：分段建造的接缝
