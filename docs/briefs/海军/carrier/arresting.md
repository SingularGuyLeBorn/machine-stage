# 航母拦阻装置（Arresting Gear）· 超详细零件级 + 细化（5 维度）

> 拦阻装置——舰载机着舰时用拦阻索拉住，~100m 内把 ~20 吨、~240km/h 飞机拉停。
> 本版按《细化规范》细化：零件再拆 + 数值时序 + 参考 + 分镜 + 剖视。

---

## 维度 1：零件再往下拆

### 拦阻索系统 → 拆到索/弹簧片级
| 层级 | 零件 |
|------|------|
| 拦阻索×4 | 每道索：**钢索**（多股钢丝绳）+ 索端连接 + **支撑弹簧片**（弓形片，把索抬离甲板 ~10cm）|
| 弹簧片 → | 弹簧片（可压平/回弹）+ 固定座 |

### 拦阻机（甲板下，能量吸收核心）→ 拆到液压件级
| 层级 | 零件 |
|------|------|
| 液压拦阻机 | **液压缸**（缸体+活塞+活塞杆）+ **可调节流阀**（阻尼调节核心）+ 蓄能器 + 滑轮组 |
| 节流阀 → | 阀体 + 阀芯（可调——按飞机重量/速度调阻尼）+ 作动 |
| 滑轮组 → | 滑轮×N（导向索）+ 滑轮轴 |
| （福特 AAG）涡轮能量回收 → | 涡轮 + 电机（能量回收）|

### 拦阻网（应急）
| 层级 | 零件 |
|------|------|
| 拦阻网 | 网 + 网支柱（可升降）+ 升降机构 |

## 维度 2：数值/时序（拦阻的精确过程）

```
拦阻时序（着舰）：
t=0     尾钩触舰面（钩索前）
t=0.1s  尾钩钩住拦阻索
t=0.2s  索开始被拉出（拦阻机阻尼加载）
t=0.2~2s  索持续拉出（阻尼减速——飞机从 240km/h 急剧减速）
t≈2s    飞机停住（~100m）
t=2.5s  尾钩脱索 → 拦阻索复位（回收）
```
- **阻尼曲线**：索被拉出时，拦阻机提供**可控阻尼**（先大后小——初始大冲击吸收，后段平稳减速）
- **钩空复飞**：尾钩没钩住索 → 飞机开加力复飞（复飞率——真实着舰有概率钩空）
- 拦阻索拉出长度 ~100m；阻尼按飞机重量/速度调

## 维度 4：交互分镜（拦阻降落的镜头脚本）

```
镜头1（全景）：舰载机进近（助降透镜引导，尾钩放下）
镜头2（特写·尾钩）：尾钩着舰钩索瞬间（钩住/钩空）
镜头3（特写·拦阻索）：索被飞机拖出（甲板下拦阻机阻尼）
镜头4（特写·飞机）：飞机急剧减速（点头+前冲被拉住）
镜头5（全景）：飞机停住 → 脱索 → 拦阻索复位
（分支：钩空 → 复飞拉起）
节奏：进近（稳）→ 钩索（瞬间）→ 减速（急剧）→ 停（稳）
```
