# 弹药升降机（Ammunition Elevator）· 超详细零件级 + 细化（5 维度）

> 弹药库→机库/甲板的弹药垂直提升。本版按《细化规范》细化。

## 维度 1：零件再往下拆

| 层级 | 零件 |
|------|------|
| 平台 | 升降平台 + 活动护栏 + 防滑导静电面 + 到位锁定 |
| 井道 | 升降井道 + 导轨×N + 导向轮 + 防火分隔 |
| 驱动 | **液压缸×N**（逐件）或 卷扬（卷筒+钢丝绳+滑轮+电机）+ 配重 + 制动器 |
| 门系统 | 各层**防火门** + 门锁 + **联动联锁**（平台不到位门不开）|
| 安全 | 防爆电气 + 防静电 + 消防喷淋 + 应急制动 |
| 弹药车 | 弹药运输车 + 固定装置 |
