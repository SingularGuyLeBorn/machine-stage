# 航母返工 Goal（福建舰）——做到"像真航母"（详细版）

> 目标：把 machine-stage 的航母（福建舰）从"渔船/驳船 + 玩具感"做到"像真航母"——外形对、舰载机对、细节真、金属感、不像玩具。
> 每条完成标准都写了**具体做什么 + 参考什么 + 怎么验**。

---

## 一、外形对照福建舰真图（最高优先——外形错了全错）

现在是"长方形浮筒 + 堆方块"（渔船/驳船）。照福建舰真图重做外形：
- **舰艏**：前倾/斜切（不是垂直方形）+ 水线下球鼻艏 + 舰艏回收角（山羊角长条 + 尼龙网）
- **舰体**：舰艏→舯→舰艉的形状变化，舷侧外飘（飞行甲板宽于舰体）
- **斜角甲板**：降落区位于左舷侧，与首尾中心线夹角 **6°~14°**（福建舰 ~9.5°），长 220-270m；直通起飞区在舰前部（长 70-100m，装弹射器）
- **舰岛**：一体化、内倾收分、隐身外形（小舰岛）——相控阵雷达面板**嵌入**（不是贴方格板）、一体化桅杆、卫通天线罩别太大太突兀
- **参考**：`docs/briefs/海军/carrier/外形与甲板依据.md`（文字依据）+ 福建舰真图
- **验**：俯视 + 侧面轮廓和福建舰真图一致（改前/改后对比截图）

## 二、无悬空（近防炮/卫通天线罩等）

- 现在近防炮、卫通天线罩看着悬空——**修**（每零件有支撑/连接）
- 悬空检测（support.ts）零报告
- **验**：悬空检测零报告 + 隔离视图截图（近防炮/天线罩与舰岛的连接）

## 三、舰载机用歼-20（学习 j20.ts，别自写简化模型）

- 参考 **`D:\FunnyProjects\fight-stage\src\three\code\j20.ts`**（歼-20，4875 行零件级：座舱内装/DSI 进气道/鸭翼/垂尾/铆钉列/尺寸都有）
- 舰载机在 j20 结构基础上 + **舰载化**（折叠机翼 + 尾钩 + 加强起落架 + 弹射牵引钩——见 `carrier/aircraft.md`）
- 别做简化模型——参考 j20.ts 的零件级
- **验**：舰载机零件级（座舱/进气道/气动面/折叠翼/尾钩），对照 j20.ts

## 四、金属感材质（告别塑料感）

按 `docs/briefs/系统/金属感材质.md`：
- 金属件 `metalness=1.0` + **HDRI 环境反射**（`scene.environment`，Poly Haven/ambientCG 免费 HDRI）
- 金属贴图：拉丝（anisotropy）/划痕/锈蚀/金属板
- **验**：塑料感 vs 金属感对比截图（一眼金属）

## 五、反光亮度合理

- 舰岛顶棚/金属件反光太刺眼——调整 roughness/envMapIntensity，别那么刺眼
- **验**：反光不刺眼（观感正常）

## 六、零件数明显增加（别像玩具）

现在零件少→像玩具。加细节加零件：
- 雷达（旋转雷达 + 相控阵 T/R 单元阵列）
- 菲涅尔透镜助降器（"肉丸"——透镜+灯光）
- 挡焰板/拦阻索/系留点/甲板设施细节
- **验**：零件数明显涨 + 细节特写截图（雷达/菲涅尔透镜）

## 七、跑道标线画对（斜角甲板保持，标线画对）

- 斜角甲板保持（斜置是特征）
- 但**标线要画对**：跑道中线/虚线**平行跑道走向、前后对齐**——不虚线画歪/前后错位
- **验**：甲板标线截图（虚线平行跑道、前后对齐）

## 八、零件树默认展开一层（UI）

- 左下角零件树默认展开第一层
- **验**：打开默认展开一层

## 九、真实感（航母在海里）

- **水线/吃水线**（舰体水上水下分界）
- **水下舰体**（球鼻艏/螺旋桨/舵——剖开/透明水可见）
- **航行尾流**（舰艏浪花 + 舰艉尾流）
- **相控阵雷达面板细节**（T/R 单元阵列，不是光板）
- **甲板使用痕迹**（轮胎磨痕/油污/系留点/挡焰板磨损）
- **验**：水线/尾流/水下舰体 + 雷达细节 + 甲板痕迹截图
