# 航母返工 Goal（福建舰）——做到"像真航母"

> 目标：把 machine-stage 的航母（福建舰）从"渔船/驳船 + 玩具感"做到"像真航母"——外形对、舰载机对、细节真、金属感、不像玩具。

## 完成标准（可验证）

1. **外形对照福建舰真图**：舰艏前倾 + 斜角甲板 6-14° + 外飘 + 一体化舰岛（俯视/侧面轮廓一致）
2. **无悬空**：近防炮/卫通天线罩等，悬空检测零报告
3. **舰载机用 `fight-stage/src/three/code/j20.ts`** 的歼-20 零件级结构 + 舰载化（折叠翼/尾钩/加强起落架）
4. **金属感材质**（按 `docs/briefs/系统/金属感材质.md`）：金属件 PBR `metalness=1.0` + HDRI 环境反射（`scene.environment`）+ 金属贴图（拉丝/划痕/锈蚀）——告别塑料感
5. **反光亮度合理**（不刺眼）
6. **零件数明显增加**（雷达/菲涅尔透镜/内部细节——不像玩具）
7. **跑道标线画对**（虚线平行跑道、前后对齐；斜角甲板保持）
8. **零件树默认展开一层**
9. **真实感**：水线 + 水下舰体（球鼻艏/螺旋桨/舵）+ 航行尾流；相控阵雷达 T/R 单元阵列细节；甲板使用痕迹（轮胎磨痕/油污/系留点）
10. tsc / vitest 全绿

## 范围

- **做**：machine-stage（航母 carrier + 舰载机相关）
- **不做**：甲板作业人员（先不做）

## 循环

每改一处 → 跑测试 + 截图对照福建舰真图验证。

## 阻塞

缺真实参考（如舰载机歼-15/35 无 GLB）→ 先用 j20.ts 结构 + 公开图，记录在案继续，别卡住。
