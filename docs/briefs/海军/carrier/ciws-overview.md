# 近防武器系统（CIWS 体系）· 超详细零件级

> 航母/舰艇的**分层近防体系**——最后一道防线（拦截来袭导弹/飞机）。
> 三层：**近程防空导弹**（点防御）+ **近防炮**（1130 转管炮硬杀伤）+ **干扰弹**（软杀伤诱骗）。

## 〇、分层拦截体系（先懂）

```
来袭导弹 →【远程：区域防空导弹】（055/护航舰）
 → 漏网 →【中程：近程防空导弹】（红旗-10——点防御）
 → 再漏网 →【近程：1130 近防炮】（弹幕硬杀伤）
 → 干扰：【干扰弹】（箔条/红外诱饵——软杀伤诱骗来袭导弹偏离）
```

## 二、机构运动/交互动画（分层拦截演示）

```
来袭导弹（多枚）→ 搜索雷达发现
 →【近程防空导弹】发射拦截（导弹升空→制导→命中）
 → 漏网 →【1130 近防炮】弹幕拦截（转管炮开火）
 →【干扰弹】发射（箔条云/红外诱饵诱骗来袭导弹偏离）
```
- **分层拦截**：导弹拦截 → 弹幕 → 干扰诱骗——多道防线
- **防空导弹发射**：发射架点火 → 导弹升空 → 制导 → 命中
- **干扰弹**：箔条云散开 / 红外诱饵燃烧（诱骗）

## 三、受击/质感

- 受击：近防炮塔中弹 / 发射架损坏 / 拦截失败被命中
- 质感：导弹/发射架 / 炮塔 / 干扰弹焰
