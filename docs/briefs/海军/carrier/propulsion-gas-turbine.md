# 燃气轮机（Gas Turbine）· 舰用动力 · 超详细零件级

> 舰用燃气轮机（如 LM2500 / QC-280 级）——055/航母（常规动力）的主动力。
> 本质是一台"喷气发动机改轴输出"：连续燃烧产生高速燃气推涡轮，经减速齿轮驱动螺旋桨。
> 参考真实舰用燃气轮机结构（LM2500 剖视）。

## 〇、工作原理（先吃透，布雷顿循环）

```
进气道吸入空气 →【压气机】多级压缩（轴流式，压力升高）
 →【燃烧室】喷入燃料点火（等压燃烧，高温高压燃气）
 →【涡轮】燃气冲击涡轮叶片 → 涡轮高速旋转
    ├─ 高压涡轮：驱压气机（自持）
    └─ 动力涡轮：输出动力 → 减速齿轮箱 → 轴系 → 螺旋桨
 →【排气】废气排出（余温高）
```

## 二、机构运动/交互动画

- **启动**：启动机带动 → 压气机转 → 点火（燃烧室点火）→ 转速爬升（喘振裕度）→ 自持 → 慢车
- **运转**：压气机/涡轮高速旋转（叶片旋转）+ 排气喷焰 + 进气
- **加减速**：油门→燃油流量→转速/功率（**阻尼感**：燃气轮机加速有惯性/热惯性）
- **剖视**：能看到压气机级→燃烧室→涡轮级的内部层次

## 三、受击/质感

- 受击：外来物打叶片（FOD）/ 起火 / 停转
- 质感：涡轮叶片高温合金（烧蚀色）/ 机匣金属 / 排气熏黑 / 进气口
