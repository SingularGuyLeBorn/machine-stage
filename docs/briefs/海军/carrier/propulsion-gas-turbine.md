# 燃气轮机（Gas Turbine）· 舰用 · 超详细零件级 + 细化（5 维度）

> 舰用燃气轮机（LM2500/QC-280 级）。布雷顿循环。本版按《细化规范》细化。

## 〇、原理
进气→压气机多级压缩→燃烧室喷油燃烧→涡轮（高压驱压气机/动力涡轮输出）→排气。

## 维度 1：零件再往下拆（拆到叶片/喷嘴级）

| 层级 | 零件 |
|------|------|
| 压气机 | **动叶×N级**（每级动叶一圈，**逐片实例化**：叶片+叶根榫头）+ **静叶×N级**（静叶圈）+ 压气机轴 + 机匣 + 可调导叶 |
| 燃烧室 | **火焰筒×N**（环管，实例化）+ **燃油喷嘴×N**（喷嘴+旋流器）+ **点火器×2** + 联焰管 + 外壳 |
| 涡轮 | **高压涡轮叶片**（逐片：叶片+榫头+**冷却气膜孔**）+ 动力涡轮叶片 + 涡轮盘 + 涡轮轴 + 导向器 |
| 减速齿轮箱 | 大齿轮 + 小齿轮 + 齿轮轴 + 轴承 + 箱体 + 滑油 |
| 附属 | 燃油泵/调节器/滤 + 滑油泵/箱/滤 + 启动机 + FADEC + 传感器 |

## 维度 2：数值/时序

- **启动时序**：启动机带动（t=0）→ 转速爬升 → 点火（t≈10s）→ 自持 → 慢车（t≈30s）
- **转速**：动力涡轮 ~3600rpm → 减速到螺旋桨 ~150rpm
- 加速曲线（油门→转速/功率，热惯性阻尼）
