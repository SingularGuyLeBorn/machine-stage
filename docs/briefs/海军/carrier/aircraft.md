# 舰载机（歼-15 / 歼-35）· 详细零件级

> 航母舰载机（歼-15 飞鲨 / 歼-35）。**舰载版特色：折叠机翼 + 尾钩 + 加强起落架 + 弹射牵引钩**。
> 参考真实歼-15/歼-35 + 舰载机结构。飞行框架和 j20-plan.md 共用，但**零件级拆分到每个小件**。

## 〇、舰载机（先懂舰载化）

舰载机为在航母起降/停放做的改动：
- **折叠机翼**：外翼段向上折叠（省甲板/机库空间）
- **尾钩**：着舰钩拦阻索（重着陆减速）
- **加强起落架**：承受着舰冲击（比陆基粗得多）
- **弹射牵引钩**：前起落架挂弹射滑梭
- 防盐雾腐蚀（海上）

| 总成 | 零件 |

### 2. 机翼 + 折叠机构（舰载特色——重点）
| 总成 | 零件 |
|------|------|
| 内翼段 | 内翼段（固定）/ 翼梁 / 翼肋 |
| **外翼段（可折叠）** | 外翼段 / **折叠铰链**（翼根铰链轴）/ **折叠作动器**（液压缸）/ **折叠锁**（锁定/解锁）/ 折叠密封 |
| 气动面 | **鸭翼×2**（歼-15）/ 副翼 / 襟翼 / **全动平尾×2** / 垂尾×2 |
| 折叠细节 | 折叠处管线（液压/电——折叠处要过管线的挠性接头）/ 折叠处蒙皮密封 |

### 3. 动力（发动机×2）
- WS-10/WS-21 涡扇×2：风扇/压气机/燃烧室/涡轮/加力燃烧室/尾喷口（参考 j20 发动机，逐件）

### 4. 起落架（加强——舰载特色）
| 总成 | 零件 |
|------|------|
| **前起落架** | 加强前起支柱 / **双轮×2** / **弹射牵引钩**（挂弹射滑梭）/ 缓冲器（加强）/ 收放作动器 |
| **主起落架×2** | 加强主起支柱（粗）/ 主轮 / 缓冲器（着舰冲击）/ 收放机构 |
| 起落架舱 | 舱门（开合）/ 舱门联动 |

### 5. 尾钩（舰载特色）
| 总成 | 零件 |
|------|------|
| **着舰尾钩** | 尾钩（机尾下的钩）/ 尾钩臂 / **收放作动器**（放下钩拦阻索/收起）/ 缓冲器（钩住时缓冲）/ 钩头 |

### 6. 座舱
- 座舱盖（整体气泡，可开）/ **弹射座椅**（零零弹射——导轨/火箭/降落伞包）/ HUD 平显 / 操纵杆 / 油门杆 / 多功能显示器×N / 仪表

### 7. 武器
- 弹舱（歼-35 内置）/ 翼下挂架（歼-15）+ **导弹**（PL-15 中距/PL-10 格斗/鹰击反舰——见 missile-plan）

### 8. 舰载化细节
- 防盐雾涂层 / 折叠处密封 / 系留点（甲板系留）/ 着舰灯

## 二、机构运动（舰载机特有）

- **机翼折叠/展开**：外翼段向上折叠（收纳）/ 展开锁定（飞行）——折叠铰链+作动器动画
- **尾钩收放**：着舰放下（钩拦阻索）/ 巡航收起
- **弹射起飞**：前起牵引钩挂滑梭 → 弹射（配合 catapult.md）
- **拦阻降落**：尾钩钩拦阻索（配合 arresting.md）→ 加强起落架缓冲
- **起落架收放**
- **飞行运动学**（同歼-20：鸭翼/副翼/平尾/垂尾/矢量喷口/姿态）

## 三、受击/质感

- 受击：折叠翼被打断 / 尾钩损伤 / 发动机起火
- 质感：海军灰隐身涂装 + 折叠处磨损 + 着舰痕迹 + 防盐雾

## 四、验收
