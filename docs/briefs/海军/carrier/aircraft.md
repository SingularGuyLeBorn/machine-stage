# 舰载机（歼-15 / 歼-35）· 超详细零件级 + 细化（5 维度）

> 航母舰载机。舰载化特色：折叠机翼 + 尾钩 + 加强起落架 + 弹射牵引钩。本版按《细化规范》细化。

## 维度 1：零件再往下拆

| 层级 | 零件 |
|------|------|
| 机体 | 前/中/后机身 + 蒙皮 + 隔框×N + 桁条×N + 进气道×2 + 检修口盖×N |
| **折叠机翼** | 内翼段 + 外翼段 + **折叠铰链**（铰链轴+轴承）+ **折叠作动器**（液压缸逐件）+ **折叠锁** + 折叠密封 + 折叠处管线挠性接头 |
| 气动面 | 鸭翼×2（歼-15）/ 副翼 / 襟翼 / 全动平尾×2 / 垂尾×2（各含舵面+作动器）|
| 发动机×2 | 涡扇（风扇/压气机/燃烧室/涡轮/加力/喷口逐件——见 j20）|
| **加强起落架** | 前起（加强支柱+**双轮**+**弹射牵引钩**+缓冲）/ 主起×2（加强支柱+轮+缓冲）+ 收放 + 舱门 |
| **尾钩** | 尾钩 + 钩臂 + **收放作动器** + 缓冲器 + 钩头 |
| 座舱 | 座舱盖 + **弹射座椅**（导轨/火箭/伞包）+ HUD + 操纵杆 + 油门杆 + 显示器×N |
| 武器 | 弹舱/挂架 + 导弹（PL-15/PL-10——见 missile-plan）|
