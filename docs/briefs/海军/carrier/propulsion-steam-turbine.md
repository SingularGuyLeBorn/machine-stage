# 蒸汽轮机（Steam Turbine）· 舰用 · 超详细零件级 + 细化（5 维度）

> 舰用蒸汽轮机（核/常规蒸汽动力）。朗肯循环。本版按《细化规范》细化。

## 〇、原理
锅炉/反应堆产高压蒸汽 → 喷嘴（静叶）→ 冲涡轮动叶 → 高低压涡轮 → 减速齿轮 → 螺旋桨；乏汽冷凝回水。

## 维度 1：零件再往下拆

| 层级 | 零件 |
|------|------|
| 蒸汽发生 | 锅炉/蒸汽发生器 + 汽包 + 过热器 + 给水泵 + 燃烧器 |
| 高压涡轮 | 高压缸 + **喷嘴静叶×N级** + **动叶×N级（逐片：叶片+叶根）** + 高压转子 + 汽封 |
| 低压涡轮 | 低压缸 + 低压级×N（**末级长叶片**逐片）+ 低压转子 + 排汽缸 |
| 减速齿轮箱 | 大齿轮 + 小齿轮×N + 齿轮轴 + 轴承 + 箱体 |
| 冷凝器 | 壳 + **冷凝管×N**（海水管束逐根实例化）+ 循环水泵 + 凝结水泵 |
| 轴系 | 主轴 + 推力轴承 + 联轴器 + 轴封 |
| 辅机 | 滑油系统 + 调速器 + 盘车 + 危急遮断（超速保护）|

## 维度 2：数值/时序
- 启动：暖管暖机（慢）→ 冲转 → 升速（热惯性大）→ 带负荷
- 涡轮高转速 → 减速到螺旋桨转速
- 阻尼：蒸汽轮机热惯性大（启动/加减速慢）
