# 航母弹射器（Catapult）· 超详细零件级 + 细化（5 维度）

> 航母弹射器——~30 吨舰载机在 ~90m 内从 0 加速到 ~250km/h。
> **福建舰用电磁弹射（EMALS）**。蒸汽（C-13）/ 电磁（EMALS）两原理都覆盖。
> 本版按《细化规范》细化：零件再拆 + 数值时序 + 参考 + 分镜 + 剖视。

## 维度 1：零件再往下拆（每个零件拆到子件）

### 电磁弹射（EMALS）直线电机——拆到绕组级
| 层级 | 零件 |
|------|------|
| 直线电机 | **定子段×N**（沿轨道分段，实例化）|
| 每段定子 → | **定子铁芯**（叠片）+ **定子线圈绕组**（铜绕组——逐相/逐匝）+ **定子冷却**（水冷板）+ 定子固定 |
| 动子/滑梭 → | 动子（滑梭下的感应/永磁体）+ 滑梭本体 + 滑梭轮 + 牵引杆 |
| 储能 → | **飞轮储能**（飞轮+电机+真空腔）或 **电容组**（电容单体×N：电容芯+外壳+接线柱+安全阀）|
| 变频 → | 大功率变频器（IGBT 功率模块×N + 驱动 + 控制）|

### 蒸汽弹射（C-13）——拆到汽缸/活塞级
| 层级 | 零件 |
|------|------|
| 弹射汽缸 | **汽缸段×N**（长汽缸分段，实例化）+ 汽缸盖 + 密封 |
| 弹射活塞 → | 活塞 + 活塞环（密封）+ 活塞杆 + 与滑梭连接 |
| 水刹车 → | 水刹车缸 + 水 + 缓冲 |
| 蒸汽储罐 → | 储罐 + 蓄压 + 安全阀 |
| 发射阀 → | 快开阀（阀体+阀芯+作动）|

## 维度 2：数值/时序（弹射的精确曲线）

### 电磁弹射加速曲线（EMALS）
```
距离    时间    速度          加速度
0m      0s      0             0（蓄力）
10m     0.6s    ~60km/h      缓起（可控）
45m     1.5s    ~180km/h     主加速段
90m     2.5s    ~250km/h     离舰
```
- **加速曲线**：缓起（保护飞机结构）→ 主加速 → 末端离舰
- **滑梭时序**：蓄力 t=0 → 释放 t=0.1s → 加速 → 离舰 t≈2.5s → 滑梭水刹车/减速 t≈2.8s → 复位
- **挡焰板时序**：飞机开加力前升起 → 离舰后放下
- 阻尼感：蓄力（张力）→ 爆发 → 加速曲线（可调）→ 末端

### 蒸汽弹射（C-13）参考数值
- 加速：~90m / ~2s / 0→~240km/h
- 蒸汽压力/活塞速度曲线

## 维度 4：交互分镜（弹射起飞的镜头脚本）

```
镜头1（全景）：舰载机在弹射位（前轮挂滑梭，挡焰板升起，飞机开加力）
镜头2（特写·滑梭）：蓄力——牵制杆拉住，滑梭蓄势
镜头3（特写·轨道）：滑梭沿轨道槽高速滑动（0→250km/h）
镜头4（特写·挡焰板）：尾焰喷在挡焰板上（挡焰板挡住尾焰）
镜头5（全景）：飞机被拖加速冲出 → 离舰 → 爬升
镜头6（特写·滑梭复位）：滑梭水刹车停 → 复位回起点
节奏：蓄力（静）→ 爆发（瞬间）→ 加速（快）→ 离舰（释放）
```
