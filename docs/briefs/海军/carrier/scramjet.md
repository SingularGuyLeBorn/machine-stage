# 超燃冲压发动机（Scramjet）· 超详细零件级 + 细化（5 维度）

> 高超音速发动机（5+ 马赫）。无运动部件——靠速度冲压 + 超声速燃烧。本版按《细化规范》细化。

## 维度 1：零件再往下拆

| 层级 | 零件 |
|------|------|
| 进气道 | 前体压缩面 + **压缩斜板×N**（产生斜激波）+ 进气唇口（尖锐）+ 边界层隔道 |
| 隔离段 | 等直隔离段 + 壁面（防喘振）|
| 燃烧室 | 超声速燃烧室 + **燃料喷嘴×N**（实例化）+ **点火器** + **火焰稳定器**（凹槽/支板）+ 燃烧室壁 |
| 尾喷管 | 尾喷管 + 喷管调节（膨胀比）|
| 燃料系统 | 燃料箱（碳氢/氢）+ 高压泵 + **再生冷却管路**（燃料先冷却燃烧室壁再喷入）|
| 热防护 | 再生冷却通道 + 高温合金/陶瓷基复合材料 + 进气道前缘（高热）|
