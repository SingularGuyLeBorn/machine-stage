# 超燃冲压发动机（Scramjet）· 超详细零件级

> 超燃冲压发动机——**高超音速飞行器**（5+ 马赫）的发动机（X-51 / 高超音速导弹用）。
> 核心：**没有压气机/涡轮**——靠飞行速度冲压压缩空气，**超声速燃烧**（气流在燃烧室里还是超声速）。
> 参考真实 scramjet（X-51A 乘波者）结构。

## 〇、工作原理（先吃透——和涡喷/火箭的本质区别）

超燃冲压 = "靠速度吃饭"的发动机：
```
高超音速飞行（5+ 马赫）→【进气道】气流被【斜激波】冲压压缩（不用压气机！）
 →【隔离段】（稳定气流，防燃烧室压力反传喘振）
 →【燃烧室】喷入燃料 +【超声速燃烧】（气流还是超声速，在其中燃烧——难点）
 →【尾喷管】膨胀喷出产生推力
```
关键：**无运动部件**（没有压气机/涡轮这些转动件）——全靠气动外形 + 超声速燃烧。
但要到 5 马赫才启动（低速要用火箭/涡喷助推到超音速）。

## 二、机构运动/交互动画

- **启动**：助推到超音速（火箭/涡喷助推）→ 进气道捕获气流 → 斜激波压缩 → 超声速燃烧启动 → 推力
- **运转**：斜激波系（进气道压缩）+ 燃烧室燃烧 + 尾喷管喷焰
- **剖视**：进气道→隔离段→燃烧室→尾喷管的内部气流通道
- **无运动部件**：和涡喷对比——scramjet 没有转动的压气机/涡轮（全是气动外形）

## 三、受击/质感

- 受击：进气道喘振 / 燃烧室熄火 / 热防护烧蚀
- 质感：高温合金 / 热防护烧蚀 / 进气道尖锐前缘 / 喷焰
