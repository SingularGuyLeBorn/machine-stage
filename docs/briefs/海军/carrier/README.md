## 实施顺序（先立核心闭环）

**先通"甲板弹射起飞 + 拦阻降落一架舰载机"这个核心闭环**，再铺其余。

1. 舰体 + 动力（立住船）
2. 飞行甲板：弹射器 + 拦阻装置（核心）
3. 舰载机（歼-15/歼-35，和歼-20 共用飞行框架）
4. 舰岛（雷达/舰桥）+ 武器（近防）
5. 内部机库 + 弹药升降机
