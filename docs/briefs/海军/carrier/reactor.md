# 核反应堆（舰船压水堆 PWR）· 超详细零件级 + 细化（5 维度）

> 舰船核反应堆（核动力航母/潜艇的心脏）。压水堆 PWR。
> 零件数 600+ 定义件（燃料棒数万实例）。本版按《细化规范》细化：零件再拆 + 数值时序 + 参考 + 分镜 + 剖视。

## 〇、压水堆原理（先吃透）

```
堆芯核裂变放热 → 一回路高压水（~15MPa 不沸腾）带热 → 蒸汽发生器传热给二回路
 → 二回路蒸汽 → 汽轮机推进/发电 → 一/二回路隔离（热交换，水不混）
```

## 维度 1：零件再往下拆（拆到最小单元）

### 堆芯 → 拆到燃料芯块级
| 层级 | 零件 |
|------|------|
| 燃料组件×~200 | 每组件：**燃料棒×~264 根**（逐根实例化）+ 组件骨架（上下管座+定位格架×N）|
| 每根燃料棒 → | **铀燃料芯块×N**（芯块逐块）+ 锆合金包壳 + 上下端塞 + 压紧弹簧 |
| 控制棒束×~50 | 每束：**控制棒×N**（吸收体棒逐根）+ 束连接 |

### 控制棒驱动机构（CRDM）→ 拆到抓钩级（用户点名）
| 层级 | 零件 |
|------|------|
| CRDM×N | 每台：**驱动轴** + **线圈组**（提升/传递/保持线圈）+ **抓钩机构**（提升抓钩+传递抓钩——抓钩卡驱动轴）+ 壳体 + 密封 |
| 抓钩 → | 抓钩（卡爪——卡住驱动轴一步步提升/下放）|

### 一回路 → 拆到泵/阀内部
| 层级 | 零件 |
|------|------|
| 主泵 | 泵壳 + 叶轮 + 电机 + **轴封**（三道轴封——防放射性泄漏）|
| 稳压器 | 稳压器筒体 + 电加热器×N + 喷淋器 + 波动管 + 安全阀组 |
| 蒸汽发生器 | 筒体 + **U 形传热管×N**（逐根实例化）+ 汽包 + 给水环 + 支撑板 |

### 压力容器
- 筒体（厚壁）+ 顶盖 + **顶盖螺栓×N（逐颗）** + 密封 + 贯穿件

## 维度 2：数值/时序

- **控制棒时序**：控制棒插抽速度（正常调节慢、应急停堆快——**紧急停堆 <2 秒全插入**）
- **一回路参数**：压力 ~15MPa、堆芯出口温度 ~320℃
- **启动时序**：冷态 → 加热升温 → 临界（控制棒逐步抽出）→ 升功率
- 阻尼感：核反应的热惯性（功率变化慢）

## 维度 4：交互分镜（反应堆的镜头脚本）

```
镜头1（全景）：反应堆舱（压力容器 + 一回路 + 屏蔽）
镜头2（剖视特写·堆芯）：压力容器内——燃料组件阵列 + 控制棒在顶部
镜头3（特写·控制棒）：控制棒插抽（CRDM 驱动，调节反应性）
镜头4（特写·蒸汽发生器）：一回路传热管束传热给二回路
镜头5（特写·应急）：应急停堆——控制棒快速插入堆芯
节奏：稳态 → 调节（控制棒慢动）→ 应急（快速停堆）
```
