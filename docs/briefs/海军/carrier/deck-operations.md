# 航母甲板作业（Flight Deck Operations）· 超详细零件级（航母的"活"）

> 航母甲板是"世界上最危险的机场"——甲板上舰载机/人员/车辆的**精心编排的作业舞**。
> 这是航母"活"的体现：弹射/拦阻是机构，**甲板作业是流程**。

## 〇、甲板作业是什么（先懂）

航母甲板的作业是一套**精确编排的流程**：舰载机出动/回收 + 甲板人员（彩色马甲分工）+ 车辆（牵引车/挂弹车/加油车）协同。

**甲板人员彩色马甲**（美军航母的分工，一目了然）：
- **黄马甲**：飞机调度员（指挥飞机移动——"指挥舞"）
- **绿马甲**：弹射/拦阻人员（弹射器/拦阻索作业）
- **红马甲**：弹药/消防（危险——弹药+消防）
- **白马甲**：安全/医疗/质量（安全监督）
- **蓝马甲**：牵引/升降机（飞机牵引、升降机操作）
- **棕马甲**：机务（飞机维护）
- **紫马甲**：加油（航空燃料）

## 二、机构运动/交互动画（甲板作业流程——航母的"舞"）

### 出动流程（舰载机起飞）
```
机库 → 升降机 → 甲板 → 牵引车拖到弹射位 → 挂弹/加油 → 黄马甲指挥到位
 → 弹射（绿马甲）→ 起飞
```

### 回收流程（舰载机降落）
```
拦阻降落 → 尾钩脱索 → 牵引车拖到停机位 → 黄马甲指挥 → 系留
 → 维护（棕马甲）/ 加油（紫）/ 挂弹（红）
```

### 甲板作业的"舞"
- **彩色马甲分工**（各色人员各司其职）
- **牵引车调度**（飞机在甲板上的移动编排）
- **连续出动/回收**（多机连续起降——甲板的节奏）
