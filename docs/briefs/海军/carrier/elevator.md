# 航母升降机（Aircraft Elevator）· 超详细零件级 + 细化（5 维度）

> 舰载机甲板↔机库的垂直升降平台。本版按《细化规范》细化。

## 维度 1：零件再往下拆

| 层级 | 零件 |
|------|------|
| 平台 | 平台面板 + 支撑框架 + **活动护栏**（升降收起/到位放下）+ 平台标记 |
| 导轨 | 升降导轨×N + 导向轮/滚轮 + 支撑 |
| 驱动 | **液压缸×N**（缸体/活塞杆/密封逐件）或 卷扬（卷筒+钢丝绳+滑轮+电机）+ 配重 + 制动器 |
| 安全 | 安全锁 + 限位开关 + 应急制动 + 护栏联锁 |
| 开口 | 舷侧开口 + 机库防火门 |

## 维度 2：数值/时序
- 承载 ~30 吨（一架舰载机）；升降速度/时序；到位锁定

## 维度 3：参考图
- 航母升降机（舷侧/舷内）；存 refs/carrier-elevator/

## 维度 4：交互分镜
```
镜头1：舰载机在机库层上平台（护栏收起）
镜头2：平台升（载飞机，阻尼感——启动慢→匀速→减速）
镜头3：到位锁定 → 护栏放下 → 飞机推出到甲板
```

## 维度 5：剖视
- 升降机构剖视（液压缸/导轨/安全锁）
