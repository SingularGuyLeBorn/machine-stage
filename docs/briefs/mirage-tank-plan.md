# 幻影坦克（Mirage Tank）· 设计任务书（零件级 · 科幻光学伪装）

> 自主别来问。冲突以「工程自洽 + 科幻感」为准，记 PROGRESS.md。
> 幻影坦克（红色警戒 Mirage Tank）——能**光学伪装成环境（树/岩石）**的科幻坦克。
> 新维度：**伪装/变形机构**——这是科幻装备，外形可放飞但机构要自洽。

## 〇、背景

幻影坦克：红警里的盟军特种坦克，能变成一棵树/环境物体隐身。科幻装备——
**内部机构我们原创**（无现实约束），但**光学伪装的"展开/收起"机构要做真实**（能动的机构）。
**零件数 ~300 定义件**。

## 一、零件树（零件级）

| 总成 | 零件 |
|------|------|
| **车体** | 底盘（比主战小，轻型）/ 倾斜装甲 / 履带（零件级：履带板/销/负重轮/驱动轮）|
| **炮塔** | 炮塔 + **光谱散射炮**（科幻主炮——能量炮）+ 俯仰机构 + 回转 |
| **伪装系统（核心）** | **全息投影发生器×N**（周身分布）+ **可展开伪装面板**（收纳在炮塔/车体，展开时覆盖整车）+ 投影天线/传感器 |
| **伪装形态** | **"树"形态**（可展开的仿真树——树干+枝叶，收纳在车内，展开罩住整车）或 全息迷彩（投影环境图像）|
| 动力 | 发动机 + 传动（简化，重点在伪装）|

## 二、核心机构：光学伪装（灵魂）

幻影坦克的灵魂是**"变身"——从坦克变成环境物体**：

```
战斗形态（坦克） → 伪装展开：伪装面板/仿真树从收纳位展开（机械展开动画）
 → 罩住整车 → 全息投影启动（车体表面投影环境图像，融入背景）
= 伪装形态（看起来像一棵树/一块岩石）
```
- **伪装面板展开机构**：收纳→展开的机械动画（铰链/伸缩杆——要能动）
- **全息投影**：车体表面投影环境（着色器特效——投影周围环境，视觉隐身）
- **树形态**：展开一个仿真树（树干+枝叶）罩住坦克（红警的经典形态）
- 变形过程有阻尼感（机械展开）

## 三、受击/质感

- 受击：伪装面板被打掉（露出坦克）/ 投影失效 / 履带断
- 质感：科幻金属 + 全息投影特效（伪装时的半透明/环境投影）+ 能量武器光效
