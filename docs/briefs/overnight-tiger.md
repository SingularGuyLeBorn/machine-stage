## 〇、项目背景（你没有世界知识，先读这段）

我们在做"纯代码生成高细节机械模型"的生产线。核心方法：**零件化 + 自内向外**——
- 每个装备 = 一棵零件树（`src/three/parts/models/tiger/` 下分 6 模块：engine/hull/running/transmission/interior/turret）
- 每个零件在 registry.ts 里声明：`{ id, name_cn, geometry, material, mate }`，由装配器生成 3D
- 重复件用实例化：`geometry.instances: N` + `instanceLayouts`
- 穿模检测（solver/detect.ts）查零件不该碰的碰了；悬空检测（solver/support.ts）查该碰的没碰
- 前端 `npm run dev` 浏览器看：构建滑杆（L1-L5 逐层装配）、爆炸视图、透视、标签、剖面

**虎式坦克 Tiger I（1942 德国重坦，57 吨）**：乘员 5 人（车长/炮长/装填手在炮塔，驾驶员/机电员在车体前部）。
布局：前部驾驶舱（驾驶员左 + 机电员右）→ 中部战斗室（炮塔吊篮）→ 后部发动机舱（HL230 V12 汽油机）。
主炮 88mm KwK 36。弹药 92 发。这些尺寸/结构是真实的，照做。

**当前进度**：250 定义件。主炮击发/机枪连射/受击分级/油箱/发动机启动/战损三态/爆炸/行进/瞄准/第一人称/仪表真指针都已上线。

## 二、弹药装填链（炮弹不是装饰，要能送进炮管）

**核心**：炮弹能从弹药架 → 装填手 → 炮闩 → 炮膛 → 击发 → 抛壳。

### 2.1 弹药架分布（虎式真实，92 发 88mm）
- **车体两侧 sponson 弹药架**：竖直/倾斜插（两侧壁，各 ~20 发）
- **战斗室地板**：水平放（~20 发）
- **炮塔吊篮周围**：装填手顺手待发弹（~10 发）
- **装填手身边待发架**：最顺手的几发
- 炮弹零件：弹头（穿甲/破甲/榴弹分型）+ 弹壳 + 发射药 + 底火（实例化 92 发）

### 2.2 装填链（动画）
```
装填手（炮塔右侧）从最近弹药架取弹（手拿弹）
 → 转身递弹到炮闩（炮塔后部主炮后膛）
 → 炮闩开闩 → 装填进炮膛 → 关闩闭锁
 → 击发 → 开闩 → 弹壳抛出（掉炮塔底板）
```
- 装填手站位要够得着弹药架和炮闩（人机工程）
- 炮闩和主炮膛连通（炮管中空，已有）
- 装填动画：取弹→递弹→装填→关闩 动作链
