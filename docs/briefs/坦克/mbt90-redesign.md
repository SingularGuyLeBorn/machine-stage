## 〇、MBT-90 是什么（现代主战坦克，先立认知）

现代主战坦克（主战 = 主力坦克）的特征：
- **倾斜复合装甲**（大倾角，多层复合：钢+陶瓷+间隔）+ **爆炸反应装甲块（ERA，贴满）**
- **大口径滑膛炮**（120mm/125mm 滑膛，没有膛线）+ **自动装弹机**或人工装填
- **尾舱弹药架 + 泄压板**（殉爆时压力从尾舱顶板泄出，保命）
- 大功率发动机（柴油 1500 马力 / 燃气轮机）+ 先进火控（热像仪/弹道计算机/猎-歼）
- 乘员 3-4 人（车长/炮长/装填手/驾驶员）

**方法论：自内向外**——L1 动力 → L2 行动 → L3 内饰 → L4 外壳 → L5 表面。先造内脏再造壳。
**目标零件数：1200+ 定义件**（比虎式 250 件多——现代坦克更复杂，零件数必须上来）。

## L1 动力系统（先做——发动机是心脏）

### 1.1 发动机（柴油机 V12 双涡轮增压，~200 件零件级）
- **缸体**：曲轴箱 + 缸套×12 + 缸盖×2
- **曲柄连杆**：曲轴（主轴颈/曲柄销/曲柄臂）+ **活塞组×12**（活塞+活塞环×3+活塞销+卡簧）+ **连杆×12**（大头剖分+轴瓦）
- **配气**：凸轮轴×2 + 气门×48（每缸4）+ 气门弹簧/挺杆/摇臂 + 正时齿轮系
- **供油**：高压油泵 + 喷油嘴×12 + 燃油滤清器 + 油管
- **涡轮增压器×2**：涡轮 + 压气机 + 中冷器 + 排气管
- **冷却**：水泵 + 散热器 + 风扇 + 节温器
- **润滑**：机油泵 + 油底壳 + 机油滤清器
- **启动**：起动机 + 飞轮 + 齿圈

### 1.2 传动（~80 件）
- 主离合器 / 变速箱（**每档齿轮独立** + 同步器 + 轴承）/ 侧传动×2（行星排）
- 转向机（差速/液压转向）

## L2 行动装置（~400 件，实例化）

- **履带**：履带板×~160（含橡胶衬垫）+ 履带销×~160 + 端部连接器（实例化）

- 履带张紧机构

## L3 内饰（~300 件——战斗室是重点）

### 3.1 驾驶舱（车体前部，驾驶员）
- 方向盘/转向杆 + 仪表 + 踏板 + 潜望镜×3 + 座椅 + 舱盖

### 3.2 战斗室（炮塔吊篮 + 车体中部）
- **炮塔吊篮**（随炮塔旋转的平台——装填手/炮长站上面）
- **炮长位**（左）：瞄准镜（**昼间镜 + 热像仪**）+ 火控面板 + 高低/方向手轮
- **车长位**（右）：车长指挥塔（周视镜×N）+ 车长超越控制
- **装填手位**（如有）：装填机构

### 3.3 弹药 + 自动装弹机（重点）
- **尾舱弹药架**：炮弹竖直/水平排列（弹丸+药筒分装或定装）+ **泄压板**（尾舱顶部，殉爆泄压）
- **自动装弹机**（苏式转盘 / 尾舱链式）：转盘 + 提弹机 + 推弹杆 + 选弹机构——**自动装弹是现代坦克特色**
- **炮弹零件化**：弹丸（**尾翼稳定脱壳穿甲弹 APFSDS**：弹芯钨合金+弹托 / 破甲弹 HEAT：药型罩 / 榴弹）+ 药筒 + 发射药 + 底火
- 弹药基数 ~40 发

## L4 外壳（~200 件——复合装甲 + 反应装甲）

### 4.1 车体 + 炮塔（复合装甲——大倾角）
- **复合装甲包**（多层：钢面板 + 陶瓷/复合材料夹层 + 间隔 + 钢背板——大倾角布置）
- 车体：首上大倾角 + 侧面 + 车顶 + 车尾
- 炮塔：楔形/大倾角复合装甲（炮塔前装甲最厚）
- 座圈 + 舱盖 + 观察窗

### 4.2 滑膛炮（~80 件）
- **滑膛身管**（无膛线）+ **抽烟装置**（炮管中段的排烟套）+ **热护套**（炮管外罩）
- 炮闩 + 复进机 + 制退机 + 炮盾

### 4.3 爆炸反应装甲（ERA，~100 件实例化）
- **ERA 反应装甲块×N**（贴在首上/炮塔/侧面——一块块炸药盒）+ 安装螺栓
- 每块 ERA：外壳 + 炸药 + 钝感夹层（被击中时爆炸推开来袭弹）

## 交互（参照 tiger-interactions.md，全套）

- 机动：前进/转向（差速）/悬挂（液气悬挂随地形）
- 主炮：自动装弹机装填 → 击发 → 后坐 → 抽烟装置排烟 → 抛壳/弹托分离
- **ERA 反应装甲**：被击中时该块爆炸（推开来袭弹）——可演示
- **殉爆泄压**：弹药架中弹 → 尾舱泄压板掀开泄压（人员保命）vs 泄压失败殉爆
- 火控：热像仪视角、猎-歼（车长发现→炮长打击）
