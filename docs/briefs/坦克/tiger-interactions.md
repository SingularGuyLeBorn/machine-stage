# 虎式交互特效设计（从"能看的模型"到"能玩的机器"）

> 设计哲学一句话：**每个可动件都要能演示它的运动学，每个系统都要能被击穿验证。**
> 虎式不是展品，是一台能开、能打、能被打坏的机器。

## ★ 全局运动原则：一切动作有重量（阻尼感总则，用户点名）

**这台坦克没有匀速和瞬动。** 57 吨车体、11 吨炮塔——每个动作都是
「慢启动 → 加速 → 减速 → 过冲回弹」四段式，质量越大惯性越明显：

| 运动学铁律 | 物理来源 |
|-----------|---------|
| 启动慢（扭矩有限，从静止要"攒劲"） | 惯性 F=ma |
| 停止有过冲回弹（停时"晃一下"再稳） | 欠阻尼弹簧-质量系统（悬挂/结构弹性） |
| 运动中带弹性微颤（长炮管行进间轻颤） | 悬臂结构振动 |
| 负载不对称（抬炮管比压炮管慢——重力） | 重力负载 |
| 一切液压先快后慢（制退/复进机） | 液压阻尼特性 |

## P0｜机动（它得先"是辆车"）

| 交互 | 设计（含阻尼细节） |
|------|------|
| **发动机启动** | 启动电机/惯性手柄带动 → 曲轴**第一转很费力**（压缩阻力）→ 逐缸点火（"突、突突"喘振）→ 转速不稳爬升 → 稳定怠速。**启动瞬间车体轻微一扭**。冷启动更难（白烟+多次点火失败） |
| **起步/前进/后退** | 转速先升（轰鸣）→ 离合器**顿挫** → 57 吨"沉一下"（悬挂压缩）→ 履带缓慢蠕动 → 渐加速。急停：惯性 → 刹车**车体重重点头** + 履带拖地划痕 |
| **转向** | **履带差速**（左快右慢=右转，一侧反转=中心转向）。转向时**车体侧倾**（离心力+悬挂外侧压缩） |
| **悬挂** | 扭杆悬挂：每负重轮独立随地形上下，过坎"轮子先抬、车身后跟"的**延迟感** |
| **换挡** | 顿挫（车轻微点头）+ 传动轴转速变化 + 发动机声调变化 |
| **炮塔回转** | **11 吨惯性**：缓慢加速 → 限速 → 停止时减速 + **过冲回弹**（停到位"晃一下"再稳——最出重量感） |
| **炮管俯仰** | **重力不对称：抬比压慢**。停顿时炮口轻颤。行进间炮管始终微颤 |
| **发动机联动** | 油门→转速→排气烟变浓；转速表指针有惯性（不瞬指） |

## P1｜火力（它得"是门炮"）

### 主炮击发全循环（帧级）
```
装填（装填手递弹→弹壳+弹头合装进膛→关闩闭锁）
 → 击发 → 炮口分相火光（初焰→主焰→白烟）
 → 后坐（炮身后坐 ~450mm，制退机液压阻尼先快后慢）
 → 后坐力传全车（车体重背后仰 + 悬挂下沉压缩 + 履带抓地）
 → 复进机缓慢回位（末段轻微过冲）→ 悬挂回弹稳回
 → 开闩 → 弹壳从炮闩抛出（抛物线→炮塔底板弹跳→滚动）
```
- **后坐力**：整个"后座—回弹—稳回"链条是重量感高潮（别缩一下就算）
- **弹壳**：黄铜弹壳全程物理
- **炮口冲击波**：地面扬尘/雪雾/水面涟漪；夜间炮口焰照亮全车

### 机枪（MG34 ×2：航向 + 同轴）
- **后坐力**：枪管短后坐——**每次射击枪管后坐-复进循环可见**；连射**枪口上跳**（后坐力矩，要压枪）；车载机枪射击车体震颤传递
- **供弹通道全程可见**：弹链从弹药箱 → 供弹口 → 机匣拨弹齿节节步进 → 抛壳口
- **弹壳蹦出来**：抛壳窗拋物线弹壳 + 落地弹跳 + **堆积**（打多了脚下一层弹壳）
- **枪管发热**：连射枪管暗红→亮红 → 过热冒烟 → **快速换枪管**（MG34 招牌：开卡扣→抽烫管→插新管）

## P2｜生存（它得"能被击穿验证"）

| 交互 | 设计 |
|------|------|
| **油箱** | 油箱盖铰链可开（密封圈）→ 油枪插入 → **油位计玻璃管油面真实上升** → 加满溢出警示；**被打漏**：中弹穿孔 → 油液沿车体流淌 → 油位降 → 供油不足发动机喘振熄火 → 油流热排气管**起火** |
| **弹药殉爆连锁** | 炮塔中弹 → 弹药架升温冒烟 → 泄压阀喷火 → 临界殉爆 → **炮塔掀飞**（泄压失败时） |
| **履带被打断** | 履带板打飞几节 → 履带松垮拖地 → 趴窝（可触发**战场抢修**：敲出履带销→接新节→打紧） |
| **起火蔓延** | 中弹起火点 → 沿油路/弹药蔓延，乘员舱冒黑烟 |

## P3｜环境交互（物理存在感）

- **泥泞**：履带甩泥块（板节带泥甩出抛物线）+ 打滑刨地
- **雪地**：履带甩雪雾 + 车体积雪（可抖落）
- **水面**：渡河水位漫履带 → 发动机舱进气口（虎式有通气管可潜渡）
- **雨天**：装甲表面雨水沿焊缝流淌成股 + 观察窗雨刮
- **声光延迟**：远处击发——先见火光，后闻炮声（距离/声速）

## P4｜深度拟真（想象力区）

- **发动机冷启动**：逐缸点火（**排气歧管按点火顺序逐根变红**）→ 怠速白烟 → 热车烟淡
- **仪表盘真实工作**：转速/速度/油量表全部与车辆状态联动（不是贴图）
- **观察窗**：驾驶员/车长潜望镜视角可切换（第一人称开坦克）
- **随车工具可用**：千斤顶真能顶起车体、撬棍真能拆履带销
- **昼夜**：夜间排气管灼红可见、红外大灯（后期型）
