## 一、这个项目是什么（愿景）

我们在做一条**"纯代码生成高细节机械模型"的生产线**。核心方法论是**零件化 + 自内向外**：
- 每个装备 = 一棵**零件树**（注册表声明几何/材质/配合/实例），由装配器生成，不是手糊的整体模型
- 每个零件有身份（partId），能被定位、拆解、检测、做动画
- **自内向外**：先造内脏（发动机/机构）再造外壳——这样每个零件都有安装关系，不是空壳

终极目标：一个**可拆解、可交互、可被击穿验证**的装备模型库，未来支撑军事 RTS / 装配演示 / 教学。

**当前在做**：虎式坦克 Tiger I（第一个装备，验证全套方法）。

## 四、虎式当前待办（按优先级）

### P0 必修（缺陷/硬伤）
1. **主炮炮闩机构缺失**：主炮现在只有炮管，**没有炮闩**（闩体/击针+簧/保险/复进机/制退机/抽壳钩）。这是"主炮击发全循环"动画的实体挂载点，必须补。
2. **主炮炮管要做中空**：现在炮管封死了——炮管该是中空的（有炮膛，能看到炮闩/弹膛），不能是实心铁棍。
3. **对空机枪人机工程**：车顶 MG34 现在在炮塔前部（x-1.95），但操作人员从后部舱口探身（车长塔 x-1.30 / 装填手舱口 x-1.25）——**人探出来够不着枪**。移到贴操作人员舱口（推荐车长塔顶环形枪座，符合史实），并补**防盾/遮挡**（乘员探身要有挡子弹的）。

### P1 系统性补强
4. **检测器加"悬空检测"**：现在只查穿模（碰了不该碰的），没查悬空（该碰的没碰）。新规则：每个零件必须有支撑邻居（最小间隙 ≤ 阈值），否则报"疑似悬空"。例外：特效件/飞行件单独标注。
5. **修赞助板铆钉带偏后悬空**：铆钉带 x[-1.74~1.74] 中心 x=0，但赞助板壳体 x[-4.50~0.91] 中心 x=-1.8——**铆钉带整体偏后 1.8m，后端超出赞助板悬空**。修到对齐通长铺满。
6. **单位/命名规范**：主炮是 8.8cm KwK 36（德军官方用 cm）——命名/标注单位要统一规范（内部计算建议统一 mm，展示标注统一一种）。别出现混乱的单位。

### P2 质感层（L5——从"新车"到"战车"，虎式现在最缺这个）
7. **防磁涂层波纹（Zimmerit）**：全车表面手糊波纹（最高优先，现在表面光溜溜最出戏）
8. **战术编号 + 迷彩条纹**：炮塔侧面三位编号 + 暗黄底绿/棕迷彩（别单色）
9. **挂满零碎**：侧裙板 Schürzen、绕车牵引缆绳、成套随车工具（铁锹/斧/千斤顶/自救木）
10. **做旧**：磨损掉漆、锈迹、油污、排气管熏黑、行走部分泥污

### P3 交互动画（tiger-interactions.md 详解）
11. 机动：前进/后退/**履带差速转向**、悬挂随地形起伏（延迟感）
12. 主炮击发全循环：装填→闭锁→击发→分相炮口焰→**后坐 450mm 传全车**→抽壳
13. 机枪：供弹链可见、弹壳蹦出堆积、枪管红热快拆换管
14. 油箱：能开盖/加油（油位上升）/被打漏/起火

**全局运动原则（所有动作）**：真实机器没有匀速和瞬动——一切动作「慢启动→加速→减速→过冲回弹」，质量越大惯性越明显。57 吨车体、11 吨炮塔，炮塔停到位要"晃一下"再稳。

## 六、工作纪律（红线，必须遵守）

1. **实例化**：重复件（螺栓/履带板/链节/弹壳）一律"一个定义 + instances"，禁止逐件手写
2. **穿模零报告**：静态/扫掠全程零穿模（白名单只豁免构造性接触，守门规则已修）
3. **零件粒度**：拆到"每个可动关节/每根液压管/每块板的螺栓圈"都是独立件——不许总成级糊弄
4. **质感层别漏**：每个装备四层（零件/机构/受击/质感）一个不能少
5. **人机工程**：每个"给人用的"部件（枪/舱口/驾驶位/弹药架）必须过"人够得着吗、挡人吗"校验
6. **commit 纪律**：每完成一个闭环即 commit（带原因），工作区不留积压
7. **tsc / vitest 全绿**，测试只增不减
8. **存疑即报**：发现不合理/悬空/干涉，主动提，别藏着

## 七、我们踩过的坑（宝贵教训，别重蹈）

| 坑 | 教训 |
|----|------|
| 穿模报告一度全靠肉眼抓 | 检测器 + 白名单 + 悬空检测要自动化，别让人肉当检测器 |

## 八、留给你的空间（这些由你发挥，不定死）

设计文档给的是**方向、原则、验收标准**，不是牢笼。以下你自由发挥：
- **具体造型/几何细节**（零件长什么样、机构怎么排——工程自洽 + 符合史实/原作即可）

- **交互动画的节奏/运镜**（阻尼感的具体曲线、镜头怎么给）

**一句话**：我们要的是"工程上真实、视觉上像真的、交互上好玩的机械"。原则是底线，细节是你的。

# 补充：两个交互/UI 问题（用户实操发现）

> 交接 Prompt 之外，刚发现两个 UI 交互问题，一并修。

## 1. 左下角面板默认折叠 + 点零件时信息要居中显示

- **左下角面板默认折叠**（不要默认展开占空间，用户要看再展开）
- **右侧 3D 视图点击一个零件时**：左侧的零件信息应该在**中间位置**展示（视觉焦点），
  现在是纯粹挤在**底部**——信息被压扁、不突出。
  期望：点中零件 → 左侧信息面板在屏幕中间（或合理焦点区）清晰展示该零件，不是在角落底部。

## 2. 点左侧零件树后，右下角框里有些元件太小看不清

- 点击左侧零件树的零件 → 右下角框（零件详情/隔离视图）里**有些元件太小，看不清**
- 期望：选中零件后，右下角框**自动缩放/聚焦**到该零件（按零件尺寸自适应取景，
  小零件放大到能看清细节），别让小元件缩在角落里看不清
