## 1. 干什么

从零造终结者 T-800 的**内骨骼金属骨架**（不做外部血肉）。
方法论：**零件化 + 自内向外**——每个零件独立 partId，注册表声明（几何/材质/配合/实例），装配器生成，不是手糊的整体模型。
**先读主线 `docs/briefs/t800-plan.md` 设计全文。**

## 2. 切入点：先做一条腿（不是全身）

腿 = 完整液压关节链（髋→膝→踝），是 T-800 的核心运动学。
先立一条腿，验证最难的"**液压活塞随关节角度真实伸缩**"——这个通了，双臂/脊柱/头是同一套逻辑的复制。

## 3. 一条腿的零件（~140 定义件，零件级，不许总成级糊弄）

> 粒度基准：**每个液压缸都是 7-9 个独立件**（缸体/活塞/活塞杆/耳环×2/导向套/密封/防尘圈），
> 每个关节的驱动缸独立、每根管/每个阀/每个接头独立。一条腿有 6-8 个液压缸，光缸就 50+ 件。

| 段 | 零件（拆到独立件） | 件数 |
|----|------------------|------|
| **髋关节** | 球头 / 窝座 / 保持环 / 主轴承×2 / 密封×2 / 角度传感器 / **屈伸驱动缸×2**（每缸 7 件） | ~22 |
| **大腿** | 股骨主骨（中空含管腔）/ 外护甲板×3 / **膝驱动主缸**（8 件）/ 液压硬管×4 / 管接头×6 | ~22 |
| **膝关节** | 铰链销 / 衬套×2 / 卡环×2 / 关节轴 / **膝后大液压缸**（9 件，标志）/ **膝前补偿缸**（7 件）/ 护罩前后 | ~24 |
| **小腿** | 胫骨主骨 / 外护甲板×3 / **踝驱动双活塞缸×2**（每缸 8 件=16）/ 液压管×2 / 接头×4 | ~26 |
| **踝关节** | 多轴节×2 / 球窝 / 轴承 / 密封 / **踝驱动缸×2** / 角度传感器 | ~12 |
| **足部** | 跟骨 / 跖骨×3 / 趾骨 / 减震垫×2 / 防滑钉×4 / 踝连接座 | ~12 |
| **液压系统（腿段）** | 主供油管 / 回油管 / 分配阀块 / **伺服阀×每关节** / 蓄能器 / 管接头×N / 管卡 | ~20 |
| **紧固/密封/传感** | 螺栓圈族 / 卡环 / 密封件族 / 线束 | ~14 |

**合计 ~140 件/腿**（双臂/脊柱/手更复杂，全身 ~800 件）。

## 4. 验收（第一闭环）

- [ ] 一条腿 ~140 件进注册表，装配成形（铬钢骨架质感）
- [ ] **髋/膝/踝可动，屈伸全程**：每个液压缸的活塞杆**随角度真实行程伸缩**（灵魂——关节转多少度，活塞伸缩多少毫米对得上）
- [ ] 静态/屈伸扫掠**零穿模**；液压件**不悬空**（每缸有缸体/杆/耳环，每管有接头）
- [ ] 阻尼感：屈伸慢启动→加速→减速→过冲回弹（别匀速别瞬动）
- [ ] 单腿屈伸演示录屏存档；tsc/vitest 全绿；commit 带原因

## 5. 红线

- 实例化（紧固件/衬套/耳环成族）；零件级粒度（活塞杆/密封都独立）
- **液压联动是灵魂**：关节转多少度，活塞伸缩多少毫米要对得上（不许活塞不动或瞎动）
- 全程 zero 穿模 + zero 悬空
- commit 带原因，工作区不留积压
