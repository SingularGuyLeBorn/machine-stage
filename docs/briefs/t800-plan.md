## 1. 干什么

从零造终结者 T-800 的**内骨骼金属骨架**（不做外部血肉）。
方法论：**零件化 + 自内向外**——每个零件独立 partId，注册表声明（几何/材质/配合/实例），装配器生成，不是手糊的整体模型。
**先读主线 `docs/briefs/t800-plan.md` 设计全文。**

## 2. 切入点：先做一条腿（不是全身）

腿 = 完整液压关节链（髋→膝→踝），是 T-800 的核心运动学。
先立一条腿，验证最难的"**液压活塞随关节角度真实伸缩**"——这个通了，双臂/脊柱/头是同一套逻辑的复制。

## 附录 A. 第一版返工记录：**减壳露机**（2026-10-20）

第一版虽然过了零件粒度和零穿模，但渲染出来是"一根腿被光滑壳包住"——
不是终结者。返工的核心判断：

> 复杂感 = **液压缸 + 活塞杆 + 走线管路 + 关节机构 + 螺栓圈** 全部外露可见。
> 一条腿看着复杂，不是零件多，是**你能看到里面的机构在工作**。

### A.1 改了哪五处

| # | 原状（包壳） | 改后（露机） | 代码位置 |
|---|---|---|---|
| 1 | 股骨/胫骨 = 圆角方管实心梁，外挂一圈"装饰环箍" | **开放桁架骨段**：4 根纵向角柱 + 5 道横撑环 + 两端带孔端板，环与环之间能看穿到对侧 | `kits.ts` 的 `trussBeam`（替掉 `beamGeometry`） |
| 2 | 髋轭 = 320×146×120 的实心盒子，把整个髋关节埋了 | **U 形开口架**：两侧立板 + 上下横梁，两个缸安装凸台铸在立板外侧，中间全开 | `segments/upper.ts` 的 `t800.hip.yoke` |
| 3 | 大腿/小腿整段护甲板（100×300 / 100×220），正面全被挡住 | **局部护板**：侧护条收窄到 20 mm、正面只留上段 20×110 mm 一块、膝部前后各一块 58×130 mm | `segments/{upper,lower}.ts` 的 `armor_*` / `guard_*` |
| 4 | 硬管埋进骨面、接头在护板后面 | 硬管 + 黄铜接头 + 管卡**明线**贴在骨段正面走，两端都有接头 | `segments/{upper,lower}.ts` 的 `lines` / `fittings` / `clamps` |
| 5 | 关节盘插销和衬套看不到 | 叉耳 / 关节盘 / 横向销轴 / 衬套 / 球头销全部外露，髋膝踝三处都能直接看到球头球面 | `segments/{upper,lower}.ts` 的 `socket` / `ballhead` / `pin` / `bushings` |

### A.2 顺带修掉的判定器陷阱（写下来免得再踩）

这套框架的穿模判定用**奇偶射线**判"点是否在实体内"，所以下面几类几何会误报：

1. **窄孔深处**的采样点（球头销杆端插进凸台盲孔 12 mm）→ 射线大半打在孔壁上 → 判成"在实体内"。
   改法：杆端只压入安装端面 **0.3 mm**（低于 0.5 mm 检测阈），孔径缩到 2 mm。
2. **小件悬空 0.5~3 mm** 贴着平面 → 射线多半打在平面上 → 误判。
   改法：要么**沉 0.3 mm**（装配过盈），要么做成 0 mm 贴合，别留悬空缝。
3. **挤出件的 1.5 mm 倒角**会让"实际外表面"比设计尺寸大 1.5 mm → 附件按名义尺寸贴上去就穿模。
   改法：附件位置统一按**倒角后的真实外表面**算（骨段 48 mm 面 → 49.5 mm）。
4. 圆柱件的**原点在圆心**，不是底面 —— 贴面定位要按 `center = face + h/2` 算。

- 零件定义 **136 件 / 201 实例**（液压缸仍 11 件/缸 × 6 = 66 件）
- 静态穿模 **0**（未豁免）、24 帧屈伸扫掠穿模 **0**（未豁免）、悬空候选 **0**

## 附录 B. 第二轮返工：**腿形要 S 曲线，不能是直柱**（2026-10-20）

零件粒度够了，但侧视仍是一根直上直下的柱子 —— 问题不在零件多少，在**布置**。

### B.1 做法：骨段本体相对关节连线做 X 偏移

关节盘插销必须对准关节中心，所以**端板不能动**；能动的只有骨段本体。
于是给骨段 kit 加两个参数（`BONES.*.bodyX` / `endScale`）：

- 骨段本体（4 角柱 + 5 横撑环）整体前移/后移；
- 两端端板留在关节连线上（x=0），本体与端板之间由**双耳连接臂**搭起来；
- 端板可单独缩放：膝端 70%（收细成腰），髋端/踝端 100%/80%（腿段连得上）。

| 段 | 本体偏移 | 效果 |
|---|---|---|
| 股骨 | 前移 55 mm | 股四头肌弧度，前缘 +103 mm |
| 胫骨 | 后移 35 mm，踝驱动缸后置 | 小腿肚后凸，后缘 −81 mm |
| 膝端板 | 70% | 膝盖最细 |

### B.2 连带要处理的事

1. **贴面附件全部跟着本体走**：硬管、接头、管卡、护条、加强条、护罩、限位销、传感器
   都要按新的本体偏移重算位置（贴面间隙按 2.5 mm 留，否则判定器会在窄缝上误报）。
2. **安装凸台的模型坐标重排**：凸台局部 x = 模型 x（零件原点 = 节点 pivot，不是本体中心），
   本体前移后凸台必须仍落在本体截面内。
3. **交叉布置的膝缸力臂**：本体偏移差越大，交叉缸的 |AB| 越不对称；
   实测膝主缸行程升到 66.5 mm、膝前补偿缸降到 45.2 mm，靠调 `lc/lr` 把余量补回来
   （杆端余量必须 > 5 mm，否则缩回时杆端顶缸底）。
4. **同心配合面统一放大间隙**：铰链销 φ27（孔 φ33）、耳环孔 φ32（球 φ24）——
   窄缝里的采样点奇偶射线判定不稳，会把正确的配合面误判成穿透。
5. **关节插销配合登记为构造性接触**（`expectedContacts` 豁免族）：
   关节盘插销插进骨段端板插座、叉耳舌片插进骨段端板，都是装配配合面，不是错位穿透。

### B.3 这一版的结果

- 静态/24 帧扫掠**未豁免穿模 0**、悬空 0、液压行程 PASS、tsc 干净、vitest 116 通过
- 中心线：髋 0 → 大腿 +55 → 膝 0 → 小腿 −35 → 踝 0 → 足前伸（S 形 ✓）
- 膝关节收窄到 70%（大腿 96 mm / 小腿 92 mm → 膝 67 mm ✓）

## 附录 C. 第三轮返工：**腿要有肉，不能是脚手架**（2026-10-20）

第二轮之后机构确实外露了，但整条腿读起来仍是一根**细长的脚手架**——
问题不在"露不露"，在**露出来的东西没有体积**。

### C.1 关键认知

> "外露"≠"细杆架子"——**外露的是饱满的液压肌肉块 + 连接的骨架**。
> 液压缸机构本身就是肌肉（鼓鼓的缸体 = 股四头肌 / 腓肠肌），骨架在肌肉之间连接。

### C.2 三处改动

1. **缸体改成纺锤形"肌肉块"**（`segments/cylinder.ts` 的 `muscleProfile`）：
   外形按 `r(t) = rEnd + (rMax − rEnd)·sin(πt)` 鼓胀（两端收细、中间最粗），
   内膛仍等径做活塞导向面 —— 外形是肌肉，内里还是液压缸。
2. **缸径整体放大**（φ42~52 → φ80~92）：髋缸 88、膝主缸 92、膝前补偿缸 80、踝缸 88。
   腿的横截面因此从"竹竿"变成约 **270 mm 宽的肌肉块**。
3. **缸块摆到解剖位置**：膝主缸缸体落在大腿中段（股四头肌）、
   踝驱动缸落在小腿中段（腓肠肌）、髋缸落在骨盆与大腿之间。
   配合缸径放大后，侧视轮廓就是"大腿前凸 → 膝收细 → 小腿后凸 → 踝再前"的起伏曲线。

### C.3 连带要处理的

1. **缸内零件的配合间隙要重算**：缸膛改 `rBody × 0.48`、活塞 `缸膛 − 1mm`、
   杆径 `rBody × 0.42`；缸底盖/导向套/卡箍都按新的收细半径 `rEnd = 0.72·rBody` 缩放
   （卡箍必须坐在缸体收细的根部，否则会插进鼓胀段）。
2. **杆长比例 `lr` 要重新配平**：缸体加长后活塞会顶出缸口，
   踝缸 `lr` 0.42 → 0.55，保证"活塞不出缸（余量 > 5mm）且杆端不脱缸"。
3. **缸内零件的互相配合登记为构造性接触**（`expectedContacts` 里的
   `t800-cylinder-fit` 族，前缀模式 `t800.shin.cyl_ankle_l_*`）——
   注意白名单的 id 模式**必须以 `*` 结尾**才是前缀匹配，否则会被当成精确 id。
4. **扫掠测试要加超时**：肌肉块让几何量翻倍，13 帧扫掠从 2s 涨到 5s+，
   vitest 默认 5s 超时会误报失败（是超时不是穿模）。
5. 膝主缸 A 端上移到 y=1.03、踝缸 A 端上移到 y=0.46：让肌肉块落在正确的高度。

### C.4 这一版的结果

- 静态未豁免穿模 0、24 帧扫掠未豁免穿模 0、悬空 0、液压行程 PASS
- 膝主缸行程 80.5 mm、膝前补偿缸 45.2 mm、踝缸 19.6 mm、髋屈曲缸 50.9 mm、髋伸展缸 24.0 mm
- 存档：侧视 9 帧 + 正视 2 帧 + 斜 45° 2 帧（`docs/qa/t800/views/`）

## 附录 E. 第四轮返工：**腿的形体 + 性能**（2026-10-21）

### E.1 形体：参考图里腿是"有体积的曲面装甲"，不是等截面梯笼

上一轮只把材质/密度改对，**体量**还是错的。补三件事：

1. **外侧曲面装甲板**（`t800ArmorShell`）：按层轮廓（y / 半宽 / 外鼓 / 前缘鼓 / 后缘鼓）
   放样出带厚度的曲面壳。关键是**并入骨段 kit** —— 装甲板与安装凸台属于同一零件，
   凸台从装甲中穿出（参考图就是这么做的），判定器不再把"凸台穿板"算成互侵。
   · 股骨：髋侧半宽 85mm → 膝侧 62mm，**前缘中段鼓 20mm**（股四头肌的肚子）
   · 胫骨：膝侧 50mm → 腓肠肌中段 66mm（**后缘鼓 24mm**）→ 踝侧 48mm
2. **机构退到内侧**：所有驱动缸的安装凸台放 -Z 侧，外侧留给装甲板 —— 参考图是
   "外皮盖机构"，外露机构在正/背面看得到。
3. **膝/踝改紧凑盘组**：叉耳换圆盘（`t800RoundCheek`）、下骨本体上沿下移 12mm 腾出盘面。

顺带补的两点外观：曲面轮廓采样 9 → 24 段（消除可见折线）、新增 `mirror` 镜面铬材质
（关节盘/球头座/销轴，参考图里这两三个圆盘是最亮的焦点）。

### E.2 性能：卡一秒的元凶是**控制台刷屏**，不是模型

排查过程：

| 嫌疑 | 实测 | 结论 |
|---|---|---|
| 模型装配 | buildModel **54ms**、11 万三角面、每帧同步 0.05ms | 不是瓶颈 |
| 着色器编译 | 切回 T-800 首帧 1525ms | 是 |
| **控制台输出** | Long Task 显示一条 1563ms 的长任务 | **真凶** |

`three-mesh-bvh` 求交时遇到**共面**三角形会打一条 `console.warn`；一台 11 万面的模型
几何里大量"贴合面"对 → 几万条警告把主线程堵死一秒。修法（`solver/detect.ts` 的
`withCoplanarWarningsSilenced`）：精检窗口内静音这类警告，检完立刻还原，其余照常输出。

同时把渲染预算压下来（观感不变）：

- `dpr` 上限 2 → 1.5（高分屏像素量少 44%）
- 后期 MSAA 4 → 2，并**去掉 N8AO 全屏环境光遮蔽**（接地阴影 + 环境暗底已交代体量关系）
- 阴影贴图 2048 → 1024、环境反射 256 → 128、接地阴影 512 → 256

结果：T-800 满载 140 件时 **60fps**（RTX 5070 Ti），模型就绪 10ms。
