## 二、核心难点：合体插接机构（全场最重要）

4 对插接面（头↔胸、胸↔腹、腹↔腿 + 双臂↔胸），每对是**真实机构**：
- **锥形导向销**（先粗对准）→ **圆柱定位销**（再精定位）→ **端面贴合** → **锁环咬合**（旋转锁死，"咔哒"）→ 对接传感器

**合体序列（阻尼感 + 电弧——用户点名的灵魂）**：
```
编队接近（快）→ 逐对对接（腿→腹→胸→头，自下而上），每对三段式：
  ① 接近段：巡航速度
  ② 临近段（阻尼感）：ease-out 强减速——越近越慢，末端小幅横向找正微颤
  ③ 电弧接通：对接面间跳起电弧链（多点闪电"啪"）——能量先连
  ④ 咬合段（慢而有力）：锥形销入槽（带涩感，一顿一顿）→ 锁环旋紧
  ⑤ 锁死："咔哒" + 轻微回弹
→ 全部锁死 → 机器人形态立起 → 关节激活
```
- 阻尼感：非线性减速 + 末端找正微颤 + 咬合涩感（**不许匀速**）
- 电弧：对接面 3-5 条电弧链 + 边缘微光；分离时电弧**拉断熄灭**
