# T-1000 设计计划（液态金属——框架的"无零件"边界突破）

> 验证框架最激进的维度——**没有零件的装备**。零件化框架假设"装备=刚性零件装配"，T-1000 打破它：装备=一团可变形的液态金属。
> 做成了，框架从"装配系统"升维成"物质系统"。

## 0. 变形再生三人组（三种哲学）

| 装备 | 哲学 | 技术 |
|------|------|------|
| 金古桥 | 主动分合（机构） | 插接咬合 + 电弧阻尼 |
| 英普莱扎 | 打碎后长回来（再生） | 断口蠕动生长 |
| **T-1000** | **本来就是液体（无形）** | **液滴聚合 + 液态变形** |

## 1. 核心概念：液态金属团 + 形态库

- **物质基础**：一团拟态多元合金（mimetic polyalloy），铬色镜面
- **形态库**：人形（默认）/ 刀刃手臂 / 尖刺 / 地板摊平 / 穿栏杆局部液化流 / 拟态他人
- **形态切换 = 液态变形**：人形↔任何形态之间不是硬切，是液态流动过渡（铬面融化→流动→重凝）

## 2. 它的"零件"是什么

T-1000 没有螺栓装甲板——它的"零件"是**液滴**（实例化的液态金属珠）：
- **常态（人形）**：一个整体液态体，按人形刚体动画（走/跑/格斗/射击）——此时"一个零件"
- **打碎/变形时**：解体成 **N 个液滴**（实例化，每滴有质量/体积）——液滴即"零件级"
- **再生/成形**：液滴相互引力 → 沿地面流动（水银珠聚拢）→ 融合 → 重新立起成形

框架新增物质类别 `fluid_body`（与 rigid 零件并列），注册表记"总质量 + 形态库"，不是刚性位置。

## 3. 技术实现（诚实标注难度）

| 效果 | 技术 |
|------|------|
| **液滴聚合** | **Metaball 融球**（N 球等势面，marching cubes）——水银融合经典做法 |
| **液态变形** | 形态间 morphing + 液态过渡（表面先融成液团再重凝） |
| **液滴流动** | 液滴粒子物理（沿地面滚动/流动，相互吸引） |
| **表面质感** | 铬色镜面着色器（高反射环境贴图）+ 流动涟漪 |
| **穿栏杆** | 局部液化：身体局部碎成液滴流过障碍 → 另一侧聚合 |

**难度诚实说**：Metaball 实时光滑流体最贵（marching cubes 每帧重建表面）。
**降级方案**：液滴用实例化小球（不融合，靠数量堆"聚拢"感）+ 成形用裁切生长——
视觉仍能出"液态重聚"，性能可控。**先降级版验证概念，Metaball 作 V2。**

## 4. 招牌场景（全做成可玩）

| 场景 | 实现 |
|------|------|
| **穿栏杆追击** | 人形到栏杆前 → 胸腹局部液化流过 → 另一侧重凝继续追 |
| **中弹出洞愈合** | 中弹处开洞 → 洞缘液态蠕动 → 流回填满 → 镜面恢复 |
| **手臂变刀刃** | 手臂液态流动 → 重凝成刀刃/尖刺 |
| **拟态** | 接触目标 → 全身液态流动 → 重凝成对方外形（渗透欺骗） |
| **地板长出** | 一滩液态 → 人形从液堆里"立"起来（最经典镜头） |

## 5. 受击与弱点（怎么杀死"杀不死"的）

- **常规物理伤害几乎无效**：枪打出洞→愈合，打碎→液滴聚合——压迫感来源
- **弱点：极端温度**（原作设定）
  - **液氮冻结**：液态变脆 → 此时打碎 → 液滴难聚合（冻住的液珠聚拢极慢）
  - **钢水/高温**：熔化失控 → 形态疯狂乱变 → 彻底熔化死亡
- **战术**：常规火力只能迟滞，**温度武器才是真杀**（液氮/燃烧单位克制 T-1000）

## 6. 质感层（L5——液态金属的皮）

| 层 | 内容 |
|----|------|
| 材质 | **完美铬色镜面** + 流动时表面涟漪 |
| 拟态 | 拟态人形的**布料/皮肤质感**（拟态警察——制服纹理）+ **恐怖谷瑕疵**（稍微不对劲，"它是假的"暗示） |
| 液态 | 液滴水银质感 / 变形流动光泽 |
| 战场 | 冻结"脆化霜冻"纹 / 高温熔化失控变形纹 |

### 深度细化（特殊：深度不在零件，在流体行为）
- **流体行为**：液滴表面张力 / 聚合力场 / 形态切换过渡帧 / 流动涟漪 / 剖切时液态断面
- **拟态细节**：拟态人形的"假内部"（剖开是液态不是内脏）/ 布料纹理 / 恐怖谷瑕疵
- **质感**：铬镜面环境反射 / 冻结脆化纹 / 熔化失控纹

## 8. 一句话

金古桥让你看到"机器怎么合体"，英普莱扎让你看到"机器怎么愈伤"，
**T-1000 让你看到"机器可以没有形状"**——
当一团水银从地板液滴里聚拢、立起、凝成人形看着你时，
零件化框架就证明了它能造的最后一种东西：物质本身。
