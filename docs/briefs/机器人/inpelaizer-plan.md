# 英普莱扎（Inpelaizer）设计计划（零件级 · 打散→再生）

> 安培拉星人"无双铁神"量产机器人。**按 T-800 零件级标准**：每个液压缸 7-9 件、每个关节逐件、每块装甲板独立、再生核心拆内构。
> 核心能力：**被打碎后自我重组再生**——再生 = 装配秀的战时形态（战损打碎 + 逆向归位 + 重组复验）。
> **~520 定义件 / 实例数千**。

## 0. 设计原则

- **零件级粒度**：碎的时候按这个粒度飞，才有"碎"的感觉（碎裂感 = 粒度 + 断面有料）
- **每块装甲板独立 partId**：这是"能被打碎"的前提
- **再生核心是唯一要害**：躯干深处发光体，碎它才真死

## 2. 核心系统：再生（全场技术核心）

> **关键设计决策**：不给每个零件做"碎块模型"（工作量爆炸）——
> 改用**两级碎裂 + 双路再生**：

```
击毁 → 零件级解体，分两路：
   · 大块结构（臂/腿/躯干大件）：物理飞散成几大块落地（件级，可飞回）
   · 零件级碎裂（装甲板碎块）：不建碎块模型，只留断口/残缺基底
 → 再生核心检测（核心完好=可再生；核心被毁=真死）
 → 再生启动：
   · 大块残骸：按 partId 查注册表飞回原位（复用装配秀编排：大件慢、按 build_order 归位）
   · 碎裂零件：断口"蠕动生长"——裁切平面从断口推进 + 表面噪声蠕动（液态/有机感）
     + 生长前沿微光裁切边 → 像长出来一样长成原样
 → 修复完成：表面一道微光扫过（克制：仅核心/大件接合处给微光，不全件发光）
 → 重组复验：自动过穿模检测（组装正确性自动验证）
```

**实现要点**：
- **碎裂零建模**：零件碎了只标"已损毁"+ 显示残缺断口，不建碎块模型
- **蠕动生长着色器**：裁切平面推进（复用打印生长）+ 顶点噪声扰动（液态感）
- **双质感**：骨架大件机械飞回（重量感）+ 表面零件有机生长（诡异感）——骨与肉两种质感
- **碎片记忆**：注册表即"记忆库"，碎件记得自己 partId 和原始位姿

## 3. 再生循环（怎么杀死"不死"的机器）

| 阶段 | 表现 |
|------|------|
| 第 1 次击毁 | 打碎 → 再生（快） |
| 第 2-N 次 | 再生越来越慢（核心能量耗）+ 复原后动作略僵（残留损伤累积，**再生疤痕**） |
| 致命 | **击中再生核心**（躯干深处发光体）→ 核心碎 → 残骸不再飞回 → 真死 |
| 战术 | 打碎它只是争取时间，**趁重组时核心暴露窗口补刀**才是真杀 |
