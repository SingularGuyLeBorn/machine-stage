# 这把冲锋枪浑身都是伤，但每一道划痕都在讲故事

- 公众号: AnimationStudio

作品欣赏

俯视角，一把灰黑色的块状冲锋枪占满画面，装甲板拼接处的缝隙和磨痕比枪口本身更先抓住视线。

![image](images/01.jpg)

这是概念艺术家 Ivo Panczel 为废土题材项目 **SALVAGE** 设计的冲锋枪——代号 **the Hound**。整把枪没有任何多余的装饰线条，所有结构都服务于一个词：耐用。

换一个角度，角形装甲的轮廓变得更加明确，戏剧性的侧光把每一道凹槽都推到前景。

![image](images/02.jpg)

![image](images/03.jpg)

右侧大面积留黑，金属表面的油污和划伤被定向光一层层剥开——这种克制的构图反而让重量感翻倍。

正面对称视角，整把枪的结构逻辑一览无余。瞄具处透出一点琥珀色的光，是全图唯一的暖色，像是废墟里还没熄灭的信号灯。

![image](images/04.jpg)

<video src="videos/01.mp4"></video>

转动之间，哑光金属上的锈迹和磨损层次比静帧里更丰富，"回收"这个概念直接写在了材质语言里。

![image](images/05.jpg)

![image](images/06.jpg)

黑暗背景把枪体完全隔离出来，庞大而沉默。没有 HUD，没有弹道轨迹，只有一件被反复修补过的工具。

![image](images/07.jpg)

![image](images/08.jpg)

最后这个角度几乎能闻到机油味——加固件、铆钉、焊接痕迹层层叠叠，每一处都在说同一件事：这把枪活过很多场战斗，而且还会继续。

想了解 SALVAGE 的完整世界观，可以去看看项目官网：playsalvage.com。
