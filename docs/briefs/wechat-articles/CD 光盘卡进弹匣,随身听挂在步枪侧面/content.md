# CD 光盘卡进弹匣,随身听挂在步枪侧面

作品欣赏

Lin Hongy 做了一把 AN94 皮肤,灵感来自 2000 年前后的电子产品。

![image](images/01.jpg)

白蓝配色,机身外壳用硬表面分件拼出 Y2K 塑料质感,表面带磨损划痕和油污。"CHORD" 全息显示屏发光,金属件和哑光塑料形成对比。

![image](images/02.jpg)

硬表面结构拆成大量精密分件,蓝紫和银白涂层在边缘磨损处露出底材。电路线条、刻度盘、散热格栅和弹匣底部的圆形组件,强化了光电磁功能感。

![image](images/03.jpg)

靠近玩家视角的核心区域嵌入了随身听元素。实体 CD 光盘、机械卡扣和青色数字显示屏,呈现出早期赛博朋克美学。检视时更换光碟,播放专属 BGM 并显示特效。

![image](images/04.jpg)

蓝白外壳搭配裸露弹簧、导轨和线缆,金属表面带磨损划痕和油污。发光的青色 "CHORD" 显示屏与全息刻度形成冷暖对比。

![image](images/05.jpg)

两支枪和散落弹药,白色与电光蓝涂装,表面覆盖电路纹理。模块化分件与复杂管线衔接,锐利倒角和金属高光反射营造精密感。

![image](images/06.jpg)

银灰与深蓝金属硬表面,磨损划痕和油污明显。全息显示屏、蓝色能量环和光盘组件,配合背景悬浮的霓虹 UI 界面。

局内可播放 BGM,达成连杀时切换成更高潮的配乐。

![image](images/07.jpg)

参考图拼贴:上半部分是索尼 Walkman、PSP 的银色阳极氧化铝外壳和圆形按键布局,下半部分混合了高饱和度平面排版、机械连杆示意图和霓虹光带建筑渲染。设计通过点线面图形拆分重构,尝试空间立体构成与武器工造、无机平面图形的结合。
