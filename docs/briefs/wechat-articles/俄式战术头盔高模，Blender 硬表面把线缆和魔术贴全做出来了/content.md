# 俄式战术头盔高模，Blender 硬表面把线缆和魔术贴全做出来了

作品欣赏

Leonardo Betancur 正在做一顶俄式战术头盔的高模。硬表面部分全部在 Blender 里完成，布料则走 Blender + Marvelous Designer 的混合流程。目前还是 WIP 阶段，但细节密度已经相当可观。

![image](images/01.jpg)

黑底轮廓光把头盔表面的层次全拉了出来——PELTOR 通讯模块的品牌字样、线缆走向、魔术贴织带、硬质塑料卡扣，金属磨砂面和织物纹理之间的反差一眼就能分辨。

![image](images/02.jpg)

侧光扫过去，塑料导轨的锐利切面和螺丝孔位全部清晰可读。这种零件堆叠的密度，放在游戏资产里通常会被简化掉大半，但高模阶段就是要把信息量先堆满。

![image](images/03.jpg)

套在人头上之后，编织蒙皮的纹理和金属卡扣之间的软硬对比更明显了。护目镜压在眉骨位置，通讯线缆从耳侧绕到下颌，功能逻辑说得通。

![image](images/04.jpg)

左、正、右三个角度摆开，能看到导轨系统几乎绕了头盔一整圈，麦克风支架和护目镜支架各占一侧，魔术贴贴片填满了剩余的平面区域。

![image](images/05.jpg)

额头那块护目镜支架用了铰链加螺丝的厚重结构，侧面突出的圆柱模块像是夜视仪或传感器接口。裸露线缆没有刻意藏，反而成了视觉节奏的一部分。

![image](images/06.jpg)

后脑的绑带系统和尼龙蒙皮占了大面积，粗糙纹理压住了周围金属件的反光。

![image](images/07.jpg)

换个角度再看一遍，织物编织纹和哑光金属导轨之间的材质落差依然是最抓眼的地方。

![image](images/08.jpg)

Peltor 护耳上的品牌压印、编织线缆的穿插路径、卡扣的弹簧结构——每个零件都有独立的造型逻辑，不是贴个法线就完事的那种。

![image](images/09.jpg)

最后这张画风突变：粉色、淡蓝、黄色的柔和配色裹在同一个硬壳结构上，右上角的 UV 展开图暴露了面片拼接的密度。缝线细节说明布料部分确实走了 Marvelous Designer 的路子，拆出来再回 Blender 做硬边衔接。
