# 从手绘底色到金属高光，铜锈和骷髅一层层浮出枪身

作品欣赏

Ilia Bodaikin 画的那把 Precise Bolter 概念稿，被 Yelizaveta Valenda 一直记着，最后变成了她手绘风格化系列里的新作——一把完整的三维布尔特枪，属于战锤 40K: Rogue Trader 的同人创作。

![image](images/01.jpg)

纯 Albedo 状态下，没有金属反射也没有环境光干扰，手绘笔触直接摊在模型表面。黄铜纹样、骷髅浮雕、枪身暗色底漆之间的层次，全靠颜色本身撑住。

![image](images/02.jpg)

切到 PBR，金属高光和粗糙度一介入，整把枪的重量感完全不一样了。磨损堆在棱角和握持区，铜绿沿凹槽沉下去，光照把每一道刻线拎了出来。

![image](images/03.jpg)

法线、粗糙度、金属度各通道平铺开来。手绘风格化项目里，这些贴图的画法跟写实路线差别很大，笔触痕迹被刻意保留而不是抹平。
