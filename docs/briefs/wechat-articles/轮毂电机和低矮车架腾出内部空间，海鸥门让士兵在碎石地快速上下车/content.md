# 轮毂电机和低矮车架腾出内部空间，海鸥门让士兵在碎石地快速上下车

作品欣赏

![image](images/01.jpg)

Edon Guraziu 设计的 GRD® MTC 多用途运输底盘，核心逻辑是用一套可重构的自主平台完成人员、货物和重症护理的运输任务。

![image](images/02.jpg)

当前配置可载八人满编班组。轮毂电机配合低矮底盘架构，把传统传动系统占用的空间腾给有效载荷，车辆体积不变但内部容积更大。

![image](images/03.jpg)

海鸥门铰链设计让门板向上展开时越过门槛和车顶线，士兵可以在不平整或受损地形上快速上下车，不必绕过门板或低头钻进去。

![image](images/04.jpg)

360° 传感器阵列为车载推理系统提供数据，支持自主路径规划和战术机动，MTC 可以在战场上独立执行和重新分配任务。

![image](images/05.jpg)

模块化任务舱让这套自主能力适配外星球和远征后勤场景——补给稀缺时，任务成败取决于车辆本身，而非操作员。
