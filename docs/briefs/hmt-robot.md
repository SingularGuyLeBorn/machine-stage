# HMT 双足机器人：参考重建首版

用户选定的是 Vitaly Bulgarov 为 Hankook Mirae Technology 设计的深灰、红色人形机器人，对应文章的 13–18 图和 `robot3/2-xm-robotdesign` 系列。07–12 的竖屏头机器人、250cm v1/v3/v5 方案不参与这版外形。

## 本次范围

从图片建立程序化几何，接入展示台的模型库、零件树、构建回放、隔离查看、透视和爆炸拆解。没有源 GLB，也没有复用其它机器人的皮肤或造型。采用项目里的注册表、装配器和检测器。

整机分为头颈、胸廓、胸甲、背甲、三节腰椎、肩、双臂、手、骨盆、腿、脚共 11 个总成，420 个可选零件。胸甲和肢体的窗口具有厚度及孔壁；腰部、关节和作动筒单独成件。紧固件位置从所属护板曲面派生。双侧护板的拆解方向随镜像翻转。

2.4m 是图片比例归一化后的展示尺度，未从可靠尺寸图获得，不能当作真实规格。`HEIGHT` 同时驱动几何和装配位置。局部遮挡下的支座和紧固件数量属于估算，代码用 `[OM-FREEPLAY]` 标出。

## 检查

- 注册表校验通过；L1–L5 逐层静态穿模检查均为零，没有接触豁免。
- 胸甲射线检查：窗口贯通，旁边护板保有实体。
- 项目默认 20mm AABB 支撑检查：无悬空件；整机为一个连接分量。这是展示装配的粗检，不证明真实接触或可制造性。
- 1.8m 与 2.4m 展示尺度的几何及位置同步缩放。
- 双侧拆解方向相反，连续三次拆装后恢复原矩阵。
- 相关模型、目录与状态测试 41 项通过；修改文件 ESLint 通过；生产构建通过。
- 生产页面验证：爆炸还原、单件隔离与拆装、构建滑杆、模型切换及静态扫描通过。应用内浏览器发现的预热材质生命周期错误已修复并复验。

## 当前边界

这是可检查、可继续细修的静态参考重建首版。整体轮廓和关键分件已建立，复杂曲率、局部微结构、线束密度与原作仍有差距。未提供行走、关节驱动、连续运动碰撞验收、制造壁厚和加工公差。

后续视觉修订优先对照同机位的头颈、胸肩侧面和腿脚；保留已经确认的区域，通过同一套注册表修改。
