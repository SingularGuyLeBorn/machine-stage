## 实际修改

- 双臂在同一胸部坐标系中镜像。肩、肘的基本位置及肩后收关系保留，前臂与腕部整体内收：腕中心比肘中心向内 45mm。上臂正面偏角约 13.05°，前臂约 6.29°；肘仍在肩后，腕从肘向前下方回落。手掌随腕调整角度，避免指节与大腿相交。
- 骨盆向前 16mm；下腰与中腰局部角度改为 −28°、+39°，胸部作小幅补偿。腰段弯曲指标由 39.02° 增至 47.00°，没有增加整机后倾。腰节、斜撑、伸缩结构、线缆和端座共同随动。
- 上臂近肩端增加体量，肩根轴承与肱骨杆增强；肩甲宽度不变。大腿中上段外壳收窄，膝部轴承略增，双脚站距增加 24mm，脚掌接地。
- 胸部缩短中央竖板，增加左右独立主胸叠板，下胸逐步收窄；背部加入左右肩胛叠板和下背过渡。上臂壳体改用连续放样与较窄硬边，去除原有阶梯高光来源。
- 肩部线束重排为平行束，端点接回插座。腰背增加 8 个有实际连接用途的安装座与接头，线缆为这些端点留出活动余量。

当前实际装配为 **2,623 件、25,685,936 个三角面**。没有对展示几何减面。2.4m 仍是图片归一化的展示尺度，不是原作真实尺寸；遮挡区域的机构仍是参考推定，不能宣称逐面复刻。

## 修配与验证

修配器保留 0.22mm 展示尺度间隙，在最终 float32 导出精度下再次检测并修配残余交叠。刀具表面的数值清理只用于布尔运算，并补偿其容差，不改变展示模型的原始细分。最终保存 652 件的局部网格修改。

- 80 项相关测试通过，其中 7 项使用完整高密度装配；L1–L5 无穿模报告，不使用接触豁免，所有零件属于同一个有支撑的组件。
- 独立检查：2,623 件全部闭合；功能线束、弹簧、连杆和安装座均为单个连续材料实体；超过 10⁻¹²m³ 的实体交叠为零。内封闭螺钉空腔不误记成断开的材料。
- 双臂内收、前臂偏角小于上臂、左右对称、肩肘腕深度顺序、腰弧增强检查通过。两侧脚底最低点约为 −5.2×10⁻¹¹m，属于数值误差。
- 类型检查及生产构建通过；所改源码 ESLint 无错误。展示台仍有 4 条既有警告，生产包仍有体积提示。
- 15 件保留切除量超过 25% 的提示，12 件延续原有提示。新增为左右下腰前斜撑（约 36.31%、34.57%）和中腰节（29.16%）。这些零件连续且无实体交叠，切除量提示仍保留，未验证承载强度。明细见 `qa-out/redline-cut-review.json`。

## 重建

安装 `scripts/requirements-hmt.txt` 的依赖后，在工作树根目录执行：

```text
npx tsx scripts/export-hmt.ts --raw
python -X utf8 scripts/machine-hmt.py
npx tsx scripts/export-hmt.ts --runtime
npx vitest run src/three/parts/models/hmt
python -X utf8 qa-out/check-manifold.py
python -X utf8 qa-out/solid-overlaps.py
npx tsx scripts/verify-hmt-runtime.ts
blender -b -t 8 --python scripts/render-hmt.py
python -X utf8 qa-out/make-redline-comparisons.py
npm run build
```

加工器拒绝将已加工模型再次作为源，也检查源哈希和功能件连续性。生成源变化后必须重新加工和导出；`qa-out` 保存回退、诊断与实际装配产物。
