## 〇、电驱动坦克（先懂电动化）

电驱坦克 vs 柴油坦克的核心差异：
- **动力**：柴油机 → **电池组 + 驱动电机 + 电控**（电驱替代内燃机+变速箱）
- **电动特性**：**静音**（电机无声——隐蔽性）、**瞬时扭矩**（电机起步快）、能量回收、充电
- 没有发动机的轰鸣和排烟——安静、低红外

## 一、零件级拆分（自内向外）

### 1. 电动动力（核心，~200 件）
| 总成 | 零件 |
|------|------|
| **电池组** | **动力电池包×N**（电芯模组×N + 电池管理系统 BMS + 冷却板 + 外壳）——底盘布置 |
| **驱动电机×2** | 左右驱动电机（电机定子+转子+外壳+冷却）——双电机独立驱动左右履带（**电动差速转向**）|
| **电控** | 电机控制器（逆变器）/ 整车控制器 / 高压配电盒 / **充电口**（快充）|
| **高压系统** | 高压线束（橙色高压线）/ 低压系统（12V 控制）|
| 冷却 | 电池/电机冷却（液冷板 + 冷却泵 + 散热器）|

### 2. 行动（~300 件）
- 履带（零件级：履带板/销/负重轮）+ 主动轮 + 诱导轮 + 悬挂——电机驱动主动轮

### 3. 车体 + 炮塔（~200 件）
- 车体（电驱布局——电池包底盘）+ 炮塔（主炮/自动装弹机/火控——同主战坦克）
- 复合装甲 / 反应装甲

### 4. 内饰（~100 件）
- 驾驶舱（电动仪表——电量表/功率表替代转速表）+ 战斗室

## 二、电动特性交互（特色）

- **静音行驶**：电机驱动**没有发动机轰鸣**（隐蔽）——安静滑行
- **瞬时加速**：电机瞬时扭矩（起步快，无换挡顿挫）
- **电动差速转向**：左右电机独立控速 → 灵活转向（比机械差速更灵）
- **能量回收**：制动/下坡回收电能
- **充电**：充电口接充电桩充电（电量管理——电池包电量）
- **电池受击**：电池包被击中 → 热失控起火（电动坦克的战损特色）

## 三、质感

- 电驱细节（橙色高压线束/电池包/充电口）+ 新能源涂装 + 静音感（无排烟）
