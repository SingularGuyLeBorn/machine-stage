# 航母拦阻装置（Arresting Gear）· 超详细零件级

> 拦阻装置——舰载机着舰时用**拦阻索拉住飞机**，在 ~100 米内把 ~20 吨、~240 km/h 的飞机拉停。
> 航母降落的核心（甲板太短，飞机靠拦阻索强制停下）。
> 参考真实拦阻装置（尼米兹 Mark 7 / 福特 AAG 先进拦阻）。

## 〇、工作原理（先吃透）

舰载机着舰**不依赖刹车**（甲板太短），靠拦阻索 + 液压拦阻机：
```
拦阻索横跨降落区甲板（4 道，间隔 ~12m）
 → 舰载机进近，【尾钩】放下
 → 着舰瞬间，尾钩【钩住】某道拦阻索
 → 拦阻索被飞机拖着向前拉 → 索两端经滑轮导入甲板下的【拦阻机】
 → 拦阻机（液压阻尼/涡轮）拉住索——给索一个可控的阻力 → 飞机被拉停
 → 飞机停 → 尾钩脱索 → 拦阻索复位（回收到位）
```
关键：索被拉出时拦阻机提供**可控阻尼**——把飞机的动能在 ~100m 内耗散掉。

## 一、零件级拆分（~180 件，逐件）

### 1. 拦阻索系统（甲板上的索）
| 零件 | 说明 |
|------|------|
| **拦阻索×4** | 横跨降落区甲板的钢索（4 道，间隔排列——飞机钩哪道都行）|
| **索支撑弹簧片** | 索下的弓形弹簧片（把索抬离甲板 ~10cm，让尾钩能钩住；飞机压过时弹簧片被压倒）|
| 索端连接件 | 索两端的连接/固定 |
| 索导向轮 | 索两端导入甲板边缘滑轮的导向 |

### 2. 甲板下拦阻机（核心阻尼机构——拦阻的"功力"在这）
| 零件 | 说明 |
|------|------|
| **滑轮组** | 索两端经滑轮组（多组滑轮，把索的直线运动导入拦阻机）|
| **拦阻机液压缸** | 液压缸——索拉活塞，液压阻尼吸收能量（**拦阻的能量耗散在这**）|
| **节流阀** | 液压缸的可调节流阀（按飞机重量/速度调阻尼）|
| **蓄能器** | 液压蓄能器（缓冲）|
| 复位机构 | 拦阻后活塞/索复位 |
| （福特 AAG：涡轮+电机能量回收——可选进阶）|

### 3. 拦阻网（应急）
| 零件 | 说明 |
|------|------|
| **应急拦阻网** | 降落区末端的网（尾钩失效/紧急情况时升起兜住飞机）|
| 网支柱 | 网两侧的支柱（可升降）|
| 升降机构 | 网平时放下，应急时升起 |

### 4. 助降配合（降落引导）
| 零件 | 说明 |
|------|------|
| **菲涅尔透镜助降器（"肉丸"）** | 舰艉的光学助降器（给飞行员目视下滑道指示——光球）|
| 进近灯光 | 甲板进近灯光系统 |
| 着舰指挥官位（LSO） | 舰艉左侧 LSO 平台 |

## 二、拦阻降落动画（完整流程，核心）

```
舰载机进近（助降透镜引导下滑道，尾钩放下）
 → 触舰瞬间：尾钩钩住某道拦阻索（钩住/钩空两分支）
 → 拦阻索被飞机拖出（液压拦阻机阻尼——飞机重重点头 + 急剧减速）
 → 飞机停住（~100m 内）→ 尾钩脱索 → 拦阻索复位
（钩空 → 复飞：飞机开加力重新拉起）
```
- **尾钩钩索瞬间**（钩住的机械动作）
- **索被拉出的阻尼感**（飞机冲击 + 液压拉住 + 急剧减速）
- **钩空复飞**分支（没钩住要复飞——真实着舰有复飞率）

## 三、细节/质感

- 拦阻索的钢索质感 + 支撑弹簧片；甲板下拦阻机的液压缸/滑轮
- 索被拉出的拉伸；甲板上的磨痕（索拖过的痕）
