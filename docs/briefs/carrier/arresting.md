# 拦阻装置（Arresting Gear）· 飞行甲板 · 零件级

> 拦阻装置——舰载机着舰时用**拦阻索拉住飞机**减速停住。航母降落的核心（甲板太短，飞机靠拦阻索停下）。

## 〇、工作原理（先懂）

舰载机着舰不刹车（甲板太短），靠**拦阻索**：
```
舰载机进近 → 尾钩放下 → 着舰瞬间【尾钩钩住横在甲板上的拦阻索】
 → 拦阻索被飞机拖着拉出 → 甲板下拦阻机（液压阻尼）拉住索 → 飞机被减速停住
 → 尾钩脱索 → 拦阻索复位
```

## 一、零件级拆分（~150 件）

| 总成 | 零件（逐件） |
|------|------------|
| **拦阻索** | **拦阻索×4**（横跨甲板降落区的钢索，间隔排列）/ 索端连接 / 支撑弹簧片（索离甲板略抬高）|
| **滑轮/导向** | 滑轮组（拦阻索两端导入甲板下）/ 导向轮 |
| **拦阻机**（甲板下） | **液压拦阻机**（液压缸+阻尼——拉住索减速）/ 拦阻机活塞 / 蓄能器 / 滑轮组 / 缓冲器 |
| **拦阻网** | 应急拦阻网（可升起——尾钩失效时用网兜住飞机）/ 网支柱 / 升降机构 |
| **复位** | 拦阻索复位机构（拉出后收回）|
| 助降配合 | 菲涅尔透镜助降器（"肉丸"）+ 进近灯光（配合降落）|

## 二、机构运动/交互（拦阻降落动画）

```
舰载机进近（助降透镜引导）→ 尾钩放下 → 触舰瞬间【尾钩钩住拦阻索】
 → 拦阻索被拉出（液压阻尼，飞机重重点头+减速）→ 停住 → 脱钩 → 拦阻索复位
```
- **拦阻索被拉出的阻尼感**（飞机冲击 + 液压拉住）
- 尾钩钩索的瞬间（钩住/钩空复飞——钩空要复飞）
