# 航母升降机（Aircraft Elevator）· 超详细零件级

> 航母升降机——舰载机在**飞行甲板 ↔ 机库**之间垂直运输的大型升降平台（舷侧/舷内）。
> 能承载一架舰载机（~30 吨）升降。

## 〇、作用与结构（先懂）

升降机 = 甲板边缘的大平台（舷侧式/舷内式），把舰载机从机库升到甲板（或反之）。
```
机库里舰载机推上升降平台 → 平台升到飞行甲板 → 舰载机推出到甲板
```

## 二、机构运动/交互动画

- **升降流程**：舰载机推上平台（机库层）→ 护栏收起 → 平台升（液压/卷扬——阻尼感：启动慢→匀速→减速到位）→ 到位锁定 → 护栏放下 → 舰载机推出（到甲板）
- **承载**：承载一架舰载机（~30 吨）的重量感（平台下沉/液压支撑）
- **阻尼感**：大平台升降的"重"感（启动慢、稳、到位停）

## 三、受击/质感

- 受击：平台中弹 / 液压失效（平台卡住）
- 质感：平台甲板面 / 液压机构 / 舷侧开口

## 四、验收

- [ ] 零件级 ~180 件：平台/导轨/驱动/安全/开口逐件
- [ ] **升降动画**（机库↔甲板，载舰载机，阻尼感——启动慢→匀速→减速到位）
- [ ] 承载重量感（~30 吨舰载机）
- [ ] 安全联锁（到位锁定/护栏联动）
- [ ] 零穿模零悬空；commit 带原因；升降录屏
