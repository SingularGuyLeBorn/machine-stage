# 航母舰岛（Island）· 超详细零件级

> 航母舰岛——右舷的"指挥塔"：舰桥（航海/航空/司令）+ 相控阵雷达 + 桅杆 + 烟囱 + 近防武器。
> 舰岛是航母的"大脑 + 眼睛"——指挥和雷达都在这。

## 〇、舰岛结构逻辑（先懂）

舰岛 = **航海舰桥**（开船）+ **航空舰桥**（管飞机起降）+ **司令舰桥**（编队指挥）+ **相控阵雷达**（眼睛）+ **桅杆**（天线）+ **烟囱**（常规动力排烟）+ **近防武器**。
福特级/福建舰的舰岛更小更隐身（一体化）。

## 一、零件级拆分（~350 件，逐件）

### 1. 舰岛结构（多层）
| 零件 | 说明 |
|------|------|
| 舰岛主体 | 多层结构（内倾隐身外形）|
| 各层平台 | 舰岛各层平台/梯 |
| 支撑结构 | 舰岛与甲板连接的支撑 |

### 2. 舰桥（三层）
| 零件 | 说明 |
|------|------|
| **航海舰桥** | 驾驶室（玻璃窗×N + 操舰控制台 + 海图桌 + 车钟/舵令）|
| **航空舰桥** | 航空指挥（着舰指挥官 LSO 位 + 甲板调度——管飞机起降）|
| **司令舰桥** | 编队指挥（司令位 + 指挥显控）|
| 玻璃窗×N | 舰桥舷窗（防弹玻璃）|

### 3. 雷达（舰岛的眼睛）
| 零件 | 说明 |
|------|------|
| **相控阵雷达×4** | 四面相控阵面板（见 radar-phased-array.md）|
| **旋转搜索雷达** | 对海/对空搜索雷达（**可旋转**——转的那个）|
| 导航雷达 | 导航/着舰雷达 |
| 火控雷达 | 近防武器的火控雷达 |

### 4. 桅杆 + 天线
| 零件 | 说明 |
|------|------|
| 主桅杆 | 桅杆（装天线）|
| **鞭状天线×N** | 通信/电子战天线（桅杆上的鞭状天线，实例化）|
| 卫星通信天线 | 卫通天线罩（球形）|

### 5. 烟囱（常规动力）
| 零件 | 说明 |
|------|------|
| 烟囱 | 排烟（燃气轮机/锅炉——红外抑制）|
| 排烟口 | 排烟口（降温/红外抑制）|

### 6. 近防武器（舰岛上/周边）
- 近防炮（1130——见 ciws-1130.md）/ 防空导弹发射架 / 干扰弹

## 二、机构运动/交互

- **旋转雷达**：搜索雷达转动（机械旋转——和相控阵不转对比）
- **航空舰桥**：着舰指挥（LSO 指挥飞机降落）
- **航海舰桥**：操舰（车钟/舵令）
- 近防武器（1130 开火/导弹发射）

## 三、质感

- 舰岛海军灰 + 隐身外形 + 玻璃窗（舰桥）+ 天线 + 雷达面板质感
