# 相控阵雷达（Phased Array Radar）· 舰岛 · 超详细零件级

> 舰岛四面相控阵雷达（中华神盾 346 / 宙斯盾 SPY-1 级）。
> 原理：**不机械转动天线**，靠成百上千个收发单元的**相位控制**电子扫描波束——比机械转快几个量级，同时跟踪数百目标。
> 参考真实舰载相控阵结构。

## 〇、工作原理（先吃透）

```
天线阵面 = 成百上千个【T/R 收发单元】（移相器+辐射单元）排成的阵列
 → 波束合成：控制每个单元的【相位】→ 各单元的电磁波在空间叠加
   同相叠加的方向 = 波束指向（改相位 → 波束转向，不用动天线）
 → 电子扫描：波束在微秒级内转向任意方向（机械转要转几秒）
 → 同时多目标：波束快速跳扫/分时多波束
```

## 一、零件级拆分（~250 件，逐件）

### 1. 天线阵面（舰岛四面，每面一阵）
| 零件 | 说明 |
|------|------|
| **T/R 收发单元×N** | 阵面的收发单元（成百上千个，**实例化阵列**）——每单元：移相器 + 辐射单元（振子/贴片）+ 收发组件（功放+低噪放）|
| 阵面框架 | 阵面的结构框架（固定 T/R 单元）|
| 阵面罩 | 天线罩（透波材料，防盐雾/防雨）|
| 水冷板 | 阵面后的水冷板（T/R 单元发热大——功放发热）|
| 阵面安装 | 阵面倾斜安装座（固定仰角，贴合舰岛）|

| 电源分配 | T/R 单元的供电分配网络 |

## 二、机构运动/交互（电子扫描可视化）

- **电子扫描演示**：天线**不转**，波束靠相位控制——可视化：阵面上波束指向随相位变化（波束摆动的可视化——扫描线/波束方向指示）
- **多目标跟踪**：同时跟踪多个目标（电子扫描优势——波束快速跳扫）
- **四面阵 360°**：舰岛四块阵面各管 90°，合起来 360° 无死角
- **对比旋转雷达**：舰岛上还有一个**机械旋转**的对海/补盲雷达（那个转）——区分：相控阵固定不转 + 旋转雷达转

## 三、受击/质感

- 受击：阵面被打坏（部分 T/R 单元失效→阵面"破洞"→性能下降）/ 水冷漏
- 质感：阵面罩的复合材料 / T/R 单元阵列细节 / 舰岛金属
