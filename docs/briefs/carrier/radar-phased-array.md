# 相控阵雷达（Phased Array Radar）· 舰岛 · 零件级

> 舰岛四面相控阵雷达（中华神盾/宙斯盾级）。原理：**不用机械转动天线**，靠成百上千个收发单元的**相位控制**电子扫描波束。
> 参考真实舰载相控阵（346 型/SPY-1）。

## 〇、工作原理（先懂）

相控阵雷达 = 电子扫描（不转动）：
```
天线阵面 = 成百上千个 T/R 收发单元（移相器）排列成阵
 → 控制每个单元的相位 → 波束在空间合成 + 指向可控（电子扫描，不用转天线）
 → 同时跟踪多目标（电子扫描比机械转快得多）
```

## 一、零件级拆分（~200 件）

| 总成 | 零件（逐件） |
|------|------------|
| **天线阵面**（舰岛四面） | 阵面框架 / **T/R 收发单元×N**（成百上千，**实例化**——移相器+辐射单元+收发组件，排成阵列）/ 阵面罩（天线罩）/ 水冷板（T/R 单元发热）|
| **馈电/波控** | 馈电网络 / 波束控制器 / 移相器驱动 / 电源分配 |
| **信号处理** | 接收机 / 信号处理机柜 / 发射机 / 电源机柜（舰岛内部机柜间）|
| **冷却** | 水冷系统（T/R 单元发热大）/ 泵 / 管路 |
| **阵面结构** | 阵面框架 / 支撑 / 与舰岛连接座 / 阵面倾斜安装（固定仰角）|
| **辅助** | 敌我识别天线 / 气象雷达 / 导航天线 |

## 二、机构运动/交互

- **电子扫描演示**：波束**不转动天线**，靠 T/R 单元相位控制——可视化：阵面上波束指向随相位变化（波束摆动的可视化）
- **多目标跟踪**：同时跟踪多个目标（电子扫描优势）
- **四面阵**：舰岛四块阵面覆盖 360°
- 配合**旋转雷达**（对海/补盲——那个是机械转的）区分：相控阵固定不转 + 旋转雷达转

## 三、受击/质感

- 受击：阵面被打坏（部分 T/R 单元失效→阵面"破洞"）、水冷漏
- 质感：阵面罩的复合材料质感 / T/R 单元阵列细节 / 舰岛金属
