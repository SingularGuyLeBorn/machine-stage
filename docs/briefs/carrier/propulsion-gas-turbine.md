# 燃气轮机（Gas Turbine）· 舰用动力 · 零件级

> 舰用燃气轮机（如 LM2500 级）——航母/大型舰艇的主动力之一。工作原理：**压气机压气 → 燃烧室喷油燃烧 → 高温燃气推动涡轮旋转输出动力**。
> 参考真实舰用燃气轮机结构。

## 〇、工作原理（先懂）

燃气轮机 = 连续燃烧的"喷气发动机改轴输出"：
```
进气 → 压气机（多级叶片压缩空气）→ 燃烧室（喷入燃料点火，高温高压燃气）
 → 涡轮（燃气推动涡轮叶片旋转）→ 一部分驱压气机，一部分输出动力（经减速齿轮→轴系→螺旋桨）
 → 排气（废气排出）
```

## 一、零件级拆分（~150 件）

| 总成 | 零件（逐件） |
|------|------------|
| **进气** | 进气道 / 进气滤网 / 导流叶片 |
| **压气机**（多级轴流） | 压气机机匣 / **压气机叶片×N 级**（每级：动叶一圈+静叶一圈，叶片实例化）/ 压气机转子轴 / 级间机匣 |
| **燃烧室** | 燃烧室外壳 / **火焰筒×N**（环管/环形）/ **燃油喷嘴×N** / 点火器 / 联焰管 |
| **涡轮** | **高压涡轮**（涡轮盘+涡轮叶片一圈，叶片实例化）/ **动力涡轮**（输出动力）/ 涡轮轴 / 涡轮导向器 |
| **排气** | 排气扩压器 / 排气道 / 排气口（红外抑制）|
| **附属** | 减速齿轮箱 / 燃油泵 / 滑油系统（油泵/油箱/滤）/ 启动机 / 控制（调速器）/ 管路 / 支架机座 |
| **盘/轴** | 各转子盘的叶片**逐片实例化**（压气机叶片/涡轮叶片——一圈圈） |

## 二、机构运动

- **启动**：启动机带动 → 压气机转 → 点火（燃烧室）→ 转速爬升 → 自持
- **运转**：压气机/涡轮高速旋转（叶片旋转）+ 排气喷焰 + 进气
- **加减速**：油门→燃油流量→转速/功率变化（阻尼感）
- **剖视**：能看到内部压气机/燃烧室/涡轮的层次

## 三、受击/质感

- 受击：叶片打伤（外来物）、起火、停转
- 质感：高温合金（涡轮叶片）/ 机匣金属 / 排气熏黑 / 热端烧蚀色
