# 弹射器（Catapult）· 飞行甲板 · 零件级

> 航母弹射器——把舰载机**在几十米内加速到起飞速度**弹射出去。电磁弹射（EMALS）或蒸汽弹射。
> 这是航母的**核心机构**之一（舰载机能满油满弹起飞靠它）。

## 〇、工作原理（先懂）

**蒸汽弹射**（尼米兹）：蒸汽储罐 → 打开阀门 → 蒸汽推动弹射汽缸的活塞 → 活塞带滑梭沿轨道高速滑动 → 滑梭拖舰载机前轮 → 飞机加速起飞。
**电磁弹射**（福特/福建舰）：直线电机 → 电磁力驱滑梭沿轨道加速 → 弹射。
共同点：**滑梭沿轨道高速滑动，拖飞机加速**。

## 一、零件级拆分（~200 件）

| 总成 | 零件（逐件） |
|------|------------|
| **弹射轨道** | 轨道（甲板上的长槽）/ 轨道分段×N（实例化）/ 密封条 / 盖板 |
| **滑梭** | 弹射滑梭（在轨道上滑动，挂飞机前轮）/ 滑梭轮 / 牵引杆 |
| **弹射动力** | 蒸汽：弹射汽缸 + 活塞 + 蒸汽阀 + 储汽罐；电磁：直线电机定子×N（实例化）+ 动子 + 变频器 |
| **挡焰板** | **挡焰板**（飞机尾焰挡板，弹射时升起）/ 液压升降机构 / 冷却水管 |
| **复位机构** | 滑梭复位（弹射后滑梭退回起点）/ 回位驱动 |
| **控制** | 弹射控制室（甲板边缘弹射官位）/ 张力释放（限力杆/拉断杆）/ 传感器 |
| 前端 | 前轮牵引杆（舰载机前轮挂滑梭）|

## 二、机构运动/交互（弹射起飞动画）

```
舰载机上弹射位（前轮挂滑梭，挡焰板升起）
 → 弹射官确认 → 开阀/通电 → 滑梭沿轨道高速滑动（阻尼感：0→极速加速）
 → 拖飞机加速 → 离舰起飞 → 滑梭复位
```
- **滑梭高速滑动** + 飞机被拖加速 + 尾焰被挡焰板挡住
- 弹射力可调（按飞机重量）
