# 航母弹射器（Catapult）· 超详细零件级

> 航母弹射器——把 ~30 吨舰载机在 ~90 米内从 0 加速到 ~250 km/h（离舰速度）。
> 两种：**蒸汽弹射**（尼米兹级，汽缸+活塞）和**电磁弹射 EMALS**（福特级/福建舰，直线电机）。
> 福建舰用电磁弹射。这是航母最核心的机构之一——舰载机满油满弹起飞全靠它。
> 参考真实弹射器结构（尼米兹 C-13 蒸汽弹射 / 福特 EMALS）。

## 〇、工作原理（先吃透两种）

### 蒸汽弹射（C-13，尼米兹）
```
蒸汽储罐（蓄压）→ 打开发射阀 → 高压蒸汽冲进【弹射汽缸】
 → 蒸汽推动汽缸里的【弹射活塞】高速前进
 → 活塞顶部的【滑梭】（从甲板轨道槽伸出）被活塞带着沿轨道高速滑动
 → 滑梭通过【牵引杆】挂住舰载机前轮 → 拖着飞机加速
 → 到末端：活塞冲入【水刹车】（水缓冲停活塞）→ 飞机离舰 → 滑梭复位
```
关键：蒸汽储压 → 瞬间释放 → 活塞+滑梭加速 → 水刹车停活塞。

### 电磁弹射（EMALS，福建舰/福特级）
```
储能（飞轮/电容）→ 大功率变频 → 【直线电机】定子沿轨道分段通电
 → 电磁力推动【动子/滑梭】沿轨道加速（精确可控加速曲线）
 → 滑梭拖飞机 → 末端断电 → 滑梭复位
```
关键：直线电机分段驱动，加速曲线精确可控（比蒸汽柔和可调，省飞机结构）。

## 一、零件级拆分（~250 件，逐件）

### 1. 弹射轨道（甲板上的长槽）
| 零件 | 说明 |
|------|------|
| **弹射轨道槽** | 甲板上的长槽（滑梭在里面滑），**轨道分段×N**（实例化，每段 ~5m 拼接）|
| 轨道盖板 | 槽口的活动盖板（密封，滑梭过时开）|
| 导轨 | 滑梭的导向轨（内侧）|
| 密封条 | 轨道槽密封（蒸汽弹射要密封防漏汽）|

### 2. 弹射活塞 + 滑梭（核心运动件）
| 零件 | 说明 |
|------|------|
| **弹射汽缸**（蒸汽） | 长汽缸（沿轨道），蒸汽推活塞 |
| **弹射活塞** | 汽缸内的活塞（蒸汽推动）|
| **滑梭** | 活塞顶部连接、从轨道槽伸出的"梭子"——挂飞机 |
| **牵引杆/牵制杆** | 滑梭前端的牵引杆（挂舰载机前轮牵引钩）|
| **水刹车**（蒸汽） | 轨道末端的水刹车（活塞冲入水缓冲停住）|
| 直线电机定子×N（电磁） | 沿轨道分段的直线电机定子（实例化）|
| 动子（电磁） | 滑梭下的动子（和定子电磁作用）|

### 3. 动力/储能系统
| 零件 | 说明 |
|------|------|
| 蒸汽储罐（蒸汽） | 蓄压罐（储存高压蒸汽）|
| 发射阀（蒸汽） | 大口径快开阀（瞬间放汽）|
| 飞轮储能（电磁） | 储能飞轮（电机储能）|
| 变频器/电容（电磁） | 大功率变频驱动 |
| 泵站/管路 | 蒸汽/液压管路 |

### 4. 挡焰板（飞机尾焰挡板）
| 零件 | 说明 |
|------|------|
| **挡焰板** | 弹射位后方的耐高温挡板（飞机开加力时挡住尾焰，保护后方）|
| 挡焰板升降机构 | 液压缸 + 铰链（弹射时升起，平时放下与甲板平）|
| 冷却水管 | 挡焰板水冷（尾焰高温）|

### 5. 复位机构
| 零件 | 说明 |
|------|------|
| 滑梭复位机构 | 弹射后滑梭退回起点（回位驱动）|
| 牵制释放 | 牵制杆（发射前牵制飞机蓄力，达力断开）|

### 6. 控制
- 弹射控制室（甲板边缘"气泡"——弹射官位）/ 发控台 / 传感器（滑梭位置/速度）/ 限力/保护

## 二、弹射起飞动画（完整流程，核心）

```
舰载机滑入弹射位（前轮牵引钩挂住滑梭，挡焰板升起）
 → 弹射官确认 → 飞机开加力（尾焰被挡焰板挡住）
 → 【牵制杆蓄力——先拉住】→ 发射阀开/直线电机通电
 → 滑梭沿轨道高速滑动（0→250km/h，阻尼感：瞬间爆发+加速曲线）
 → 牵制杆断开 → 滑梭拖飞机冲出 → 飞机离舰
 → 活塞冲水刹车停住（蒸汽）/ 断电（电磁）→ 滑梭复位
```
- **滑梭的高速滑动**（轨道槽内）+ 飞机被拖加速
- **挡焰板升起**（挡尾焰）+ 尾焰
- **阻尼感**：蓄力→爆发→加速→末端减速

## 三、细节/质感

- 轨道槽的密封/盖板细节；挡焰板的耐高温/水冷；滑梭的金属磨损
- 蒸汽弹射的蒸汽喷出（轨道缝冒汽）；电磁的安静
