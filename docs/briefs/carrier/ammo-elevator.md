# 弹药升降机（Weapons/Propulsion... Ammunition Elevator）· 零件级

> 弹药升降机——把弹药从舰体深处的弹药库**垂直提升**到机库/飞行甲板（挂弹用）。
> 航母有多部弹药升降机（弹药库→机库→甲板）。

## 〇、作用（先懂）

舰载机挂弹流程：弹药库（舰体深处，装甲保护）→ **弹药升降机**垂直提升 → 机库/甲板 → 挂弹车挂到舰载机。
弹药升降机是弹药从库到机的通道——要安全（防火/防爆/防静电）。

## 一、零件级拆分（~120 件）

| 总成 | 零件（逐件） |
|------|------------|
| **升降平台** | 平台（承载弹药车/弹）/ 平台护栏 / 防滑面 |
| **导轨/井道** | 升降井道（垂直贯穿）/ 导轨×N / 导向轮 |
| **驱动机构** | 液压驱动（液压缸/泵站）或 钢丝绳卷扬（卷筒/钢丝绳/滑轮/电机）|
| **门系统** | 各层舱门（防火门，甲板/机库/弹药库层）/ 门锁 / 联动（平台到位才开门）|
| **安全** | 防爆电气 / 防静电 / 消防喷淋 / 应急制动 / 限位开关 |
| **弹药车** | 弹药运输车（在平台上）/ 固定装置 |
| 弹药库侧 | 弹药库货架 + 弹药（导弹/炸弹——弹药零件化）|

## 二、机构运动/交互

- **升降演示**：弹药车进平台 → 门关 → 平台升降（从弹药库到甲板）→ 到位门开 → 弹药车出
- **各层联动**：平台到位 → 该层防火门才开（安全联锁）
- **挂弹链**：弹药库 → 升降机 → 甲板 → 挂弹车 → 舰载机挂弹（和舰载机/机库连上）
- 阻尼感：平台启动慢→匀速→减速到位

## 三、受击/质感

- 受击：井道中弹（弹药库殉爆风险——弹药库装甲+泄压）
- 质感：井道金属 / 平台防滑 / 防火门
