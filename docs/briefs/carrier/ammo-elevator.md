# 弹药升降机（Ammunition Elevator）· 超详细零件级

> 弹药升降机——把弹药从舰体深处的**弹药库**（装甲保护、防火防爆）垂直提升到**机库/飞行甲板**（给舰载机挂弹）。
> 航母有多部弹药升降机（弹药库→机库→甲板的垂直通道）。安全是第一位（弹药运输防火防爆防静电）。

## 〇、作用与流程（先懂）

```
舰载机挂弹链：弹药库（舰体深处）→【弹药升降机】垂直提升 → 机库/甲板 → 挂弹车 → 挂到舰载机
弹药升降机是弹药从"库"到"机"的垂直通道——全程防火/防爆/防静电。
```

## 二、机构运动/交互动画

- **升降流程**：弹药车进平台（弹药库层）→ 层门关 → 平台升降（液压/卷扬——阻尼感：启动慢→匀速→减速到位）→ 到位锁定 → 该层门开（联锁）→ 弹药车出（到甲板/机库）
- **各层联动**：平台到位 → 该层防火门才开（安全联锁演示）
- **挂弹链**：弹药库 → 升降机 → 甲板 → 挂弹车 → 舰载机挂弹（和 aircraft.md 连上）
- **安全**：防爆/防静电/消防细节

## 三、受击/质感

- 受击：井道中弹（弹药库殉爆风险——装甲 + 泄压）
- 质感：井道金属 / 平台防滑 / 防火门 / 液压机构
