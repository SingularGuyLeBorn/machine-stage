# 核反应堆（舰船用压水堆 PWR）· 超详细零件级（零件数 600+）

> 核反应堆——核动力航母/核潜艇的心脏。压水堆 PWR。
> 真实反应堆极其复杂：堆芯光**燃料组件就 ~200 个、燃料棒几万根**。零件数 600+（实例化后数万）。
> 参考真实舰船压水堆（A1B/A4W/潜艇堆）。

## 〇、压水堆工作原理（先吃透）

```
【堆芯】核燃料棒裂变放热（链式反应，控制棒控制快慢）
 →【一回路】高压冷却剂（水，高压 ~15MPa 不沸腾）流过堆芯带热
 → 进【蒸汽发生器】传热管，把【二回路】水烧成蒸汽
 → 二回路蒸汽 →【汽轮机】→ 推进 + 发电
 → 一回路/二回路隔离（热量经蒸汽发生器传递，水不混）
```

## 二、机构运动/交互动画

- **启动/停堆**：控制棒抽出（反应开始）/插入（停堆）——**控制棒在堆芯插抽**（CRDM 驱动）
- **功率调节**：控制棒位置 → 反应性 → 功率（阻尼感——核反应热惯性）
- **一回路循环**：主泵驱动冷却剂循环（堆芯→蒸汽发生器→回）
- **蒸汽发生**：一回路传热管传热给二回路 → 二回路蒸汽
- **剖视**：压力容器内堆芯（燃料组件+控制棒）可见 + 蒸汽发生器传热管束

## 三、受击/质感（核安全是重点）

- 受击：压力容器受损（辐射泄漏）/ 主泵失效 / 失水事故
- **安全演示**：应急停堆（控制棒快速插入）/ 安全注入
- 质感：压力容器厚壁钢 / 屏蔽层 / 一回路管路 / 控制棒
