# 核反应堆（舰船用压水堆 PWR）· 超详细零件级

> 核反应堆——核动力航母（福特/尼米兹）和核潜艇的"心脏"。
> 舰船用**压水堆（PWR）**：核裂变放热 → 一回路高压水（不沸腾）带热 → 蒸汽发生器烧二回路成蒸汽 → 汽轮机推进/发电。
> 参考真实舰船压水堆（A1B/A4W/潜艇堆）结构。

## 〇、压水堆工作原理（先吃透）

```
【堆芯】核燃料棒裂变放热（链式反应，控制棒控制快慢）
 →【一回路】高压冷却剂（水，高压下不沸腾）流过堆芯带走热量
 → 一回路热水进【蒸汽发生器】，把【二回路】的水烧成蒸汽
 → 二回路蒸汽 →【汽轮机】→ 推进（轴系/螺旋桨）+ 发电
 → 二回路乏汽冷凝回水循环
关键：一回路（放射性）和二回路（干净）隔离——热量经蒸汽发生器传递，水不混。
```

## 二、机构运动/交互动画

- **启动/停堆**：控制棒抽出（反应开始）/插入（停堆）——**控制棒在堆芯里插抽**是关键动作
- **功率调节**：控制棒位置 → 反应性 → 功率（阻尼感——核反应的热惯性）
- **一回路循环**：主泵驱动冷却剂循环（堆芯→蒸汽发生器→回）
- **蒸汽发生**：一回路传热给二回路 → 二回路蒸汽 → 汽轮机
- **剖视**：压力容器内堆芯（燃料组件+控制棒）可见

## 三、受击/质感（核安全是重点）

- 受击：压力容器受损（辐射泄漏风险）/ 主泵失效 / 失水事故
- **安全演示**：应急停堆（控制棒快速插入）/ 安全注入
- 质感：压力容器厚壁钢 / 屏蔽层 / 一回路管路 / 控制棒
