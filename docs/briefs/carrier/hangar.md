# 航母内部机库（Hangar）· 超详细零件级

> 航母机库——飞行甲板下的"飞机停放+维护+挂弹"大舱。舰载机的"家"。
> 机库是航母内部最大的舱室（防火分段 + 密集停放舰载机 + 维护区）。

## 〇、机库结构逻辑（先懂）

机库 = 飞行甲板下的大舱，停放/维护/挂弹舰载机。
核心：**防火分段**（机库分几段，防火门隔开——一处起火不蔓延）+ **密集停放**（舰载机折叠机翼密集停）+ **维护挂弹**（机库内维护/挂弹）。

## 二、机构运动/交互动画

- **舰载机调度**：牵引车拖飞机（机库→升降机→甲板）/ 折叠机翼密集停放
- **挂弹**：弹药升降机上来弹药 → 挂弹车挂到舰载机
- **维护**：维护工位检修舰载机
- **消防**：起火 → 泡沫喷淋 + 防火门关闭隔离

## 三、受击/质感

- 受击：机库起火（舰载机带油带弹——危险）/ 消防喷淋
- 质感：机库金属 + 停机位标记 + 防火门 / 工具设备
