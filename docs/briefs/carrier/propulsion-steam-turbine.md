# 蒸汽轮机（Steam Turbine）· 舰用动力 · 零件级

> 舰用蒸汽轮机——核动力/常规动力航母的主动力。工作原理：**锅炉/反应堆烧水产生高压蒸汽 → 蒸汽冲击涡轮叶片旋转 → 输出动力**。
> 参考真实舰用蒸汽轮机结构。

## 〇、工作原理（先懂）

蒸汽轮机 = 用蒸汽推涡轮：
```
锅炉/核反应堆 加热水 → 高压高温蒸汽
 → 蒸汽经喷嘴冲击【涡轮叶片】→ 涡轮高速旋转
 → 经减速齿轮箱 → 轴系 → 螺旋桨
 → 乏汽进冷凝器冷凝成水 → 回锅炉循环
```

## 一、零件级拆分（~150 件）

| 总成 | 零件（逐件） |
|------|------------|
| **蒸汽发生** | 锅炉/蒸汽发生器 / 汽包 / 过热器 / 给水泵 / 燃烧器（常规）或 反应堆一回路（核）|
| **高压涡轮** | 涡轮机匣 / **涡轮级×N**（每级：喷嘴静叶一圈 + 动叶一圈，**叶片逐片实例化**）/ 高压转子轴 |
| **低压涡轮** | 低压涡轮级×N / 低压转子轴 / 排汽口 |
| **减速齿轮箱** | 大齿轮 / 小齿轮 / 齿轮轴 / 轴承 / 箱体（减速：涡轮高转速→螺旋桨低转速）|
| **冷凝器** | 冷凝器壳 / 冷凝管×N / 循环水泵 |
| **轴系** | 主轴 / 轴承×N / 推力轴承 / 联轴器 / 轴封 |
| **管路** | 主蒸汽管 / 乏汽管 / 给水管 / 阀门×N |
| 辅机 | 润滑油系统 / 调速器 / 盘车装置 / 支架机座 |

## 二、机构运动

- **启动**：锅炉产汽 → 暖机 → 冲转（蒸汽冲涡轮）→ 升速 → 并网
- **运转**：涡轮旋转（叶片）+ 减速齿轮啮合 + 轴系转 → 螺旋桨
- **剖视**：涡轮级层次（喷嘴+动叶一级级）+ 减速齿轮箱内部齿轮

## 三、受击/质感

- 受击：管路破裂喷汽 / 涡轮损伤 / 停转
- 质感：涡轮叶片金属 / 管路保温层 / 高温段烧蚀色
