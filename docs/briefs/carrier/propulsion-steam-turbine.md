# 蒸汽轮机（Steam Turbine）· 舰用动力 · 超详细零件级

> 舰用蒸汽轮机——核动力航母（尼米兹/福特）和常规蒸汽动力舰的主动力。
> 原理：锅炉/核反应堆产生高压蒸汽 → 蒸汽冲涡轮 → 减速 → 螺旋桨。
> 参考真实舰用蒸汽轮机结构。

## 〇、工作原理（先吃透，朗肯循环）

```
锅炉/核反应堆 把水烧成【高压高温蒸汽】
 → 蒸汽经【主汽阀】→【喷嘴】（静叶，把蒸汽压力能转成速度能）
 → 高速蒸汽冲击【涡轮动叶片】→ 涡轮高速旋转
    ├─ 高压涡轮（高压缸）
    └─ 低压涡轮（低压缸，蒸汽膨胀做功）
 → 经【减速齿轮箱】→ 轴系 → 螺旋桨
 → 乏汽进【冷凝器】（海水冷却）凝结成水 → 给水泵打回锅炉循环
```

## 二、机构运动/交互动画

- **启动**：锅炉产汽 → 暖管暖机 → 冲转（蒸汽冲涡轮）→ 升速 → 并网带负荷
- **运转**：高/低压涡轮旋转（叶片）+ 减速齿轮啮合 + 轴系转 → 螺旋桨
- **剖视**：涡轮级层次（喷嘴+动叶一级级）+ 减速齿轮箱内部齿轮 + 冷凝器管束
- **阻尼感**：蒸汽轮机启动慢（暖机）、加减速有热惯性

## 三、受击/质感

- 受击：蒸汽管路破裂（喷高温蒸汽）/ 涡轮损伤 / 冷凝器漏（海水进）
- 质感：涡轮叶片金属 / 管路保温层 / 高温段烧蚀色 / 冷凝器铜管
