# 1130 近防炮（H/PJ-11）· 超详细零件级

> 1130 近防炮——11 管 30mm 转管炮，射速 ~10000 发/分（**万发炮**）。
> 航母/舰艇拦截反舰导弹的**最后一道硬杀伤防线**。
> 加特林原理（外能源电机驱动 11 管旋转，每管转到击发位依次击发）+ 近防火控（雷达/光电跟踪）。
> 参考真实 1130 / 密集阵（Phalanx）结构。

## 〇、工作原理（先吃透）

```
【搜索雷达】发现来袭导弹 →【跟踪雷达/光电】精确跟踪 → 火控解算提前量
 → 转管炮组【俯仰/旋回】瞄准
 → 电机驱动【11 根炮管绕中心轴旋转】→ 每管转到击发位依次击发
 → 射速上万发/分 → 在导弹航路上打出一片【弹幕】拦截
```
关键：外能源（电机）驱动转管——射速不受弹药燃气限制，能到上万发/分。

## 二、机构运动/交互动画

- **跟踪瞄准**：雷达/光电跟踪目标 → 炮塔俯仰/旋回随动（**阻尼感**——炮塔转动有惯性）→ 指向来袭方向
- **转管射击**：电机驱动 11 管旋转 → 每管依次击发 → **弹幕**（密集弹丸形成拦截幕）→ 弹壳瀑布式抛出
- **拦截演示**：来袭导弹 → 雷达锁定 → 转管炮转向 → 开火 → **弹幕命中导弹**（空中拦截爆炸）
- **射速可调**：点射/连射/全速（万发/分）

## 三、受击/质感

- 受击：炮塔中弹 / 炮管损坏 / 供弹卡壳
- 质感：炮管烤蓝 / 炮塔海军灰 / 炮口焰 / 弹壳堆积
