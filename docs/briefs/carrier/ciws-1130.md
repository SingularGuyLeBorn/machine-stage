# 1130 近防炮（H/PJ-11）· 近防转管炮 · 零件级

> 1130 近防炮——11 管 30mm 转管炮，射速 ~10000 发/分（**万发炮**），航母/舰艇拦截反舰导弹的**最后防线**。
> 加特林原理（外能源电机驱动 11 管旋转），参考枪械线加特林 M134 的转管机构。
> 参考真实 1130 / 密集阵（Phalanx）结构。

## 〇、工作原理（先懂）

转管近防炮 = 加特林原理（转管）+ 近防火控：

```
雷达/光电跟踪来袭导弹 → 火控解算 → 转管炮转向瞄准
 → 电机驱动 11 根炮管旋转 → 每管转到击发位依次击发（射速上万发/分）
 → 弹幕拦截（在导弹航路上打出一片弹幕）
```

## 二、机构运动/交互

- **转管射击**：11 管旋转 + 每管依次击发 + **弹幕**（密集弹丸形成拦截幕）+ 弹壳瀑布式抛出
- **跟踪瞄准**：雷达/光电跟踪目标 → 炮塔俯仰/旋回随动（阻尼感）→ 指向来袭方向
- **拦截演示**：来袭导弹 → 雷达锁定 → 转管炮转向 → 开火 → 弹幕命中导弹（空中拦截爆炸）
- **射速变化**：可调射速（点射/连射/全速）

## 三、受击/质感

- 受击：炮塔中弹 / 炮管损坏 / 供弹卡壳
- 质感：炮管烤蓝 / 炮塔白色或海军灰 / 炮口焰
