# 近防武器系统（CIWS 总览）· 零件级

> 航母近防武器 = 最后一道防线（拦截来袭导弹/飞机）。含**近防炮**（硬杀伤）+ **近程防空导弹** + **干扰弹**（软杀伤）。

## 〇、体系（分层拦截）

```
远程：舰载防空导弹（区域防空）
中程：近程防空导弹（点防御）
近程：近防炮（1130 转管炮——弹幕硬杀伤）+ 干扰弹（软杀伤，诱骗）
```

## 一、零件级拆分（~150 件）

| 系统 | 零件（逐件） |
|------|------------|
| **近防炮**（见 ciws-1130.md） | 1130 转管炮组（11 管）+ 火控雷达 + 光电 |
| **近程防空导弹** | 发射架/垂发单元 + **导弹**（弹体/导引头/战斗部/发动机/舵面——弹药零件化）+ 制导雷达 |
| **干扰弹发射器** | 发射管×N（箔条/红外诱饵弹）+ 控制箱 |
| **火控** | 搜索雷达 + 跟踪雷达 + 火控计算机 + 指挥仪 |

## 二、机构运动/交互

- **分层拦截演示**：来袭导弹 → 搜索发现 → 远程/中程导弹拦截 → 漏网的由 1130 弹幕拦截 → 干扰弹诱骗
- **导弹发射**：垂发/发射架点火 + 导弹升空 + 制导（舵面机动）
- **干扰弹**：发射箔条/红外诱饵（弹幕云）
- 近防炮弹幕（见 1130 分册）
