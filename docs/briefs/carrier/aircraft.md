# 舰载机（歼-15 / 歼-35）· 零件级

> 航母的舰载机（歼-15 飞鲨 / 歼-35）。**舰载版特色：折叠机翼 + 尾钩 + 加强起落架**。
> 和歼-20（j20-plan.md）共用飞行框架——这份只写舰载机特有的部分 + 舰载化差异。

## 〇、舰载机 vs 陆基机（舰载化差异）

舰载机为在航母起降/停放做的改动：
- **折叠机翼**（外翼段向上折叠——省甲板/机库空间）
- **尾钩**（着舰钩拦阻索）
- **加强起落架**（承受着舰冲击——重着陆）
- 防盐雾腐蚀 + 弹射牵引钩（挂弹射器）

## 一、零件级拆分（~400 件，机体同歼-20 + 舰载化）

| 总成 | 零件 |
|------|------|
| 机体 | （机身/气动面/发动机/座舱/航电——同歼-20，见 j20-plan.md）|
| **折叠机翼**（舰载特色） | 外翼段（可折叠）+ **折叠铰链 + 折叠作动器** + 折叠锁 + 翼尖导弹挂架 |
| **尾钩**（舰载特色） | 着舰尾钩（机尾可放下钩子）+ 收放机构 + 缓冲 |
| **加强起落架** | 主起/前起**加强**（粗支柱+双轮）+ 弹射牵引钩（前起落架挂弹射滑梭）|
| 武器 | 弹舱/翼下挂架 + 导弹（PL-15/PL-10）|
| 舰载化 | 防盐雾涂层 / 折叠处密封 |

## 二、机构运动（舰载机特有）

- **机翼折叠**：外翼段向上折叠（收纳省空间）/ 展开（飞行）——折叠动画
- **尾钩收放**：着舰时放下（钩拦阻索）/ 巡航收起
- **弹射起飞**（挂滑梭）/ **拦阻降落**（尾钩钩拦阻索——配合 arresting.md）
- **升降机**：甲板↔机库升降
- 飞行运动学（同歼-20：舵面/矢量喷口/姿态）
