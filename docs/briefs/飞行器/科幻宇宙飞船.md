## 〇、科幻星际飞船（先懂）

星际飞船（赛尔号等）：科幻的大型宇宙飞船。
核心：**引擎**（推进）+ **舰体** + **舰桥** + **武器** + **机库/舱门**。
科幻点：曲率/跃迁引擎、能量武器、力场护盾、反重力。

## 一、零件级拆分

### 1. 舰体（~300 件）
- 舰体（科幻外形）/ 各舱段 / 甲板分层 / 舱壁 / 外板（科幻装甲）

### 2. 引擎（推进，~200 件——科幻核心）
- **主引擎×N**（推进器——喷口 + 推进舱）+ **跃迁/曲率引擎**（科幻——能量环/引擎核心）
- 推进喷口（发光喷焰）

### 3. 舰桥（指挥，~100 件）
- 舰桥（指挥舱——全息投影控制台 + 舰长位 + 大屏幕）

### 4. 武器（~150 件）
- **能量武器**（激光炮/离子炮——炮塔 + 发射口发光）+ 导弹/鱼雷发射口

### 5. 机库 + 舱门（~100 件）
- 机库（舰载机/穿梭机）+ 舱门（开合）+ 登陆艇

### 6. 科幻系统
- **力场护盾**（能量护盾）/ **反重力**（舰内重力）/ 跃迁引擎（曲率——空间扭曲）

## 二、机构运动/交互

- **飞行**：主引擎推进（喷焰）+ 姿态调整（姿态发动机）
- **跃迁/曲率**：跃迁引擎启动（空间扭曲特效——曲率飞行）
- **武器**：能量武器射击（激光/离子束）
- **护盾**：力场护盾（受击泛涟漪）
- **舱门/机库**：舱门开合 + 舰载机进出

## 三、质感

- 科幻金属 + 发光（引擎喷焰/能量武器/护盾/舷窗灯光）+ 舰体做旧
