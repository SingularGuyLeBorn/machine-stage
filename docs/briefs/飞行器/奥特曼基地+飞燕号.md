## 〇、TPC 胜利队基地（先懂）

TPC 胜利队基地（迪迦奥特曼）：海上/地下的高科技基地。
核心：**指挥塔**（司令室）+ **机库**（飞燕号）+ **发射平台**（飞燕号出击）+ **跑道**。
飞燕一号/二号：胜利队的战机（能变形——飞燕一号可变形成强化形态）。

## 一、零件级拆分

### 1. 基地建筑（~400 件）
- **指挥塔**（司令室——指挥台/大屏幕/控制台）+ 基地主体建筑
- **机库**（飞燕号机库——停放/维护）+ 机库门
- **发射平台**（飞燕号出击平台——可升起到发射位）
- **跑道**（飞燕号起降跑道）
- 基地设施（雷达/通信塔/停机坪/燃料库）

### 2. 飞燕一号（~250 件——胜利队主力战机）
- 机身（飞燕一号外形）+ 机翼（可变——**变形成强化形态**）+ 发动机 + 座舱（驾驶舱：座椅/仪表/操纵杆）+ 武器（激光炮/导弹）
- **变形机构**：飞燕一号的**变形**（战机形态 ↔ 强化形态——机翼/机身变形）

### 3. 飞燕二号（~250 件——重火力/支援）
- 飞燕二号（比一号大/重火力）+ 武器 + 座舱

### 4. 基地系统（~100 件）
- 雷达/预警系统 + 指挥系统 + 出击系统（飞燕号出击流程）

## 二、机构运动/交互动画

- **飞燕号出击**：机库 → 发射平台升起 → 飞燕号发射（出击动画）
- **变形**：飞燕一号变形（战机↔强化形态——机翼/机身变形动画）
- **基地运转**：指挥塔（指挥）+ 雷达旋转 + 警报（怪兽来袭警报）
- **起降**：飞燕号起降跑道

## 三、质感

- 基地科技感（白色/蓝色涂装）+ 飞燕号（胜利队涂装——红白）+ 指挥塔内构（大屏幕/控制台）
