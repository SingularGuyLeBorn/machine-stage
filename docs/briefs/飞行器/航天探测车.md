## 〇、航天探测车（先懂）

巡视器（rover）= **轮式移动平台 + 太阳能板 + 桅杆相机 + 机械臂 + 探测仪器**。
特色：环境探测（相机/光谱仪/雷达）+ 机械臂采样 + 太阳能供电。

## 一、零件级拆分

### 1. 移动平台（巡视器的"腿"）
| 零件 | 说明 |
|------|------|
| **轮子×6** | 巡视器轮（带防滑齿——**摇臂转向架悬挂**：摇臂+转向架，越障）|
| 摇臂转向架 | 摇臂+转向架（6 轮独立悬挂——越障时各轮自适应地形）|
| 驱动电机×6 | 每轮驱动电机 |
| 车体 | 巡视器主体（仪器设备舱）|

### 2. 能源（太阳能）
- **太阳能板×N**（可展开的太阳能电池板）+ 展开机构 + 蓄电池

### 3. 探测仪器（探测车的"眼睛和手"）
| 零件 | 说明 |
|------|------|
| **桅杆** | 桅杆（可升降/旋转）+ **导航相机/全景相机**（桅杆顶）|
| **机械臂** | 机械臂（多关节——采样/钻探）+ 末端采样器/钻头 |
| 探测仪器 | 探地雷达 / 光谱仪 / 气象站 / 磁场仪 |

### 4. 通信
- 高增益天线（对地通信）+ 低增益天线 + UHF 天线

## 二、机构运动/交互动画

- **巡视**：6 轮驱动 + 摇臂转向架（越障——各轮自适应地形起伏）
- **桅杆**：升降 + 旋转（相机环拍）
- **机械臂**：多关节伸展 → 采样/钻探（取土样）
- **太阳能板**：展开 + 对日定向
- **探测**：探地雷达/光谱仪工作

## 三、受击/质感

- 受环境（火星沙尘暴——太阳能板积灰）/ 卡轮
- 质感：金属 + 太阳能板（蓝色/金色）+ 多层隔热（MLI 金色膜——巡视器包金膜）+ 火星沙尘
