# 金古桥（King Joe）设计计划（零件级 · T-800 标准 · 变形合体）

> 佩丹星人机器人，四体分离合体。**按 T-800 零件级标准重拆**：
> 每个液压缸 7-9 件、每个插接机构的销/锁/导轨/轴承逐件、每个喷口逐件、反重力发生器拆内构——
> 不许总成级糊弄。四体合计 **~580 定义件 / 实例上千**。
> 核心难点：**合体插接机构**（机械真实地咬合，不是播动画）。

## 0. 设计原则

- **忠于原作**：银色镜面金属 + 四体分离合体 + 怪光线（赛文奥特曼 14/15 话）
- **科幻可放飞**：反重力悬浮、怪光线能量（无现实工程约束）
- **科幻不许放飞**：合体插接必须机械真实（锥形销入槽 + 锁环咬合，严丝合缝）
- **零件级粒度**：每个可动关节/每个液压缸/每个插接件/每个喷口都是独立 partId

## 2. 核心难点：合体插接机构（零件级，全场最重要）

4 对插接面（头↔胸、胸↔腹、腹↔腿 + 双臂↔胸），每对都是**真实机构**：
- **锥形导向销**：先粗对准（锥面导入）
- **圆柱定位销**：再精定位（销入孔）
- **端面贴合**：配合面贴平
- **锁环咬合**：旋转锁环锁死（可闻"咔哒"）
- **对接传感器**：对接状态检测（连通的"信号"来源）

**合体序列（阻尼感 + 电弧，用户点名）**：
```
编队接近（快）→ 逐对对接（腿→腹→胸→头，自下而上），每对：
  ① 接近段：巡航速度
  ② 临近段（阻尼感）：ease-out 强减速——越近越慢，末端小幅横向找正微颤
  ③ 电弧接通：对接面间跳起电弧链（多点闪电"啪——"）——能量先连的可视化
  ④ 咬合段（慢而有力）：锥形销入槽（带涩感，一顿一顿）→ 锁环旋紧
  ⑤ 锁死："咔哒" + 轻微回弹
→ 全部锁死 → 机器人形态立起 → 关节激活
```
- 阻尼感物理：非线性减速 + 末端找正微颤 + 咬合涩感（**不许匀速**）
- 电弧特效：对接面 3-5 条电弧链 + 边缘微光；分离时电弧**拉断熄灭**
- 可逆：分离 = 解锁 → 电弧断 → 销出槽 → 脱离（**分离回避攻击**的招牌动作）

## 3. 运动学（三形态，三套）

| 形态 | 运动学 |
|------|--------|
| 飞船形态（×4） | 反重力悬浮 + 编队飞行（楔形/纵队变换）+ 喷口姿态微调（调节叶片作动） |
| **合体过程** | 三段式对接（上节）——全场技术核心 |
| 机器人形态 | 肩/肘/髋/膝/踝关节液压（活塞随角度真实伸缩）+ 腰部转轴（弯腰/转身）+ 重踏步（地面震颤） |

## 4. 武器与受击

- **怪光线**：眼部（King Ship）+ 胸部（King Chest）双发射口——充能（充能环渐亮+能量聚集）→ 发射（能量束+命中爆闪）
- **分离回避**（招牌）：被锁定 → 瞬间解体 4 飞船四散 → 绕侧翼 → 再合体
- **单体受击**：某飞船被击落 → **残缺合体**（缺腿的机器人只能爬）
- **机器人受击**：装甲板崩落（零件级）+ 关节损毁（液压断喷能液）+ 插接座被打坏（无法合体）

## 5. 质感层（L5——佩丹星科技的皮）

| 层 | 内容 |
|----|------|
| 材质 | 银色镜面金属但非完美——细微拉丝/机加工痕；装甲板间接缝线 + 铆接点 |
| 身份 | 佩丹星文字/纹章、分体识别色条 |
| 做旧 | 镜面细微划痕（完美镜面反而假）、关节活动处磨损 |
| 战场 | 能量武器灼烧痕、凹坑、插接处插拔痕迹 |
| 科幻层 | **发光缝隙**（关节/怪光线发射口的能量辉光） |

### 深度细化（可见内部 + 机加工痕）
- **可见内部**：插接机构逐件（销/锁/导轨/轴承）、关节液压、反重力发生器内构（悬浮线圈/能量核心）、怪光线发射机构（充能电容/聚焦透镜组）
- **机加工痕**：佩丹星精密加工（镜面+接缝）、能量导管、发光缝隙
