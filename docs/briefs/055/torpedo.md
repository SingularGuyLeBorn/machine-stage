# 鱼雷发射管 + 反潜 · 055 · 零件级

> 055 的反潜武器：鱼雷发射管（反潜鱼雷）+ 反潜直升机（直-20 投放鱼雷/声呐）。

## 〇、反潜体系

055 反潜：舰壳声呐 + 拖曳声呐 → 发现潜艇 → **反潜鱼雷**（发射管发射）或 **直-20 投放反潜鱼雷**。

- **声呐**：拖曳声呐放出/收回；声呐探测
- 直-20 投放反潜鱼雷（配合 helicopter.md）
