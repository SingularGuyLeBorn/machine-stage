# 130mm 主炮（H/PJ-45）· 055 舰艏主炮 · 零件级

> 055 舰艏的 130mm 单管舰炮——对海/对陆/对空射击。舰炮机构（供弹/俯仰/旋回）。

## 〇、结构（舰炮）

舰炮 = 炮塔（含身管 + 俯仰机构）+ 旋回架 + **甲板下供弹系统**（弹药库→扬弹机→炮塔）。

## 一、零件级拆分（~150 件）

| 总成 | 零件（逐件） |
|------|------------|
| **炮塔** | 炮塔外壳 / 身管（130mm）+ 炮闩 + 复进机 + 制退机 + 炮口制退器 / 俯仰机构 |
| **旋回架** | 旋回平台（方向转动）/ 旋回驱动 / 俯仰驱动 |
| **供弹系统** | 弹药库 → **扬弹机**（垂直提升）→ 扬弹筒 → 装填机构（装弹入膛）→ 炮闩 |
| **弹药** | 130mm 炮弹（弹丸+药筒）/ 制导炮弹 |
| 控制 | 火控（雷达/光电引导）/ 控制机柜 |

## 二、机构运动/交互

- **射击循环**：扬弹机供弹 → 装填入膛 → 关闩 → 击发 → 后坐（复进/制退）→ 抛壳 → 下一发
- **俯仰/旋回**：炮塔转动 + 身管俯仰（火控随动，阻尼感）
- 对海/对陆/对空射击演示
