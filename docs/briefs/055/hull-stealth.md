# 隐身舰体（055）· 零件级

> 055 舰体——**隐身外形**（内倾舷侧 + 一体化上层建筑）+ 全通甲板。万吨舰体。

## 〇、隐身舰体（055 特色）

055 舰体是**隐身设计**：内倾舷侧（雷达波反射偏转）+ 一体化上层建筑（减少直角反射）+ 内倾烟囱 + 舷侧内收。
