# 垂直发射系统（VLS）· 055 的灵魂 · 零件级

> 055 的灵魂——**112 个通用垂直发射单元**（前 64 + 后 48，冷热共架）。
> 参考真实 VLS（MK41 / 055 通用垂发）。

## 〇、工作原理（先懂）

VLS = 导弹垂直存放在甲板下的发射井阵列，发射时垂直升空：
```
垂发单元 = 甲板下的发射井阵列（每井一枚导弹）
 → 发射：井盖打开 → 【热发射】导弹在井内点火冲出 或【冷发射】燃气发生器把导弹弹出井后空中点火
 → 导弹升空 → 转向目标
```
**冷热共架**（055 通用垂发特色）：同一发射井兼容热发射（海红旗防空）和冷发射（鹰击-21 等大型弹）。

## 一、零件级拆分（~250 件）

| 总成 | 零件（逐件） |
|------|------------|
| **发射井单元×112**（前 64 + 后 48，实例化） | 每单元：**发射井盖**（可开合——铰链+作动）+ 发射筒（井筒）+ 燃气排导管（热发射排焰）+ 弹射机构（冷发射燃气发生器）+ 井口密封 |
| **排导系统** | 燃气排导道（热发射的火焰排出通道）/ 排导舱 / 防爆 |
| **甲板开口** | 甲板垂发口盖（前甲板 64 + 后甲板 48 阵列）+ 密封 |
| **供弹** | 弹药库（导弹存储）→ 装填机构 → 井内导弹 |
| **装载导弹**（和 missile-plan 联动） | **海红旗防空**（热发射）/ **鹰击-21 高超音速反舰**（冷发射）/ 反潜导弹 / 对地巡航导弹——每型零件化 |
| **发射控制** | 发射控制机柜 / 点火线路 / 发控台 |

## 二、机构运动/交互

### 热发射（海红旗防空）
井盖开 → 导弹井内点火 → 燃气经排导管排出 → 导弹冲出 → 转向 → 相控阵引导拦截

### 冷发射（鹰击-21 等大弹）
井盖开 → **燃气发生器把导弹弹射出井** → 导弹离井后**空中点火** → 爬升 → 高超音速滑翔/机动

- **发射井阵列**：前 64 + 后 48 的排布（甲板下）
- **连续发射**：多单元依次发射（防空拦截扇面）
- 冷热共架的两种发射方式都要演示

## 三、受击/质感

- 受击：VLS 中弹（弹药殉爆风险——井内导弹殉爆）/ 井盖损坏
- 质感：甲板垂发口盖阵列 + 井筒金属 + 发射焰熏黑
