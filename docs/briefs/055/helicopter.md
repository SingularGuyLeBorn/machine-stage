# 直-20 舰载直升机 + 双机库 · 详细零件级

> 055 的双机库 + 直-20 舰载直升机（反潜/通用）。直升机难点全在**旋翼系统**和**传动系统**。
> 参考真实直-20 舰载版。**零件数 ~350 件**（直升机比想象复杂）。

## 〇、直升机的难点（先懂）

直升机 = **旋翼系统**（主旋翼产生升力+变距控制）+ **传动系统**（发动机→主减速器→主旋翼/尾旋翼）+ **尾旋翼**（抵消反扭矩）。
舰载版：**旋翼折叠 + 尾梁折叠**（省机库空间）+ 防盐雾 + 着舰系留。

## 一、零件级拆分（逐件）

### 1. 主旋翼系统（核心难点，~80 件）
| 总成 | 零件 |
|------|------|
| **旋翼叶片×5** | 主旋翼叶片×5（每片：叶片本体 + 前缘包片 + 配重）——**可折叠**（舰载）|
| **桨毂** | 桨毂（中央件）/ **挥舞铰/摆振铰/变距铰**（每片桨叶三铰）/ 挥舞限动器 |
| **变距机构** | **自动倾斜器**（倾斜盘——上盘随旋翼转/下盘固定，变距核心）/ **变距拉杆×5**（连倾斜盘到桨叶）/ 液压助力器×3 |
| 旋翼折叠 | 桨叶折叠铰链 + 折叠作动器（舰载收纳）|

### 2. 传动系统（~60 件）
| 总成 | 零件 |
|------|------|
| **主减速器** | 主减壳体 / **行星齿轮**（太阳轮+行星轮+齿圈）/ 输入/输出轴 / 滑油系统 |
| 传动轴系 | 主传动轴 / **尾传动轴**（长轴沿尾梁到尾旋翼）/ 中间减速器 / **尾减速器** |
| 离合器 | 自由轮离合器（发动机断开后旋翼自转）|

### 3. 尾旋翼（~30 件）
- 尾旋翼叶片×4 + 尾桨毂 + 尾变距机构 + 尾传动轴支撑×N

### 4. 发动机×2（涡轴，~60 件）
- 涡轴发动机×2：压气机 + 燃烧室 + 涡轮（燃气涡轮+动力涡轮）+ 排气 + 进气

### 5. 机身（~50 件）
- 前机身（座舱）/ 中机身（机舱）/ **尾梁**（可折叠，舰载）/ 尾撑 / 平尾 / 垂尾

### 6. 起落架 + 着舰（~30 件）
- 前三点起落架 / **着舰系留装置**（甲板系留——鱼叉格栅）/ 尾轮（前移）

### 7. 反潜设备（~40 件）
- **吊放声呐**（可收放的声呐吊舱）/ **磁探仪**（尾部的磁探杆）/ **声呐浮标×N**（投放）/ 反潜鱼雷（挂架）

### 8. 座舱/航电（~30 件）
- 座舱（驾驶舱双座 + 任务位）/ 航电 / 玻璃座舱显示器

## 二、机构运动（直升机特有）

- **旋翼旋转** + **变距**（自动倾斜器倾斜→变距拉杆→桨叶变距→控制升降/方向）
- **旋翼挥舞/摆振**（桨叶三铰的真实运动）
- **旋翼折叠**（舰载收纳）+ **尾梁折叠**
- **起降**：旋翼加速 → 离地 → 着舰（系留）
- **反潜作业**：吊放声呐放入海 / 投放声呐浮标 / 投鱼雷
