# 直升机（直-20）+ 双机库 · 055 · 零件级

> 055 双机库 + 直-20 舰载直升机（反潜/通用）。舰载直升机 + 机库 + 甲板起降。

## 〇、舰载直升机（直-20 舰载版）

直-20 舰载型：**旋翼可折叠**（省机库空间）+ 尾轮前移 + 防盐雾 + 着舰系留。反潜（吊放声呐/鱼雷）。

## 一、零件级拆分（~250 件）

| 总成 | 零件 |
|------|------|
| **直-20** | 机身 / **主旋翼**（旋翼叶片×N + 桨毂 + **折叠机构**）/ 尾旋翼 / 发动机×2 / 起落架 / 反潜设备（吊放声呐/鱼雷）|
| **旋翼折叠**（舰载特色） | 旋翼叶片折叠铰链 + 折叠作动 / 折叠锁 |
| **双机库** | 机库（双机位）/ 机库门 / 牵引导轨 / 维护区 |
| **起降甲板** | 直升机甲板 / 着舰格栅（系留）/ 助降灯 |

## 二、机构运动/交互

- **旋翼折叠/展开**（舰载收纳）
- **起降**：直升机从甲板起飞/着舰（旋翼旋转 + 起落架）
- **反潜**：吊放声呐放入海 / 投放鱼雷
- 进出机库（牵引）
