## 〇、总体认知（航母是"平台"，不是单件）

航母的核心是：**让舰载机能在海上起降**。
五大系统：**舰体结构 / 动力推进 / 飞行甲板（弹射+拦阻）/ 舰岛（指挥+雷达）/ 舰载机+机库**。
**分层做**：先舰体动力立住 → 飞行甲板（弹射/拦阻核心）→ 舰岛 → 舰载机 → 内部机库。

---

## 一、舰体结构（~500 件——船是底）

| 系统 | 零件级拆分 |
|------|-----------|
| **船体** | 球鼻艏 / 舰艏 / 舰体分段×N（**分段建造**，每段独立件）/ 舰艉 / 龙骨 / 肋骨框架 / 外板 |
| **水密舱** | 横向水密舱壁×N / 纵向舱壁 / 双层底 / 水密门×N（可开关）|
| **甲板分层** | 飞行甲板 / 机库甲板 / 内部分层甲板×N（01/02/03 层）|
| **舱室** | 住舱 / 机舱 / 弹药库 / 油库 / 泵舱 / 配电舱 |
| 细节 | 焊缝/分段接缝（分段建造感）/ 舷窗 / 通风口 |

## 二、动力推进（~300 件）

- **核反应堆**（或燃气轮机——福建舰是常规动力）：反应堆舱 / 蒸汽发生器 / 稳压器 / 主泵 / 管路 / 屏蔽
- **蒸汽轮机**（高压/低压）+ **减速齿轮箱** + **轴系×4** + **大螺旋桨×4** + **舵×N**
- 辅机：发电机 + 泵 + 冷凝器 + 锅炉（常规动力）

## 三、飞行甲板（~500 件——核心，舰载机的"机场"）

| 系统 | 零件级拆分 |
|------|-----------|
| **甲板结构** | **斜角甲板**（降落区斜置 ~9°）+ 起飞区（前甲板/斜角）+ 停机区 + 甲板板块×N |
| **弹射器**（电磁 EMALS / 蒸汽）×N | **弹射轨道** + **弹射滑梭**（挂舰载机前轮）+ 弹射汽缸/电磁直线电机 + 挡焰板（可升起）|
| **拦阻装置** | **拦阻索×4**（钢索横跨甲板）+ 滑轮组 + 拦阻机（甲板下液压阻尼）+ 拦阻网（应急）|
| **升降机×N** | 升降平台（甲板↔机库，**可升降**）+ 导轨 + 驱动机构 + 安全锁 |
| **甲板设施** | **甲板标记**（跑道中线/停机位/引导线——涂装）+ 系留点×N + 防爆网（可升）+ 安全护栏 + 甲板灯 |
| **助降** | 菲涅尔透镜助降器（"肉丸"）+ 进近雷达 + 灯光助降系统 |

## 四、舰岛（~300 件）

- **舰岛**（右舷）：**相控阵雷达面板×4**（四面阵）+ **旋转雷达**（对空/对海搜索，**可旋转**）+ 桅杆（鞭状天线×N）
- **舰桥**：航海舰桥（驾驶）+ 航空舰桥（着舰指挥官 LSO 位）+ 司令舰桥——每层玻璃窗 + 控制台
- 烟囱（常规动力）/ 电子战天线 / 通信天线
- **近防武器**：**1130 近防炮**（11 管转管炮——万发炮）+ **海红旗防空导弹**（垂发/发射架）+ 干扰弹发射器

## 五、舰载机（独立装备，~400 件/型——参考 j20-plan）

- **歼-15/歼-35**（舰载版）：**折叠机翼**（外翼段可向上折叠——省甲板空间）+ **尾钩**（拦阻降落钩拦阻索）+ 加强起落架（着舰冲击）+ 防盐雾
- 舰载机是独立零件树（弹舱/发动机/座舱同歼-20），在航母上起降

## 六、内部机库（~400 件）

- **机库甲板**：舰载机停放（密集）+ 防火隔断门（机库分段）
- **升降机井**（贯穿甲板到机库）
- **弹药库**：导弹/炸弹存储 + **弹药升降机**（弹药库→甲板）
- **维护区**：舰载机维护工位 + 备件 + 牵引车（甲板牵引车，拖舰载机）+ 挂弹车
- **消防/损管**：消防栓/泡沫系统 + 损管站

## 七、机构运动（航母的"活"）

- **弹射起飞**：舰载机挂弹射滑梭 → 挡焰板升起 → 弹射（滑梭带飞机加速离舰）→ 滑梭复位
- **拦阻降落**：舰载机进近 → 尾钩放下 → 着舰钩拦阻索 → 拦阻索拉出（液压阻尼减速）→ 停住 → 脱钩
- **升降机**：舰载机在甲板↔机库间升降
- **机翼折叠**：舰载机外翼段折叠/展开
- **雷达旋转**：舰岛搜索雷达转动
- **航行**：螺旋桨推进 + 尾流 + 舵转向
- **甲板作业**：牵引车拖飞机、挂弹车挂弹、甲板人员（彩色马甲）作业

## 八、受击/质感

- 受击：甲板中弹（炸出坑）/ 舰岛受损 / 舰载机起火 / 近防拦截
- 质感：甲板防滑涂层 + 标记 / 舰体海军灰 / 海水腐蚀锈迹 / 焊缝
