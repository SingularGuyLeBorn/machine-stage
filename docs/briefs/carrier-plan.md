# 航空母舰 · 设计任务书（零件级 · 大工程 · 移动平台）

> 自主别来问。冲突以「真实 + 工程自洽」为准，记 PROGRESS.md。
> **这是大工程**——航母不是单个装备，是一个**移动平台**（舰载机+弹射+机库+舰岛）。
> 参考真实航母（福建舰/福特级/尼米兹）。**零件数 2000+ 定义件**（含舰载机则更多）。

## 〇、背景

航空母舰：海上移动机场。核心是**飞行甲板 + 舰载机 + 弹射/拦阻 + 舰岛**。
**这是平台**：舰载机（歼-15/歼-35）是独立装备在航母上起降。
**分层做**：舰体 → 飞行甲板 → 舰岛 → 舰载机 → 弹射/拦阻 → 内部机库。

## 一、零件树（零件级，分层）

### 1. 舰体（~400 件）
- 船体（球鼻艏/舰体分段/水线）/ 甲板分段 / 舱壁 / 龙骨 / 推进（螺旋桨×N + 轴系 + 舵）/ 动力（核反应堆或燃气轮机——简化）
- 舰体焊缝/分段接缝（大型船舶的分段建造感）

### 2. 飞行甲板（~300 件）
- **斜角甲板**（降落区斜置）+ 起飞区 + 停机区
- **弹射器×N**（电磁弹射 EMALS / 蒸汽弹射——弹射滑梭+轨道）
- **拦阻索×N**（降落拦阻——钢索+滑轮+拦阻机）
- 甲板标记（涂装：跑道线/停机位/标识）
- 升降机×N（甲板↔机库，平台可升降）+ 安全护栏/防爆网

### 3. 舰岛（~200 件）
- 舰岛（右舷）：**相控阵雷达**（旋转）+ 舰桥（航海/航空舰桥）+ 桅杆（雷达/天线）+ 烟囱
- 近防武器（近防炮/防空导弹）

### 4. 舰载机（独立装备，~300 件/型）
- **歼-15/歼-35**：折叠机翼（舰载机特色——机翼可折叠省空间）+ 尾钩（拦阻降落）+ 加强起落架
- 舰载机是独立零件树，在航母上起降

### 5. 内部机库（~300 件）
- 机库甲板（停放舰载机）+ 升降机井 + 弹药库 + 舰载机维护区 + 消防/牵引车

## 二、机构运动（航母的"活"）

- **弹射起飞**：舰载机挂弹射器 → 弹射滑梭加速 → 离舰（弹射动画）
- **拦阻降落**：舰载机着舰 → 尾钩挂拦阻索 → 拦阻索拉出减速 → 停住
- **升降机**：舰载机在甲板↔机库间升降
- **机翼折叠**：舰载机机翼折叠/展开（省空间）
- **雷达旋转**：舰岛相控阵雷达转动
- **航行**：螺旋桨推进 + 尾流

## 三、受击/质感

- 受击：甲板中弹、舰岛受损、舰载机起火
- 质感：甲板防滑涂层/标记、舰体涂装（海军灰）、做旧（海水腐蚀/锈迹）

## 大工程提示

航母太大，**分层分块做**（先舰体+甲板立住，再舰载机，再内部）。
舰载机（歼-15/歼-35）可作为独立装备先做（和歼-20 共用框架）。
别一次全做——**先让"甲板上能弹射起飞/拦阻降落一架舰载机"这个核心闭环通了**。
