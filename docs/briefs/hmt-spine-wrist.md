# HMT：腰椎连续覆盖、背侧咬合与腕周分片

本轮接续 `efb0a62` 的装甲版本。用户确认的体态提交为 `49610dd`；随后按用户新的轮廓对照与明确角度要求，修改肩甲轮廓、臂轴转面、腿甲外翻和脚尖朝向；胸廓—腰椎—骨盆的已确认弧线、头部造型、金属配色和灯光保留。修改前的真实网格、源文件和装配文件保存在 `D:\FunnyProjects\machine-stage-bulgarov\qa-out\revisions\20261024-before-spine-wrist`。

## 参考与改动

- **三节腹甲**：依据 13 号正面标注，改为三片近乎竖直的短甲，从胸廓下缘连续排到骨盆横梁上方。外甲不再照搬内部腰节的大角度转动。三片各自带窗口、紧固件与背后安装杆。
- **中央脊柱**：在现有腰节轴承内孔中补入五段承力轴，从骨盆座接至胸肩内部；胸内五层斜肋通过独立连接杆接到同一脊柱。前后外甲安装杆分别落到各自锚点，避免背甲翻面后左右连接杆在轴心内交叉。
- **背侧 A/B 咬合**：依据 11 号标注，将三片宽耳板做成上下中央凹槽，两片较窄连接甲的上下舌伸入凹槽，保留真实分缝。上节与背壳下缘同步避让，外壳不靠叠放遮住接缝。
- **前臂与腕圈**：依据 20 号图和用户逐点标记，前臂下缘与腕甲上缘共用一条凹凸轮廓，分缝留出倒角和活动间隙。每只手沿腕轴增加八片带内壁的弧形护甲，片间留 1.6° 接缝；前后凹凸唇继续对接前臂下缘，另有独立拇指桥翼。以实际加工网格在三个轴向高度逐度射线检查外甲并集；腕口下缘与掌背甲共同覆盖，内部轴承不计作护甲。不能仅凭四向零件存在就判定完整环绕。
- **腰背回包**：三层左右各一片水滴形侧翼，与中央 A/B 咬合片采用不同形态，向侧后方转折包覆；前面的三节腹甲保持原排列。
- **整体轮廓**：读取用户新给的 291 点全身标注，按头顶到脚底高度归一化比较横截宽度。收回过宽的下胸侧甲及肩背侧桥，并调整相应肋架端点。图像包含投影和姿态差异，测量只用于定位比例问题，不代表全部轮廓已经重合。
- **踝部嵌入件**：依据 23 号图，左右踝内窗口各增加独立护甲嵌片，具有独立零件编号和拆解方向。27、28 号侧后视用于检查包覆方向；本轮没有重做整套大腿、小腿外壳。
- **内衬配合**：收回背壳内衬尖端和掌背内衬的相邻边缘，给新腕甲、背侧耳板留出位置。检查的是实际材料连通性，未通过删除导出碎片或放宽相交阈值掩盖问题。

用户给出的五份分区 JSON、一份整体轮廓 JSON 和 robotcmp 对比标注 原样复制在同目录 `hmt-interface-reference` 中；手部逐点数据另存为 `hand-20-user-outlines.json`。原始图片、下载目录中的 JSON 和 outline-atlas 项目未修改。坐标是透视投影，尺寸、厚度、遮挡后的安装方式按当前模型尺度重建，不能据此宣称一比一复刻或可直接制造。

## 最新角度与包覆修订

- 大臂绕肩—肘长轴转 40°，小臂绕肘—腕长轴转 80°。从肩沿骨轴看向末端，右臂逆时针、左臂顺时针。关节中心沿原折线，不用额外外展代替转面；手掌保留自然下垂方向。
- 按 robotcmp 对照收窄肩甲，肩关节中心保留已确认位置；大腿外侧甲向内回收 10 mm，为垂手留出空隙。腿甲绕各自骨轴外翻 8°，脚尖朝外 22°，髋、膝、踝接点与脚底高度保持。
- 肘叉朝向前臂的一支独立拆成错层回包片，保留真实接缝；上臂驱动器上端下移 25 mm，避开转面后的肩罩。踝部轴承外径收敛 4 mm，以适配小腿外翻与脚尖外撇后的空间。
- 八片立领离开颈轴向外撑开，前缘低、侧后缘高，真实板面沿颈部竖起，给下巴留出空间。
- 腰侧新增两层左右斜脊甲，增加前后包覆深度；腰背三层水滴翼与中央咬合甲保留。
- 骨盆增加八片闭合弧面护甲，沿前低、髋侧高、后部升起的鞍形中线围合；正前片较窄，留出原横梁窗口和中央下甲的层次。

## 验证方式

沿用现有源生成、实体配合、精确网格导出、发布缓存和 Blender 渲染流程。新增五项关系测试覆盖腹甲方向及连续覆盖、背侧凹凸嵌入、脊柱首尾接续、双腕分片角度覆盖与踝部独立分件。

全身正面、侧面、三分之四、背面机位沿用原设置。近景通过 `render-hmt.py --camera-mesh-dir=qa-out/revisions/20261024-before-spine-wrist` 固定修改前的取景中心，避免相机随零件位置改变。对比图只并排原始渲染，不修饰模型外形。

- 实际装配：2,659 个独立零件、29,495,132 个三角面；全部零件通过闭合实体检查。
- 全部实体对检查：相交体积阈值保持 1e−12 m³，报告为 0 对相交，未新增豁免；功能连杆和线束的截断报告为 0。
- 材料连通性：修改前 28 项警告，当前 19 项，解决 9 项，没有新增或加重项。19 项遗留记录仍在 `qa-out/disconnected-parts.json`，不把它们列为全部解决。
- 腕周包覆：每侧在三个高度各作 360 条射线，均有 355 个角度命中外甲，最长连续空档为 1°，对应分片接缝。骨盆沿鞍形中线的三个取样带均为 360/360；这是静止姿态的取样验证。
- HMT 测试 59/59 通过；TypeScript 检查、修改文件 ESLint、生产构建通过。构建仍提示部分代码块较大；全仓历史 lint 问题不计为本轮已清除。
- 59 个发布块与真实装配的顶点、法线、UV、变换逐项一致；300 次加速拾取结果检查通过。1,599 件重复网格共用属性，未做减面。发布块共 813,246,946 字节；本机 Node 解码约 4.69 秒、装配约 0.65 秒，不能换算成浏览器首屏或帧率保证。

相机、灯光和材质设置沿用既有渲染脚本。对比图直接并排修改前后真实渲染。当前工作树的构建预览地址为 `http://127.0.0.1:4183/?qa=1`；`localhost:5173` 对应原仓库，不能据此判断本轮产物。开发预编译曾在与渲染同时启动时内存不足，交付预览使用已完成构建的文件，不进行启动预编译。
