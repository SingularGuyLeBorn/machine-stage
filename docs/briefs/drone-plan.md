# 无人机装备计划（零件级 · 验证"飞行运动学"）

> 定位：验证**飞行运动学 + 空中受击**。两款先小后大。**按 T-800 零件级标准**拆到电机/电路板/舵机逐件。

## 0. 选型（两款）

| 款 | 定位 | 为什么先做 |
|----|------|-----------|
| **FPV 自杀无人机** | 前线消耗品（俄乌现实感） | 结构极简，最快验证飞行运动学 |
| **察打一体无人机** | 中空长航时（MQ-9 类） | 固定翼运动学 + 侦察/打击 |

## 1. FPV 自杀无人机（~80 定义件，零件级）

| 系统 | 零件 |
|------|------|
| 机架 | 碳板中心板 + X 四臂（碳板纹理）+ 紧固件族 |
| **电机 ×4** | 每电机：外壳 / 定子 / 线圈 / 轴承 / 转轴（~5 件 ×4 = 20） |
| 螺旋桨 ×4 | 桨叶（实例化）+ 桨毂 + 螺母 |
| 电源 | 电池（**电芯×N** + 外壳 + 保护板）+ 分电板 |
| 飞控 | 飞控电路板（**主控芯片/电容/焊点**）+ IMU + 图传模块 |
| **FPV 摄像头** | 镜头组 + 图像传感器 + 外壳（**第一人称视角的"眼睛"**） |
| 图传 | 天线 + 馈线 |
| **战斗部** | **装药 + 引信（碰炸）+ 破片层/药型罩 + 外壳**（弹药零件化） |
| 固定 | **扎带 + 胶带 + 焊点**（FPV 的"作坊拼凑感"灵魂） |

### 运动学（飞行新维度）
- **4 桨差速**：俯仰/滚转/偏航全靠 4 桨转速差（姿态控制）
- 飞行姿态：加速前倾、转向侧倾、急停后仰
- 桨叶高速旋转模糊

### 交互/受击
- 起飞 → 悬停 → 巡航 → **FPV 第一人称视角**（摄像头画面 + 图传噪点）
- 俯冲攻击：锁定 → 俯冲加速 → **碰炸（战斗部起爆 + 机体粉碎性解体，碎片实例化）**
- 被击落：中弹 → 单桨停转 → 失衡螺旋坠落 → 坠地散架
- 低电量：动力衰减、图传闪断

## 2. 察打一体无人机（~150 定义件，零件级）

| 系统 | 零件 |
|------|------|
| 机身 | 蒙皮×N / 隔框 / 桁条 / 设备舱 |
| 机翼 | 左右机翼（蒙皮 + **翼肋×N + 翼梁 + 副翼 + 舵机**） |
| 尾翼 | V 尾×2（舵面 + 舵机） |
| 动力 | **活塞发动机**（气缸/活塞/曲轴/螺旋桨）——推进式 |
| **光电转塔** | **镜片组×N（可见光/红外/激光照射）+ 三轴稳定陀螺 + 伺服×3 + 外壳**（机体晃、转塔稳） |
| 航电 | 卫通天线鼓包 + 飞控 + GPS |
| 起落架 | 前三点×3（**收放机构**：收放作动器/锁/轮） |
| 武器 | 挂架×2 + **空地弹×2**（弹体/**导引头/战斗部/发动机/舵面**——导弹零件化） |

### 运动学
- 固定翼姿态（滚转转弯、俯仰爬降）
- **光电转塔三轴稳定**（机体晃、转塔指着目标不动——最出戏的稳定性演示）
- 起落架收放

### 交互/受击
- 盘旋侦察（转塔锁定地面目标持续跟踪）
- 挂弹打击：投弹 → 自由落体 → 命中
- 受击：机翼中弹 → 冒烟 → 失控下坠 → 触地爆炸

## 3. 质感层（L5）

| 款 | 质感 |
|----|------|
| **FPV** | **作坊拼凑感是灵魂**：碳板纹理 / 扎带+胶带 / **手写标记（部队涂鸦/编号）** / 焊点 / 战斗部粗糙改装感 |
| **察打一体** | 蒙皮接缝+铆钉 / **低可视化灰涂装** / 传感器光学窗口镀膜反光 / 序列号+中队徽记 / 起降磨损 |

### 深度细化（可见内部 + 机加工痕）
- **FPV 可见内部**：电机（定子/线圈/轴承）/ 飞控电路板元件 / 电池电芯 / 战斗部装药结构
- **察打一体可见内部**：光电转塔（镜片组/陀螺/伺服）/ 发动机 / 舵机 / 卫通内构
- **机加工痕**：碳板纹理 / **3D 打印层纹**（FPV 零件多 3D 打印）/ 焊点 / 热缩管 / 扎带

## 4. 框架新维度验收

- [ ] **飞行运动学**：4 桨差速 / 固定翼姿态 / 转塔稳定——求解器支持"无支撑悬空"合法存在
  （**飞行件不受"绝不悬空"约束**，框架加"飞行件"类别）
- [ ] **空中受击**：解体/坠落/螺旋下坠——零件级破坏（机翼断、桨飞、碎片实例化）
- [ ] **第一人称**：FPV 摄像头视角接入（视角系统第二次用）
- [ ] 零件级：FPV ~80 / 察打一体 ~150，电机/电路板/舵机/导弹逐件
- [ ] drone/ 之外零框架改动；零穿模（地面停放态）；commit 带原因；飞行/受击录屏存档

## 5. 一句话

虎式证明"地面机动"，无人机证明"飞行"——
**它逼框架承认"合法悬空"（飞行件），并把战场从地面拉到空中。**
