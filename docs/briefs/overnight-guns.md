## 〇、背景（你没有枪械知识，先读透）

造**枪械系列**（真实枪械，结构公开，该考据——搜各枪拆解图/剖视图做参考）。
方法：零件化 + 自内向外（registry.ts 声明零件，装配器生成）。
**枪械的灵魂是"射击循环"的自动原理**——子弹怎么被击发、枪机怎么自动退壳上弹。

**先搞懂三个自动原理**（后面每把枪对应一个）：
1. **导气式**（AK-47、M249）：子弹击发后，火药燃气从枪管侧面的**导气孔**泄出一部分，推动**活塞**后退，活塞带动枪机后退→抽壳抛壳→复进簧推回→推下一发上膛。
2. **枪管短后坐**（M2HB）：击发瞬间枪管和枪机**一起后坐一小段**，然后枪管停下、枪机继续后退抽壳。
3. **转管式**（加特林）：**6 根枪管绕轴旋转**，外接电机驱动，旋转中每根枪管依次完成装填→击发→抽壳——射速极高。

**子弹结构（每发都是零件）**：弹头（被甲+铅芯+钢芯）+ 弹壳（黄铜）+ 发射药（颗粒火药）+ 底火（击发药）。
**射击循环**：撞针击底火→发射药燃→弹头出膛→弹壳抛出。

## 一、AK-47（导气式，先做——立框架，~80 件）

**机构**：导气式 + 枪机回转闭锁（枪机头旋转锁住枪膛）。

零件级拆解（每个独立 partId）：
| 总成 | 零件 |
|------|------|
| 机匣 | 冲压机匣（左/右/铆钉族实例化）/ 机匣盖 / 弹匣卡榫 |
| 枪管 | 枪管（**带膛线**，剖视可见）/ 枪口制退器 / 准星 / 导气箍 |
| **导气系统** | 导气箍 + **活塞 + 活塞杆**（燃气推活塞——核心）+ 导气管 |
| **枪机** | **枪机框** + **枪机头（回转闭锁，有闭锁凸榫）** + 击针 + 抽壳钩 + 抛壳挺 |
| **击发机构** | 击锤 + 击锤簧 + 扳机 + 阻铁 + **快慢机（保险/单发/连发三档）** |
| 复进 | 复进簧 + 复进簧导杆 |
| **弹匣** | 30 发弧形弹匣（弹匣体 + **托弹板 + 托弹簧** + 底板） |
| 木件 | 护木 / 握把 / 枪托（木质纹理） |
| 弹药 | 7.62×39 子弹（弹头/弹壳/发射药/底火）实例化 |

**射击循环动画**：扣扳机→击锤打击针→击底火→弹头出膛（枪口焰）→燃气推活塞→枪机框后退→枪机头旋转开锁→抽壳→抛壳（弹壳抛物线+堆积）→复进簧推回→推弹上膛→闭锁。

## 四、加特林 M134（转管——最难最酷，压轴）

机构：**6 根枪管绕中心轴旋转** + 外接电机驱动。
- **6 根枪管束**（实例化，旋转）+ 旋转机匣 + 枪管箍
- **每根枪管的独立枪机**（旋转中依次装填→闭锁→击发→抽壳→抛壳）
- **驱动电机 + 减速齿轮组**（外能源）
- 供弹系统（弹链/无链）
- **超高射速**：旋转时各管轮流击发，弹壳瀑布式抛出
- 这是皇冠——6 管旋转 + 每管独立枪机依次击发
