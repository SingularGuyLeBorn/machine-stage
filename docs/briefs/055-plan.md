# 055 型驱逐舰 · 设计任务书（零件级 · 万吨大驱 · 航母带刀侍卫）

> 自主别来问。冲突以「真实 + 工程自洽」为准，记 PROGRESS.md。
> 055 型（南昌舰级）——中国万吨导弹驱逐舰，航母战斗群的"带刀侍卫"。**灵魂是 112 个通用垂直发射单元（VLS）**。
> 参考 055 公开资料。**零件数 1500+ 定义件**。

## 〇、背景

055：万吨级驱逐舰（满载 ~13000 吨），核心特征：
- **112 个通用 VLS 单元**（前 64 + 后 48，冷热共架）——能发射海红旗防空 / **鹰击-21 高超音速反舰** / 反潜 / 对地巡航导弹
- **中华神盾相控阵雷达**（346B 型，一体化桅杆/综合射频）
- 130mm 主炮 + 1130 近防炮 + 鱼雷 + 双直升机库

## 一、零件树（零件级）

### 1. 垂直发射系统 VLS（灵魂，~200 件）
- **VLS 单元×112**（前 64 + 后 48，**每个单元**：发射井盖（可开合）+ 发射筒 + 燃气排导（热发射）或 弹射（冷发射））
- **通用冷热共架**：热发射（导弹点火出筒）+ 冷发射（弹射出筒后点火）
- **装载导弹**：海红旗防空 / **鹰击-21** / 反潜 / 对地巡航（和 missile-plan 联动）
- VLS 排布（甲板下的垂发阵列）

### 2. 雷达/电子（~200 件）
- **346B 相控阵**（一体化桅杆，四面阵 + X 波段）——综合射频
- 一体化桅杆（多面阵 + 通信/电子战天线集成）
- 火控雷达 / 导航雷达 / 敌我识别

### 3. 武器（~200 件）
- **130mm 主炮**（舰艏，舰炮：炮塔+身管+供弹）
- **1130 近防炮**（见 carrier/ciws-1130.md）
- **鱼雷发射管**×N（反潜鱼雷）
- 干扰弹发射器

### 4. 舰体/动力（~300 件）
- 舰体（隐身外形，内倾舷侧）+ 全燃动力（燃气轮机×N）+ 轴系 + 螺旋桨 + 舵
- 机库（双机库，直-20 直升机×2）+ 直升机甲板

## 二、机构运动/交互

- **VLS 发射**（灵魂）：发射井盖开 → 导弹点火/弹射 → 出筒 → 转向 → 制导——**冷热两式**
- **鹰击-21 反舰**：VLS 发射 → 高超音速 → 末段机动突防（打航母）
- **防空导弹**：VLS 发射 → 相控阵引导 → 拦截
- 主炮射击 / 1130 近防 / 鱼雷发射 / 直升机起降（双机库）
- 相控阵电子扫描（不转动，波束电控）

## 三、受击/质感

- 受击：VLS 中弹（殉爆风险）、舰岛受损、近防拦截
- 质感：隐身外形哑光灰 + 焊缝 + 做旧（海水腐蚀）
