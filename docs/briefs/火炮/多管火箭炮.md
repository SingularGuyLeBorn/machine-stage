# 多管火箭炮（PHL-191 远程火箭炮）· 超详细零件级

> 远程多管火箭炮（PHL-191"远火"）——面覆盖火力。**模块化发射箱**（可换口径）+ 火箭弹齐射。
> 参考真实 PHL-191 / 海马斯（HIMARS）结构。**零件数 800+ 定义件**。

## 〇、多管火箭炮（先懂）

多管火箭炮 = **发射车（底盘 + 发射架 + 模块化发射箱）** + **火箭弹**（零件化）。
核心：**模块化发射箱**（一箱多管，打完换箱——可换 300mm/370mm/750mm 不同口径火箭弹）+ **齐射**（多发覆盖）。

## 二、机构运动/交互动画

- **齐射**：发射箱内火箭弹**依次/齐射**（多发连续发射——火焰+烟）——面覆盖火力
- **发射架回转/俯仰**：瞄准方向（回转 + 俯仰，阻尼感）
- **发射稳定**：发射前液压支撑（千斤顶落地稳定）
- **换箱**：打完 → 吊装换发射箱（模块化——快）
- 火箭弹：发射 → 固体火箭推进 → 弹道 → 命中（战斗部：杀爆/子母——子母弹开舱放子弹药）

## 三、受击/质感

- 受击：发射箱中弹（殉爆）/ 发射车中弹
- 质感：军用绿涂装 + 发射箱 + 火箭弹 + 发射烟熏黑
