## 〇、88 炮（先懂——传奇高射炮）

88mm Flak：本来是高射炮（打飞机），后来发现反坦克无敌（高初速穿甲强）。
特色：**十字形炮架**（四肢展开成十字——可 360° 回转 + 大仰角对空）+ **可拖车机动**（炮架可收拢到拖车）。

## 二、机构运动/交互动画（尽可能还原）

- **展开/收拢**：炮架四肢展开成十字（作战）↔ 收拢到拖车（机动）——展开动画
- **360° 回转 + 大仰角**：对空（身管大仰角）/ 对地（平射反坦克）
- **射击循环**：装填（装填手装弹入膛）→ 关闩 → 击发 → 后坐（复进/制退）→ 开闩退壳 → 下一发（高射速）
- **对空引信装定**：引信装定机设定爆炸高度 → 定时榴弹空中爆炸（弹幕防空）
- **对地平射反坦克**：穿甲弹平射（高初速穿甲）
