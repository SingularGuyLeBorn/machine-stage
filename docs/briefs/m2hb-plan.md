# M2HB 重机枪设计计划（零件级 · 验证"框架复用"）

> 定位：虎式之后**第二个装备**——验证"生产线边际成本递减"。真实枪械，结构公开（有图纸可查）。
> **按 T-800 零件级标准**：供弹杠杆逐件、击发机构逐件、铆钉成族。
> **核心验收：m2hb/ 之外零框架改动**（被迫改就说明框架没抽象好，记录重构）。

## 1. 零件树（真实枪械，~120 定义件）

| 总成 | 零件（拆到独立件） |
|------|------------------|
| **接收器** | 左/右侧板 + **铆钉族（几十颗实例化）** + 拉壳槽导轨 + L 形退壳杠杆+销 + 后挡板 + 供弹口盖 |
| **枪管组件** | 枪管（**带膛线**）/ 枪管延伸部 / 闭锁环 / 提把 / 枪口制退器 / 枪管卡扣（快拆） |
| **供弹机构** | 供弹滑块 / 拨弹齿×2 / 压弹板 / **多级供弹杠杆组（逐件）** / 可散弹链（M9 链节×N 实例化）/ 抛壳通道 |
| **枪机组** | 枪机 / 拉壳槽（螺面凹槽——撞针随动）/ 撞针 / **加速子（臂撞击枪机框）** / 复进簧+导杆 / 拉机柄 |
| **扳机组** | 扳机 / 阻铁 / 保险 / 握把 |
| **M3 三脚架** | 三腿（**驻锄 + 腿管 + 调节机构**）/ 高低机 / 方向机 / 架座 / 俯仰回转锁 |
| **T&E 机构** | 高低手轮 / 方向手轮 / **50 密位刻度机构（点击手感）** / 表尺 |
| **附件** | 机油壶（六阶段注油）/ 弹药箱（供弹链路起点） |

## 2. 核心机构难点（验收重点）

| 难点 | 要点 |
|------|------|
| 拉壳槽随动 | 撞针收进拉壳槽螺面凹槽，随枪机运动 |
| 加速子 | 加速子臂撞击枪机框，把枪管后坐能量传给枪机 |
| L 形退壳杠杆 | 长臂受理、短臂出力，退壳力放大 |
| 半自由枪机 | 枪管短后坐 + 枪机惯性，**开闩待击** |
| 供弹链逆向 | 弹链节从供弹口→拨弹齿→抛壳口完整路径 |
| 弹壳重力掉落 | 无弹匣弹簧，空弹壳靠重力从底部排出 |

## 3. 分波执行（每波 commit 带原因 + 零穿模）

- **波 1 核心机体**：接收器 + 枪管组件 + 枪机组 → 射击循环运动学可演示（短后坐→加速子→枪机后座→抛壳→复进）
- **波 2 供弹抛壳**：供弹机构（多级杠杆）+ 弹链 + 抛壳通道 → 弹链节节步进、空弹壳底部蹦出
- **波 3 脚架+瞄准+弹道**：M3 三脚架 + T&E（50 密位点击）+ 弹道
- **波 4 交互质感**：拉机柄（开闩待击）+ **机油壶六阶段注油** + 受击故障 + 分解（枪管快拆）

### 深度细化（可见内部 + 机加工痕）
- **可见内部**：供弹杠杆组 / 击发机构（阻铁/击针/保险）/ **枪管膛线** / 复进簧 / 拉壳槽螺面 / 表尺机构 / 弹链节内部
