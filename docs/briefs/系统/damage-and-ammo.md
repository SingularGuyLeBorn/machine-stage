# 战损与弹药零件化系统（跨装备横向系统）

> 核心洞察：**碎裂真实感 = 零件粒度 + 断面有料**（里头有东西可露）。
> 两个子系统：① 战损三态（damage states）② 弹药零件化。

## 1. 战损版本机制（damage states——碎裂感的工程解）

**矛盾**：全零件实时物理碎裂（工作量/性能爆炸）vs 整件消失（假）。
**解：预制战损变体**——每个关键零件做 3 态，受击按伤害切换，不实时碎裂。

### 三态
| 状态 | 表现 | 例子 |
|------|------|------|
| **完好** | 原样 | 装甲板平整 |
| **破损** | 凹陷 + 裂痕 + 划伤 | 装甲板凹陷、液压管弯折渗油 |
| **破碎** | 缺块 + **断面金属撕裂 + 内部结构露出** | 装甲板破洞，露出骨架/管路/线束 |

**关键：破碎态的断面要做"内部结构露出"**——破洞不是黑窟窿，是边缘撕裂 + 能看见里头
（这就是"零件要够多"的原因：里头得有东西可露）。

### 每装备优先做战损版的零件（先验证效果，不全做）
| 装备 | 优先件 |
|------|--------|
| 虎式 | 首上装甲 / 炮塔前甲 / 履带板 / 负重轮 / 炮管 / 油箱 / 侧裙板 |
| M2HB | 接收器侧板 / 枪管 / 供弹盖 / 三脚架腿 |
| 无人机 | 机翼 / 螺旋桨 / 机臂 / 光电转塔 |
| 金古桥 | 分体外壳板 / 插接座 / 喷口 |
| 英普莱扎 | 躯干重甲板（再生核心外露是关键镜头）/ 肩炮 / 臂甲 |
| T-800 | 头骨 / 肋骨 / 肱骨液压 / 膝后活塞（断件续行重点） |

**战损版 = 预制变体切换**：零件存 3 个几何版本（intact/damaged/broken），受击按伤害阈值切。
配合断面"内部结构露出"（断面处渲染内部骨架）。

## 2. 弹药零件化（不止外壳）

### 子弹（如 7.92mm）
弹头（**被甲 + 铅芯**）/ 弹壳 / **发射药（颗粒火药，剖视可见）** / 底火（底火杯+击发药）

### 炮弹（虎式 88mm，弹种分型）
| 弹种 | 内部结构 |
|------|---------|
| **穿甲弹 APCBC** | 风帽 + 被帽 + **钨合金弹芯** + 弹托（出膛脱落）+ 弹壳 + 发射药 + 底火 |
| **破甲弹 HEAT** | 引信 + **药型罩（铜罩）+ 空心装药**（起爆→金属射流）+ 弹体 |
| **榴弹 HE** | 引信 + **弹体装药** + 预制破片层 + 弹壳 + 发射药 |

**击发零件级过程**：撞针击底火 → 发射药燃烧（膛压）→ 弹头离壳 → 弹壳抛出。
**命中零件级过程**：穿甲弹风帽破碎→弹芯穿透→弹托脱落；破甲弹引信触发→药型罩射流→穿甲。

### 导弹 / 雷管
| 舱段 | 零件 |
|------|------|
| **导引头** | 整流罩 + 红外/雷达传感器 + 万向架 |
| **战斗部** | **装药 + 药型罩（破甲）或预制破片层（杀爆）+ 引信**——杀伤核心 |
| **发动机** | 固体火箭：壳体 + **药柱** + 喷管（点火→推进） |
| **控制舱** | 制导计算机 + 舵机 |
| **气动面** | 弹翼 + 尾舵（可动舵面） |
| **雷管/炸药** | 外壳 + 装药 + 引信/雷管 |

**导弹全生命周期零件级**：点火（药柱燃烧+喷焰）→ 飞行（舵面机动+导引头锁定）
→ 命中（引信触发 → **战斗部起爆**：破甲=金属射流 / 杀爆=破片飞散）。

## 3. 与框架的咬合

- 弹药 = 零件（弹壳/弹头/发射药/底火/战斗部全进注册表，可剖视拆解）
- 战损版 = 零件变体（`damage_states` 字段存多形态几何）
- 受击 = 形态切换（战损系统按伤害切 damage_state，不实时碎裂）
- 击发/命中 = 弹药零件的分离/起爆编排
