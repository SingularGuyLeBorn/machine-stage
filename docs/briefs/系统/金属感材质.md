# 金属感材质规范（所有装备统一——告别塑料感）

> **问题**：现在的模型全是"塑料感"——光滑、均匀、无金属质感。
> **目标**：所有装备都是**金属**——金属的光泽、反射、拉丝、机加工痕、磨损划痕。
> 这是所有装备的材质标准，必须遵守。

## 〇、塑料感 vs 金属感（本质区别）

| 塑料感（现在，错） | 金属感（要） |
|-------------------|-------------|
| 光滑均匀，像塑料/树脂 | 金属的光泽和反射 |
| 高光散、闷 | 金属的锐利高光 + 环境反射 |
| 颜色均匀 | 金属处理色（烤蓝/磷化/拉丝/镀层） |
| 无磨损 | 机加工痕 + 磨损划痕 + 锈蚀 |

**核心：金属会反射环境、有锐利高光、有处理纹理、有磨损痕迹。塑料不会。**

## 一、PBR 金属-粗糙度工作流（必须用 PBR，不用普通 lambert）

所有金属件用 **PBR 材质（MeshStandardMaterial 或物理材质）**：
- **metallic = 1.0**（全金属）——金属度拉满
- **roughness 按处理调**：
  - 抛光/镀铬金属：roughness 低（~0.1-0.2，锐利反射）
  - 机加工/拉丝金属：roughness 中（~0.4-0.6）
  - 磨砂/铸铁/装甲钢：roughness 高（~0.7-0.9，哑光金属）
- **金属必须反射环境**——需要**环境贴图/HDRI**（金属反射周围环境才有金属感，没环境反射就是灰塑料）

## 二、金属质感细节（这是金属感的灵魂——必须有）

| 细节 | 效果 | 用于 |
|------|------|------|
| **拉丝**（brushed） | 各向异性高光（单向拉丝纹理） | 枪管、炮管、金属杆 |
| **机加工痕**（machining） | 车削/铣削的刀痕 | 机加件、活塞、轴 |
| **磨损掉漆** | 边缘/常摸处掉漆露金属（发亮） | 握把、边缘、把手 |
| **划痕** | 表面划痕 | 装甲、外壳 |
| **烤蓝** | 深蓝黑金属色 | **枪械**（枪管/机匣） |
| **磷化** | 灰绿/灰黑磷化层 | 枪械机匣、炮 |
| **锈蚀** | 锈迹（边角/焊缝/常年处） | 甲板、焊缝、老装备 |
| **焊缝** | 蛇形焊缝 + 焊接变色 | 装甲板、舰体 |

**实现**：这些细节用 **normal 贴图（凹凸）+ roughness 变化 + 颜色变化**（不是改几何——是材质层面）。

## 三、各装备的材质要求（具体）

### 枪械（AK/机枪/三八大盖等）
- 枪管：**烤蓝**（深蓝黑金属，拉丝）+ 枪口积碳烧蚀
- 机匣：**磷化**（灰绿/灰黑）+ 铆接金属
- 木件：木质纹理（不是金属）
- 磨损：握把/拉机柄**磨亮**（掉漆露金属）

### 航母/舰船
- 舰体：**钢铁**（哑光金属，roughness 高）+ 焊缝 + 海水腐蚀锈蚀
- 甲板：防滑钢 + 磨损 + 标记
- 金属件：炮/雷达/武器金属（烤蓝/磷化）

### 坦克（虎式/MBT/现代坦克）
- 装甲钢：**哑光装甲钢**（roughness 高）+ 焊缝蛇形 + 防磁涂层（虎式）/ 复合装甲（MBT）
- 炮管：金属拉丝 + 抽烟装置
- 磨损：边缘掉漆、泥污、锈迹

### 发动机/机构
- 金属机加件：**机加工痕 + 拉丝 + 油润感**
- 铬钢（T-800）：**镀铬金属**（roughness 低，镜面反射）
