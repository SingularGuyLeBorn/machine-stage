## 一、Three.js PBR 金属实现（代码级——照这个写）

### 1. 基础金属（MeshStandardMaterial）
```js
const metalMat = new THREE.MeshStandardMaterial({
  color: 0x9a9a9a,      // 金属基色（银灰/枪灰）
  metalness: 1.0,       // 金属度拉满（全金属）
  roughness: 0.4,       // 粗糙度按处理调
  envMap: envMap,       // ★ 环境贴图（金属感的关键——金属反射环境）
  envMapIntensity: 1.0, // 反射强度
});
```

### 2. 进阶金属（MeshPhysicalMaterial——拉丝/清漆）
```js
const brushedMetal = new THREE.MeshPhysicalMaterial({
  color: 0x8a8a8a,
  metalness: 1.0,
  roughness: 0.3,
  envMap: envMap,
  anisotropy: 1.0,            // ★ 各向异性——拉丝金属的单向高光（枪管/炮管）
  anisotropyRotation: 0,
  clearcoat: 0.3,             // 清漆层（镀铬/抛光金属的表层亮泽）
  clearcoatRoughness: 0.1,
});
```

**关键：`metalness=1.0` + `envMap`（环境反射）——没有 envMap 就是灰塑料，有了才是金属。**

## 二、环境贴图 HDRI（金属感的灵魂——必须有）

**金属感 = 金属反射周围环境。没有环境贴图，金属就是死的（灰塑料）。**

### 免费 HDRI 资源（CC0，直接下载用）
- **Poly Haven**：https://polyhaven.com/hdris —— 850+ HDRI，CC0 免费
  推荐：`studio_small_08`（工作室）/ `industrial_hall_01`（工业——适合机械）
- **ambientCG**：https://ambientcg.com/ —— 420+ HDRI，CC0 免费

### 加载（RGBELoader + scene.environment）
```js
import { RGBELoader } from "three/examples/jsm/loaders/RGBELoader.js";
const hdr = await new RGBELoader().loadAsync("./hdr/studio_small_08_2k.hdr");
hdr.mapping = THREE.EquirectangularReflectionMapping;
scene.environment = hdr;        // ★ 场景级环境——所有 PBR 材质自动反射
scene.background = hdr;         // 可选：背景也用 HDRI
```
**`scene.environment = hdr` 一次设置，全场景 PBR 金属自动反射环境——金属感立刻出来。**

## 三、金属 PBR 贴图资源（免费 CC0，直接下载）

金属的"拉丝/划痕/锈蚀/机加工"细节靠 **PBR 贴图**（albedo颜色 + normal法线 + roughness粗糙 + metallic金属 + AO）：

### 资源站（CC0 免费，成套下载）
- **Poly Haven Textures**：https://polyhaven.com/textures —— 搜 "metal"：brushed/scratched/corrugated（拉丝/划痕/波纹）
- **ambientCG**：https://ambientcg.com/ —— 直接有现成金属 PBR：
  - `MetalBrushed02` / `MetalBrushed01`（**拉丝金属**——枪管/炮管）
  - `MetalScratched01`（**划痕金属**——装甲/外壳磨损）
  - `MetalRust01` / `MetalRust02`（**锈蚀金属**——甲板/焊缝/老装备）
  - `MetalPlates01`（**金属板**——装甲/舰体）
  - `MetalCorrugated`（波纹金属）

### 用法（贴图赋予材质）
```js
const tex = (n) => new THREE.TextureLoader().load(`./textures/metal/${n}`);
metalMat.map = tex("MetalBrushed02_Albedo.jpg");
metalMat.normalMap = tex("MetalBrushed02_Normal.jpg");
metalMat.roughnessMap = tex("MetalBrushed02_Roughness.jpg");
metalMat.metalnessMap = tex("MetalBrushed02_Metallic.jpg");
metalMat.aoMap = tex("MetalBrushed02_AO.jpg");
```

## 四、第三方库/工具（可选加速）

- **three.js 内置 PBR**：MeshStandardMaterial / MeshPhysicalMaterial（够用，不用额外库）
- **@react-three/drei**（如果项目用 R3F）：`<Environment files="..." />` 一行加载 HDRI 环境
- **Quixel Megascans**（epic 免费，PBR 贴图库——质量更高，需注册）
- **Poly Haven / ambientCG 的 Blender/插件**：批量导出 PBR 贴图

## 五、各装备贴图选型（照这个配）

| 装备 | 材质贴图 | 关键参数 |
|------|---------|---------|
| **枪管/炮管** | `MetalBrushed`（拉丝）+ anisotropy | metalness=1, roughness~0.3, anisotropy=1 |
| **枪械机匣** | 磷化灰绿（颜色）+ `MetalScratched`（划痕） | metalness=1, roughness~0.5 |
| **坦克装甲** | `MetalPlates`（金属板）+ 焊缝 + 磨损 | metalness=1, roughness~0.7（哑光钢） |
| **航母舰体** | `MetalPlates` + `MetalRust`（锈蚀，焊缝/边角） | metalness=1, roughness~0.75 |
| **T-800 铬钢** | 抛光金属 + clearcoat（镀铬） | metalness=1, roughness~0.15, clearcoat=0.5 |
| **机加件（活塞/轴）** | 拉丝 + 机加工痕 | metalness=1, roughness~0.4, anisotropy=1 |
