# 任务书：装配秀（Assembly Show）

> 用户原话："零件散落一地，点击组装，一点一点组装成完整坦克；零件可以像 3D 打印一样慢慢长出来，
> 也可以从四面八方飞过来；发动机组成后动一下展示可玩性；然后再一层层外壳。"
> 本任务为**表现层编排**，不改注册表几何、不动检测器逻辑。

## 1. 功能定义

右栏新增主动作「组装」（AssembleShow）。完整时间线：

```
T0   散落态：全部零件随机散布（地面一圈 + 空中零星悬浮），整机位置空着
T1   L1 发动机：零件逐批登场组装（核心件慢、重复件波浪快）
T2   L1 落成 → 发动机原地运转 2s（曲轴转、活塞往复——「动一下」可玩性展示）
T3   L2 传动支撑 → L3 内饰 → L4 外壳 → L5 表面，每层组完短暂停顿展示
T4   整车落定 → 灯光渐亮 + 镜头收尾环绕一周 → 回到可交互态
```

全程可暂停 / 可跳过 / 可回放；与构建滑杆联动（滑杆 = 手动版，组装 = 自动版，
秀播放时滑杆实时跟随，拖动滑杆可随时接管）。

## 2. 三种登场效果（按零件类型分配，注册表可加 `entrance` 字段声明）

| 效果               | 适用                                      | 实现提示                                                      |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------- |
| **A. 3D 打印生长** | 壳体大件（曲轴箱/缸体/装甲板）            | 局部裁剪平面从零件包围盒底部向顶部扫过，裁切口跟一圈发光边    |
| **B. 飞入落定**    | 小件/紧固件（螺栓/火花塞/履带销）         | 随机方向弧线飞入（easeOutCubic + 落定 2% 过冲回弹），可带自旋 |
| **C. 波浪批量**    | 实例化重复件（履带 ×192/气门 ×24/螺栓圈） | 按实例索引错峰登场（每件延迟 20–40ms），只动实例矩阵          |

缺省按零件包围盒尺寸自动判断：大 → print，小 → fly，实例件 → wave。

## 3. 编排与节奏（呼吸感）

- 核心件慢（曲轴/缸体/炮塔：登场时间长 + 镜头推近）
- 重复件快（螺栓/履带销：波浪扫过，不逐件停留）
- 层间停顿 0.5–1s（让用户看清"这一层是什么"）
- **T2 运转 2s 是全秀高潮**（不是结尾）——转速曲线必须用 kinematics 真实数字

## 4. 相机

- 全程自动运镜：开场全景（散落态）→ 跟随当前组装层的总成特写 → 收尾环绕
- 用户拖动鼠标 = 临时接管，松手 3s 交还自动运镜；提供"无运镜"开关

## 5. 架构纪律（不许重造轮子）

- 组装顺序 = 注册表 `build_order`；散落起点 = 终点 + 伪随机偏移（固定种子，可复现）
- 状态机：`DISASSEMBLED → ASSEMBLING(L1..L5) → RUNNING_DEMO → COMPLETE`
- 打印生长的裁剪平面按批复用，禁止每零件一个材质实例
- 与 ErrorBoundary / 穿模面板 / 零件树联动不破坏（秀中点零件仍可聚焦）

## 6. 验收

- [ ] 点「组装」：散落 → 五层逐层生长 → 发动机运转 → 整车落定，60fps 流畅
- [ ] 打印生长有发光裁切边、飞入有缓动回弹、重复件有波浪错峰
- [ ] 暂停/跳过/回放可用；拖滑杆可接管
- [ ] L1 落成时曲轴+活塞真实联动（kinematics 数字）
- [ ] 秀后静态扫描零报告（组装终点 = 装配位，不许为表演乱飞）
- [ ] 录屏存档 docs/screenshots/ 或 docs/videos/；tsc/vitest 全绿；commit 带原因

## 7. 发挥空间

- 登场效果参数（速度/弧线/发光色）、运镜路径、散落态形态（地面圆圈/货架/空中星座）——好看为准
- 音效钩子可加（打印嗡嗡/落定咔哒/发动机轰鸣，Web Audio 合成）
