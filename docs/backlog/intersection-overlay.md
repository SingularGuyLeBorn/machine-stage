# 待办：交线 / 穿模位置可视化（报告的可视化图层）

> 来源：用户 2026-10 原话「交线和穿模检测可以有更明显的颜色，提供一个功能显示交线和穿模的位置」。
> 状态：**待办（用户明示：有空再做）**。不改 `detect.ts` 判定逻辑，纯表现层。

## 1. 功能定义

视图新增**交线图层**（开关，默认随「静态重扫 / 动画扫掠」开启）：

- 检测到的**交线段**（bvhcast 输出的截线段）直接画在整机模型上；
- **穿透点**（报告 `point`）小球标记 + 引线标注；
- 穿模位置一圈亮线，比报告卡片直观。

## 2. 颜色语义

| 类别                                     | 颜色                              | 说明                                                 |
| ---------------------------------------- | --------------------------------- | ---------------------------------------------------- |
| `displaced` / `suspect`（真穿透 / 存疑） | 亮红 / 洋红（emissive，吃 bloom） | 必须一眼炸出来                                       |
| `bearing_overlap`（同心配合面，已豁免）  | 青色半透明（默认隐藏）            | 配合接触，不抢戏                                     |
| `face_mate`（共面贴合，已豁免）          | 灰色半透明（默认隐藏）            | 同上（注意：face_mate 现在不进报告集，需要额外通道） |
| 当前报告对                               | 亮黄 + 闪烁                       | 点报告时该对高亮                                     |

- 交线：单批 `LineSegments`（或 `Line2` 粗线）合并所有段 = 1 draw call；端点小球用 `InstancedMesh`。
- 明显度红线：整机视图 3m 外能一眼看到亮红交线，不许细到看不见。

## 3. 联动

- 点报告卡片（`ClippingPanel`）→ 只显示该对交线（其余淡出）+ 相机飞到线中心；
- 点隔离视图（`IsolationView`）→ 隔离视图内显示该对交线（A/B 之间那圈截线）；
- 工具条开关四态：全部 / 仅未豁免 / 仅选中 / 关；
- 扫掠：动画扫掠时实时看到交线出现 / 消失（调试用，性能允许就做，加分项）。

## 4. 前置依赖与数据通道（实现前先确认）

1. 报告里是否已带**交线端点数据**：`detect.ts` 内部算过截线段（`交线 XXmm` 就是它），但要看 `PairContact` / `ReportEntry` 是否把段端点保留下来。若没有 → 先按加法补输出（`segments: [x0,y0,z0,x1,y1,z1][]`，世界坐标，注意实例变换）。
2. `form` 字段（`displaced / suspect / bearing_overlap / face_mate`）已由判定树修复提供，正是颜色语义输入。
3. `face_mate` 目前不进报告集（判据：交线总长 < `FACE_MATE_LINE_M`）——若要显示灰色共面层，需在报告集之外单独开一条通道，别恢复它进报告。
