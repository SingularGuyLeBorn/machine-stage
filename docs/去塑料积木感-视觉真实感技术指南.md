# 去塑料积木感 —— 视觉真实感技术指南

> 适用对象：fight-stage 中所有程序化生成模型（虎式坦克、枪械、战机、火炮等）。
> 本文档不列计划，只回答一个问题：**为什么代码量已经很大，看起来还是像积木，以及怎么解决。**

---

## 一、症状：什么是"塑料积木感"

塑料积木感不是"零件太少"，而是一种综合观感：

- 表面像**喷漆塑料**：颜色均匀、反光一致、没有使用痕迹
- 零件像**机加工标准件**：边缘锐利、形状完美、重复件一模一样
- 整体像**展示柜里的模型**：孤立、干净、与环境无互动
- 动起来像**电动玩具**：匀速、精确、没有惯性和迟滞

关键认知：**真实感不来自"多"，来自"不完美"**。一个只有 500 个零件但有磨损、油渍、铸造误差的模型，比 5000 个完美零件的模型看起来更真。

---

## 二、根因诊断（五层）

### 2.1 材质层：均匀即塑料

当前状态：全身共用一套 512×512 程序化贴图，metalness 统一 0.18，颜色是平涂的 Dunkelgelb。

为什么塑料：
- 真实装甲钢的表面是**多层系统**：底漆 + 面漆 + 磨损露金属 + 氧化变色 + 油污 + 灰尘
- 当前材质只有**一层**，且这层在空间上均匀分布
- 金属度全场一致——但真实坦克上，履带销（高金属）、装甲漆（低金属）、观察窗玻璃（高反光低粗糙）是完全不同的光学特性

判断方法：截图放大 200%，看任意一块装甲板。如果颜色均匀、没有凹陷处积灰、没有凸起处磨亮，就是塑料。

### 2.2 几何层：完美即积木

当前状态：Box/Cylinder/Extrude 为主体，边缘倒角 0.02m，焊缝是完美圆柱，履带板是完美矩形。

为什么积木：
- 真实装甲板是**轧制或铸造**的：边缘有轧制圆角（不是倒角，是过渡弧）、表面有铸造纹理、板与板之间有装配误差
- 真实焊缝是**手工焊**的：焊道有起弧收弧的堆高、有蛇形摆动的不规则、有飞溅
- 真实履带板有**铸造编号、磨损不均、泥土嵌入**
- 真实重复件（96 节履带、24 个负重轮）存在**制造公差和磨损差异**

判断方法：看任意两个相同零件（比如两节履带板）。如果一模一样，就是积木。

### 2.3 光照层：硬阴影即渲染图

当前状态：directionalLight 硬阴影 + hemisphereLight 均匀环境光 + HDR 背景仅作背景。

为什么像渲染图：
- 真实环境中，物体凹陷处（焊缝根部、铆钉周围、舱口内侧）有**接触阴影**（AO）
- 光滑表面（炮管、玻璃）有**环境反射**，不是只有高光点
- 阴影有**半影过渡**，不是锐利边缘
- 没有色调映射，亮部过曝、暗部死黑

判断方法：看零件交接处（比如炮塔座圈和车体之间）。如果有清晰的暗缝，就是有 AO；如果是亮的或均匀灰，就是缺 AO。

### 2.4 动态层：匀速即玩具

当前状态：炮塔匀速旋转、履带匀速滚动、射击后坐是线性关键帧。

为什么像玩具：
- 真实炮塔启动时有**加速过程**，停止时有**减速和过冲回弹**
- 真实履带经过负重轮时有**振动**，车体会随地形**起伏**
- 真实射击后坐：炮身后坐 → 复进 → 车体下沉 → 悬挂回弹 → 稳定，是一个**阻尼振荡**，不是简单位移
- 真实机械有**次级运动**：天线摇摆、缆线晃动、舱盖震颤

判断方法：录屏逐帧看炮塔旋转。如果角速度恒定，就是玩具。

### 2.5 氛围层：孤立即展品

当前状态：坦克放在圆形展台上，背景是 HDR 环境，无地面互动。

为什么像展品：
- 真实坦克在**泥土/雪地/公路**上，履带会带起尘土、压出痕迹
- 真实坦克有**声音**：发动机怠速震动、履带金属摩擦、风噪
- 真实坦克会**脏**：挡泥板上的泥点、排气管的熏黑、观察窗的灰尘
- 真实战场有**氛围光**：阴天、黄昏、扬尘

判断方法：把坦克 P 到一张战场照片里。如果看起来格格不入，就是缺氛围。

## 三、解决方案（按层）

### 3.1 材质层：从"单层平涂"到"多层系统"

**核心思路：把材质拆成"结构层 + 磨损层 + 脏污层"**

#### 结构层（决定基色）
- 按功能分区：前装甲 / 侧装甲 / 顶甲 / 炮塔 / 履带 / 工具，各自独立的程序化贴图（不同 seed、不同 repeat）
- 贴图分辨率提升到 1024×1024 或 2048×2048（512 在特写时像素化）

#### 磨损层（决定哪里露金属）
- 边缘磨损：所有凸起边缘（舱口边缘、工具把手、履带板边缘）用顶点色或 mask 贴图标记，磨损处 metalness 提高、颜色变浅
- 高接触区：驾驶员舱口周围、装填手位置、踏板——这些地方靴子摩擦多，漆磨得快
- 焊缝：焊道本身发黑（高温氧化），周围有 heat tint（热变色，蓝紫渐变）

#### 脏污层（决定哪里积灰）
- 凹陷积灰：焊缝根部、铆钉周围、格栅内侧、舱口角落——用 AO 贴图或顶点色让这些地方变暗、粗糙度提高
- 重力流痕：雨水、油污沿垂直面向下流，形成垂直方向的污渍条纹（不是水平的）
- 底部泥污：车体下 1/3、挡泥板内侧、履带——泥点的颜色 = 地面颜色 + 深度变化

#### three.js 具体实现
```typescript
// 材质拆分示例：装甲 = 基色 × 磨损mask × 脏污mask
const armorMat = new THREE.MeshStandardMaterial({
  map: baseColorTex,           // 结构层：基色 + 板缝
  roughnessMap: roughnessTex,  // 结构层：粗糙度变化
  metalnessMap: metalnessTex,  // 新增：磨损处高金属、漆面低金属
  aoMap: aoTex,                // 新增：凹陷积灰
  normalMap: normalTex,        // 新增：铸造纹理（替代 bumpMap）
  envMapIntensity: 0.8,        // 新增：环境反射（不要太强，漆面不是镜子）
});
```

**不要用 bumpMap，改用 normalMap**。bumpMap 只影响光照，normalMap 同时影响光照和反射，真实感强得多。铸造纹理、焊缝起伏、防滑纹都可以用 normalMap 表现。

### 3.2 几何层：从"完美形状"到"制造痕迹"

**核心思路：消灭"数学完美"，引入"制造公差"**

#### 边缘处理
- 倒角改为**过渡弧**：不是 `bevelBoxGeometry` 的统一小倒角，而是根据真实工艺变化的圆角。轧制装甲板边缘圆角大（3-5mm），铸造件过渡更圆滑
- 焊缝：放弃圆柱体，用 `CatmullRomCurve3` 生成蛇形路径 + `TubeGeometry`，半径有波动（0.8-1.2 倍变化），模拟手工焊的不规则

#### 表面起伏
- 铸造纹理：铸造表面（炮塔、主动轮）用噪声位移贴图或几何噪声，幅度 0.1-0.3mm，产生"橘皮"感
- 防滑纹：翼板、挡泥板上的防滑凸点不是完美半球，是冲压的菱形或扁豆形，有方向性

#### 重复件差异化
- 履带板：96 节履带，每节加 0.1-0.5mm 的随机位置偏移和 0.1-0.5° 的随机旋转，模拟磨损不均
- 负重轮：橡胶轮缘的磨损不是均匀的，接地面磨损更严重，可以用顶点色标记接地面

#### 装配误差
- 板与板之间：不是完美对齐，有 0.5-2mm 的高低差
- 舱盖：关闭时不是严丝合缝，有 0.5-1mm 的缝隙不均

### 3.3 光照层：从"打光"到"环境"

**核心思路：让光照来自环境，而不是来自灯具**

#### 必须加的后处理
- **SSAO**（屏幕空间环境光遮蔽）：焊缝根部、铆钉周围、舱口内侧产生接触阴影。这是去塑料感最有效的一步
- **ACES 色调映射**：替代默认的线性映射，高光不过曝、暗部有细节
- **Bloom**：炮口焰、车灯、观察窗玻璃的泛光，强度要低（0.2-0.3），只是模拟镜头眩光

#### 光照调整
- directionalLight 的 shadow radius 加大（2-4），软化阴影边缘
- 环境光强度降低，让 SSAO 的效果显出来
- 考虑加入第二个方向光作为补光（从地面反射的天光），强度 0.2-0.3

#### 阴影优化
- shadow-mapSize 提升到 2048 或 4096（如果性能允许）
- shadow-bias 微调（-0.0001 到 -0.0005），消除阴影痤疮

### 3.4 动态层：从"匀速"到"物理"

**核心思路：所有运动都有惯性、迟滞、振动**

#### 旋转运动
- 炮塔旋转：用缓动曲线（ease-in-out），加速 0.5s → 匀速 → 减速 0.3s + 过冲 2° + 回弹
- 舱盖开启：不是匀速翻开，是重力 + 阻尼，先快后慢，最后有轻微弹跳

#### 直线运动
- 履带：不是匀速，有"主动轮驱动 → 履带张紧 → 诱导轮从动"的延迟感
- 射击后坐：完整的阻尼振荡曲线——后坐（快）→ 复进（慢）→ 过冲（下沉）→ 回弹（稳定）

#### 次级运动
- 天线：不是简单正弦波，是车辆振动（随机）+ 惯性（延迟）+ 阻尼（衰减）的叠加
- 缆线：重力下垂 + 车辆振动
- 发动机怠速：车体有 0.5-1mm 的高频微震（20-30Hz）

#### 地形反馈
- 履带路径点根据地形高度图调整 y 值，不是固定平面
- 负重轮：经过障碍物时独立压缩（简化：用射线检测地形，每轮独立偏移）

### 3.5 氛围层：从"展台"到"战场"

**核心思路：让模型与环境发生关系**

#### 地面互动
- 履带痕迹：车辆经过后在地面留下压痕（decal 或地形形变）
- 尘土：移动时履带后方扬起尘土（粒子系统，注意性能）
- 地面材质：不是纯色平面，是泥土/雪地/沥青，有颜色变化和粗糙度变化

#### 天气与时间
- 雾：距离雾（已有）+ 高度雾（低处浓、高处淡）
- 光线方向：不是固定方向，根据"时间"变化（清晨斜射、正午顶光、黄昏侧逆光）

#### 声音（可选但强烈建议）
- 发动机怠速：低频隆隆（Web Audio 合成：低频振荡 + 噪声滤波）
- 履带：金属摩擦 + 泥土挤压声
- 射击：闷响 + 回音

## 四、自查清单

每次修改后，用这张清单自测：

### 材质
- [ ] 放大 200% 看装甲板：有磨损、色差、污渍吗？
- [ ] 看焊缝：发黑了吗？周围有热变色吗？
- [ ] 看凹陷处（铆钉周围、舱口角落）：有积灰变暗吗？
- [ ] 看履带和工具：金属感强吗（高 metalness、低 roughness）？
- [ ] 看玻璃：有环境反射吗？不是纯黑吗？

### 几何
- [ ] 看两个相同零件：有微小差异吗？
- [ ] 看焊缝：是不规则蛇形吗？不是完美圆柱吗？
- [ ] 看边缘：是过渡弧吗？不是锐利直角吗？
- [ ] 看铸造件（炮塔、轮子）：有橘皮纹理吗？

### 光照
- [ ] 看零件交接处：有接触阴影（暗缝）吗？
- [ ] 看阴影边缘：是软过渡吗？不是锐利直线吗？
- [ ] 看亮部和暗部：都有细节吗？不过曝不死黑吗？

### 动态
- [ ] 看旋转运动：有加减速吗？停止时有过冲回弹吗？
- [ ] 看射击：车体有下沉和回弹吗？不是只有炮身后坐吗？
- [ ] 看天线/缆线：有随机振动吗？不是简单正弦波吗？

### 氛围
- [ ] 看地面：有履带痕迹吗？车辆带起尘土吗？
- [ ] 看整体：像战场装备还是展示柜模型？

## 五、常见误区

### 误区 1：零件越多越真实
错。零件多但每个都是完美几何体，只是"更复杂的积木"。真实感来自零件的**制造痕迹**（铸造、焊接、磨损），不来自数量。

### 误区 2：贴图分辨率越高越真实
错。2048×2048 的纯色贴图还是塑料。真实感来自贴图的**内容**（磨损、污渍、氧化），不来自分辨率。

### 误区 3：光照越亮越真实
错。过强的光照会杀死 AO 和阴影细节，让一切看起来平。真实感来自**光照对比**（亮部与暗部的差异），不来自亮度。

### 误区 4：动画越流畅越真实
错。60fps 的匀速线性动画还是玩具。真实感来自**运动的不规则**（惯性、迟滞、振动），不来自帧率。

### 误区 5：真实感 = 照片级渲染
错。实时渲染做不到照片级，也不需要。真实感是**心理感知**——当大脑检测到足够的"真实线索"（磨损、惯性、环境互动）时，就会判定为"真"。

## 六、参考基准

判断"够真了没有"的参照物：

- **游戏**：《战争雷霆》（War Thunder）的载具细节——注意它的磨损分布、焊缝形状、履带泥土
- **模型**：军模论坛的成品旧化作品——注意灰尘堆积在凹陷处、高接触区磨亮
- **照片**：博物馆实拍（Bovington Tiger 131）——注意轧制纹理、铸造编号、使用痕迹
- **电影**：《狂怒》（Fury）的坦克特写——注意油污、尘土、金属质感的层次

不要参照：CG 渲染图（通常太干净）、游戏截图（可能开了太高画质）、新出厂装备（没有使用痕迹）。

---

## 七、一句话总结

**塑料积木感的本质 = 数学完美 + 物理静止 + 环境孤立。**

**去塑料积木感 = 引入不完美（磨损、公差、污渍） + 引入物理（惯性、振动、反馈） + 引入环境（地面、天气、声音）。**

先从材质和光照入手（见效最快），然后动态，最后氛围。每一步都停下来截图对比，确认有效再继续。
