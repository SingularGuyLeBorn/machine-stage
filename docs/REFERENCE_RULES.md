# 参考库使用规则（一页纸）

> `D:\FunnyProjects\fight-stage`（老项目）是**参考资料库，不是代码来源**。
> 它是流水账架构（匿名 partN、散落的字面量坐标），已被放弃。本文档防止"参考着参考着就开始抄"。

## 可以拿（四样）

1. **颜色数值**：`src/three/code/tigerTank.ts` 顶部 `C` 常量区（对照 Bovington Tiger 131 实物取色：暗黄装甲、深钢、象牙白内饰等）
2. **尺寸数字**：各模型文件顶部的真实尺寸常量区（米制，研究过的数字，可直接引用）
3. **零件名单**：老项目有哪些零件（工具布局、焊缝位置、内饰构成）——当**完整度 checklist**，防止漏件
4. **资料线索**：Tigerfibel / Tiger 131 / TM 手册等出处

## 禁止拿（三样）

- ❌ **代码**：不复制任何几何构建代码（它是 box 堆叠思路，本项目是声明式注册表思路，范式不同）
- ❌ **结构**：不模仿它的文件组织、函数划分、流水账写法
- ❌ **习惯**：partN 匿名体系、字面量坐标、匿名 mesh——全是本项目明令禁止的

## 判断口诀

**拿走数字、颜色、名单；不拿代码、结构、习惯。**

犹豫时自问：我这次从老项目文件里读到的是"一个数字/一个颜色值/一个零件名"，还是"一段逻辑"？前者可用，后者违规。

## 执行检查

- 代码评审抽查：发现与 fight-stage 雷同的几何构建代码段 → 整段返工
- 验收佐证：主要尺寸与颜色与老项目核对一致（证明参考库被**正确**使用，而不是被无视或抄袭）
