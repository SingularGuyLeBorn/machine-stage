## 水下视角

从舰底仰视，双轴、五叶可调距桨和舵。水下不是一张平面：水面内侧、深水雾、海床沙脊与焦散、悬浮海雪和从水面斜射的光束共同组成水体；相机可直接从水上拖到水下环视。

![水下视角](05-fujian-underwater.jpg)
