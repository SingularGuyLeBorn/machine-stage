# 金古桥案例中实际踩过的坑

这些是复盘事实和适用条件，不是要求所有模型长成金古桥。此案例的下部接口、头肩双臂、胸甲与彩窗迭代多次；早期“测试全绿”的版本仍被用户正确指出外观不对。

下表用于查找可能原因，不是自动修复表。同样的现象可以来自不同原因：腿部残缺既可能误分，也可能源件缺面；天线悬空既可能安装点错，也可能缩放原点错。先找能区分原因的证据。判断如何形成、何时换解释及实际效果见 [decision-cases.md](decision-cases.md)。

| 症状 | 根因 | 修正方向 |
|---|---|---|
| 大臂被截断 | 仅按身高分层 | 源骨骼/连通域归组，完整手臂保护掩模 |
| 腿部缺一角、髋鼓归腹部 | 躯干切面穿过斜髋鼓 | 先固定腿部语义实体，主躯干模具排除它 |
| 头与身体或髋腿不连 | 分组不等于实体连接；源网格有缝 | 明确接头、局部补实并融合，逐组件检查 |
| 接口像胸甲中间有洞 | 只封边没形成完整接触面 | 同一模具生成完整槽底/侧壁，配对验证 |
| 腹盆像圆盘塔 | 前后左右统一缩放圆形 | 用源壳截面轮廓、中央脊、前后独立退台 |
| 腹盆像山形板叠放 | 只画正面山形后挤出 | 沿整个壳体轮廓放样，层间共享侧壁 |
| 顶部像尖帽子 | 中央所有曲面收成一点 | 有限小平顶，下面宽弧肩，配对槽同步改变 |
| 胸甲像圆角盒 | 改了倒角却没改宽高比和轮廓 | 先描参考上窄下展的双瓣，灰模对比再加细节 |
| 胸顶多了一圈帽檐 | 用整片胸壳上移当连接唇 | 只在内部连接区补薄唇，别沿全外缘叠横板 |
| 肩根很圆但遮住大臂 | 把圆肩避让体/运动凸包分给头部成为护甲 | 避让区域留空，小护甲局限于关节；检查原臂面可见性 |
| 双彩窗像彩条盾牌 | 把“彩虹”当等宽横条、沿用错误旧叠加细节 | 重画不规则窗轮廓、厚黑边和二维云斑；删除被替代横条 |
| 眼带像浮在额头前的横条板 | 用平盒和横向百叶代替实际后倾玻璃，没查剧照 | 先区分轮廓、安装和光学外观；重新确定参考各自的用途 |
| 眼带贴壳后反光仍有折痕 | 把源壳的低面数折面逐点复制到玻璃外表面 | 安装背面贴真实壳，外表面光顺拟合；分别检查厚度与贴合 |
| 天线悬空 | 只猜安装坐标，缩放中心在杆中部 | 表面定位、套筒嵌入、根节点作为缩放原点 |
| 髋天线不在圆盖中心 | 用整个髋部包围盒中心 | 拟合圆盖平面、圆周与法向 |
| 分体先竖直再横飞 | 两段平移硬拼 | 连续空间曲线、起步多轴位移，兼顾接口释放方向 |
| 合体四件一起动 | 一个全局 openness | 各模块独立起始时刻与展开量 |
| 第一帧电弧太大 | 常量长度/束数/亮度 | 从局部短电花逐渐增长，限制在当前接近接口 |
| 细节和主体互穿 | 低面数背板被非线性弯曲，面内仍是平面 | 前后表面共同细分或整套用同一切平面 |
| 布尔通过、浏览器开放边 | float64 中间结果和 float32 产物不同 | 对实际导出网格重新逐边审计 |
| 重合面产生极薄碎面 | 独立布尔与切割域边界完全重合 | 共用 split，消除偶然共面条件；不要只放宽精度 |
| 静态吻合、起步碰撞 | 小圆桥被槽包住，未给桥设计释放空间 | 新桥也沿释放向量加工真实槽并重跑动画采样 |
| 已确认腹盆随胸部变形 | 用改过的新躯干重新生成旧截面 | 冻结并先分出已确认模块，再编辑上部 |
| 预览看不见修改 | 页面服务旧 dist 或选了旧卡片 | 检查实际服务路径，构建并重载正确模型 |
| 导出多出一个球 | Blender 导入器生成骨骼 custom_shape 辅助物 | 从 pose bone 的 custom_shape 引用识别并排除，不能凭名字猜 |

## 不应照搬的旧做法

本案例里用过按体积过滤微小组件。只能删除已定位、尺度远小于产品容差的数值碎屑；负体积壳可能是内腔，不能通用地 `volume > 0` 过滤。

用少量点判断接触面时，大三角可能跨接触区，导致完整三角子集的面积不等于真实接触面积。应该裁剪或加密采样；不能只删失败断言后说接口已验证。边界连续性、配对距离、实体守恒各有独立价值。

构造性接触豁免只针对明确的套筒/杆、嵌入框等零件对，并限定深度。绝不能加“所有头肩与胸甲都豁免”来隐藏大臂遮挡或真实穿插。

离线几何审计通过后仍要看真实渲染。本案例用户指出的胸甲宽高、彩窗和肩根遮挡，都是几何测试看不出来的。验收要先回答“像不像图、有没有遮挡”，不能用测试数量回应审美反馈。

## 减少返工的检查顺序

1. 改之前保存正确参考与当前正侧背图；写明当前只动哪几个区域。
2. 先完成轮廓灰模和接触空间，先看见原大臂、完整髋鼓，再细化装饰。
3. 分件后立刻检查闭合与配对，不等材质/动画做完才发现基础错误。
4. 接口一变就跑近距运动，尤其新连接桥、榫槽与套筒。
5. 每一可验收切片保留可回退版本；生成器和生成资产一起保存。
6. 视觉证据用当前实际产物，不沿用旧版截图。交付别称“完全一致”，明确此次改动和已验证范围。
