# 参考图 vs 本实现

## 参考图（`ref/`）

| 文件 | 出处 |
|---|---|
| `ref-t800-endoskeleton-full.jpg` | Wikimedia Commons · *Terminator.jpg* · Daniel Oberhaus |

> 参考图里看语言（这是方向修正的依据）：
> **瘦削的铬钢杆**（不是粗壮肉块）、**细液压缸 + 细活塞杆 + 杆端球头**、
> **大量波纹软管**、**深色关节盘/护罩**做对比、整体**银亮铬钢**。
> 电影道具 500+ 零件、280+ 螺栓、60 根软管 —— 密度来自**零件多**，不是来自体量大。

## 逐条对照

| 参考图特征 | 本实现 | 状态 |
|---|---|---|
| 瘦削铬钢骨骼杆 | 骨段 = 4 根纵向角柱 + 5 道横撑环 + 带孔端板，铬钢银亮 | ✅ |
| 细液压缸 + 细活塞杆 + 球头耳环 | 6 根驱动缸缸径 φ36~44（杆 φ12~13），耳环/球头销独立成件 | ✅ |
| 大量波纹软管 | 每段 6 根软管束 + 4 根硬管 + 卡套接头 | ✅ |
| 深色关节（对比） | 关节盘/衬套/卡环/密封用深色件 | ✅ |
| 轮廓起伏来自机构排列 | 大腿前缘 6 根细活塞杆束 + 小腿后缘 4 根后置活塞杆束，弧度由杆束排布形成 | ✅ |
| 银亮铬钢、不用黑 | 骨段/杆束/缸体用 chrome + bone（银亮），只有密封/软管是深色 | ✅ |
| 密度 | 136 定义件 / 211 实例（缸 11 件/根 × 6） | ✅ |
