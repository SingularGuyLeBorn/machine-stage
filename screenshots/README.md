# T-800 右腿 · 侧视 / 正视 / 斜 45° 存档

## 参考图（`ref/`）

| 文件 | 出处 |
|---|---|
| `ref-t800-endoskeleton-full.jpg` | Wikimedia Commons · *Terminator.jpg* · Daniel Oberhaus |

> 参考图给出的语言：**瘦削铬钢杆**、**细液压缸 + 细活塞杆 + 杆端球头**、
> **大量波纹软管**、**深色关节盘**做对比、整体**银亮铬钢**。
> 电影道具 500+ 零件、280+ 螺栓、60 根软管 —— 密度来自零件多，不是体量大。
> **腿的体量来自外侧那一整片光滑曲面装甲板**（上宽下窄 / 膝细-中鼓-踝细）。

## 屈伸演示（`demo/`）

| 文件 | 说明 |
|---|---|
| `t800-flex-side.mp4` | 侧视完整屈伸循环（60 帧 / 5.4s / 12fps，H.264） |
| `t800-flex-iso.mp4` | 斜 45° 同一循环 |
| `t800-flex-side.gif` | 侧视 GIF（可直接贴聊天窗口预览） |

生成方式：

```bash
npx tsx scripts/t800-demo.ts                 # 渲染 60 帧 PNG
cd docs/qa/t800/demo
ffmpeg -y -framerate 12 -i side-%03d.png -c:v libx264 -pix_fmt yuv420p -crf 20 t800-flex-side.mp4
```

> 帧是**离屏投影渲染**（三角形深度排序 + 平面着色），不是浏览器截图 ——
> 所以无头也能出片，且不依赖窗口是否可见。

## 逐条对照

| 参考图特征 | 本实现 | 状态 |
|---|---|---|
| 瘦削铬钢骨骼杆 | 骨段 = 4 角柱 + 横撑环 + 带孔端板，铬钢银亮 | ✅ |
| 细液压缸 + 细活塞杆 + 球头耳环 | 6 根驱动缸缸径 φ36~44（杆 φ12~13），耳环/球头销独立成件 | ✅ |
| 大量波纹软管 | 每段 2 根软管束 + 4 根硬管 + 卡套接头 | ✅ |
| 深色关节（对比） | 关节盘/衬套/卡环/密封用深色件 | ✅ |
| 银亮铬钢、不用黑 | 骨段/杆束/缸体用 chrome + bone，密封/软管近黑 | ✅ |
| 镜面关节 | 新增 `mirror` 材质（roughness 0.035）：关节盘/球头座/销轴 | ✅ |
| **腿的体量 = 外侧曲面装甲板** | 骨段 kit 内置 `shell`：按层轮廓放样的曲面壳，前/后缘带肚子鼓出（股四头肌/腓肠肌） | ✅ |
| 上宽下窄 / 膝细-中鼓-踝细 | 装甲板轮廓：股骨 85→62mm，胫骨 50→66→48mm | ✅ |
| 密度 | 140 定义件 / 201 实例（缸 11 件/根 × 6） | ✅ |
