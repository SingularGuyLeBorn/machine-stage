# 舰员人物模型来源

本目录下的角色 GLTF 来自 **Quaternius** 的 Universal / Ultimate Modular Characters 系列
（Worker、Suit、Casual Hoodie、SWAT），授权为 **CC0 1.0**，可自由用于商业与非商业项目。

- 来源：https://quaternius.com/
- 镜像来源：本机 `fight-stage/assets/local-imports/quaternius-mirror/`（Quaternius 角色包）
- 处理：仅重命名文件；运行时按岗位重新着色（海军蓝/白/灰/医护红），并隐藏手枪网格。
- 动画：使用模型自带的 `Idle_Neutral` / `Interact` 循环，不修改骨骼与蒙皮。

这些模型是低多边形写实比例角色（身高约 1.86m，带手指/面部/服装分件），
用于替换此前由方块和球体拼出的程序化小人。
